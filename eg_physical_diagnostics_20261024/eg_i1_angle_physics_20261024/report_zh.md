# EG力闭合可靠性：I1离散角度物理效果验证

2026-10-24。**结论：HOLD。I1能够指出真实解析摩擦需求更低的角度，但单独降低I1也会明显增加碰撞并损害原可行抓法。实验1、2完成；未达到预设的完整训练准入条件，未启动T0/T1/T2。**

## 1. 选择I1及梯度核验

复用R0结果，不重新做AUROC分析。首次接触代理相对原PCR的场景平均AUROC优势为 **0.1765，95%区间[0.1439,0.2091]**，超过本轮0.10门槛，因此选择首次接触约束I1。

I1沿用R0定义：从官方`close_fingers`恢复左右首次接触点和法向，取两侧外向法向与对应闭合轴方向的平均不对齐风险。它与解析force-closure共享接触几何，因此高AUROC本身不是独立的泛化或创新证明；本轮关键是改变角度后的实际评价结果。

采用离散期望风险：对12个角度类计算固定I1表，以角度logit的softmax概率加权。接触求解器不参加反向求导；梯度通过分类概率传递，形式为 `p_k × (I1_k − E[I1]) / T`。主温度为1，另保留0.5/2敏感性结果；无效第13类梯度为零，深度不参加本轮约束。

**1,227/1,229个候选有非零角度梯度**，所有梯度有限；自动求导与解析公式最大差异1.39×10⁻¹⁷，有限差分最大误差8.77×10⁻¹¹。梯度路径通过，但“期望风险下降”不能替代实际离散姿态质量检查。

## 2. 数据、干预和评价

使用官方完整EG Kinect epoch-10的既有C3面板：12场景×4帧，48帧。固定最终候选池内原本无碰撞、非空且已知力闭合档位的1,229个候选：641可行、588弱力闭合，涉及56个物体ID。原始无解、碰撞及空夹候选不在这次角度干预的主体样本中。

每个候选评价全部12个真实15°角度类别，共 **14,748次逐姿态解析评价**。固定抓取点、接近轴、深度、宽度、候选ID、原分数及候选池成员；不重新NMS或截断。不用邻近离散GT质量替代实际姿态评价。统一可行标准仍为无碰撞、非空且 `0<μ≤0.4`；弱力闭合为 `0.4<μ≤1.2`。

所有原始角度的μ、碰撞和空夹均与历史标签严格一致。另将恢复与损害两个代表案例的全部12类姿态交给既有`Direct.score`独立复验，24个新旧姿态的μ、碰撞、空夹全部一致。I1跨服务器重算最大浮点差异2.13×10⁻⁸，数值一致容差为10⁻⁷；物理判据未改变。输入缓存与历史评价文件的SHA前后不变。最终成功任务累计约610 CPU秒，三台服务器每台最多4个CPU进程并行；无网络推理、无训练或参数更新、无C4/C5访问。

3,178/14,748个姿态没有可用I1：3,177次首次接触求解失败、1次空夹导致无Dex-Net抓法。它们的实际状态仍单独保留，**解析质量未知数为0**。期望风险只在接触可定义类上归一化，缺失类不伪填为可行或低风险；每候选平均9.41个有效类，原softmax缺失质量平均2.23%、最高63.37%。这是一项训练覆盖局限。

## 3. 固定分数后的实际物理效果

主分析I1选优不查看μ或碰撞标签：在可恢复接触的12类中选择最低I1，数值并列保留原角度。碰撞姿态只要能恢复接触，也可以被它选中。这避免用GT碰撞过滤暗中美化I1的效果。

|角度选择方式|最终可行|弱→可行|原可行→失败|新碰撞|无力闭合解|
|---|---:|---:|---:|---:|---:|
|冻结EG原角度|641|0|0|0|0|
|I1最低，全部12类，GT Oracle|750|190|81|224|1|
|I1最低，原角度±15°，GT Oracle|743|141|39|87|3|
|I1最低，原角度±30°，GT Oracle|762|182|61|144|1|
|GT辅助logit干预，最大改变量0.5|692|62|11|38|2|
|直接用真实解析质量选最佳角度，Oracle上界|879|238|0|0|0|

以上干预策略未新增空夹。最后一行直接查看解析质量和碰撞，仅表示角度可达的物理上界，不能当作I1或模型的效果。

12类I1选优使840个候选改变角度且I1下降，**只有414个在保持干净且有力闭合解的情况下μ降低**；另426个不能称为摩擦需求降低，其中包括新碰撞。原641个可行抓法中，81个受损：77变为碰撞、4变为弱力闭合。不能把“弱力闭合数减少”中转移到碰撞的部分算作成功。

按场景等权、在seen/similar/novel内分层bootstrap 10,000次：

- 全12类I1选优：可行率净增 **9.91个百分点 [7.59,12.52]**；但新碰撞率 **18.02% [14.15,22.16]**，原可行损害率 **13.38% [8.80,17.98]**。
- ±15°I1选优：可行率净增 **8.55个百分点 [7.04,9.98]**；新碰撞率 **6.80% [5.60,8.02]**，原可行损害率 **6.68% [3.72,10.60]**。
- 主logit干预：可行率净增 **4.42个百分点 [3.66,5.16]**，新碰撞率 **3.28% [2.60,3.99]**，原可行损害率 **1.35% [0.63,2.08]**。

区间以12个场景为重采样单位，不把1,229个候选视为独立样本；只反映该开发面板的不确定性。

**代表性案例：**

- scene100/帧0/候选760，其他参数不变，角度类10→9（−15°）：I1从0.02881降至0.01347，μ从0.6降至0.4，真实解析状态由弱力闭合恢复为可行。
- scene100/帧64/候选752，角度类9→1：I1从0.03122降至0.02024，但原μ=0.4的可行姿态变为碰撞。更好的接触法向配置并不保证场景中的抓取几何可行。

作为额外Oracle参照，先用GT排除碰撞／空夹再按I1选择，可得到864个可行抓法、228次恢复及5次损害，接近真实质量Oracle的879。这说明I1包含有效接触信息，同时也清楚表明当前收益依赖额外的几何可行性条件；该GT过滤不是可部署推理输入。

## 4. Oracle、logit可达性与真实模型收益

临时logit干预仅用于核验离散可达性：对已有角度logit施加一次归一化负梯度位移，最大绝对变化预设为0.25/0.5/1.0，主值0.5；没有优化网络参数或覆盖缓存。它使用GT接触风险，**不是冻结EG自己从点云推断出的结果，也不是已经学会的模型收益**。

主干预中1,227个候选的期望I1下降，但只有242个实际argmax改变。最终净增51个可行抓法，且仍引入38个碰撞。改变量0.25/1.0时净增可行分别35/75，新碰撞分别21/56；没有根据C3结果重新选择步长。真正冻结的原EG输出保持不变，实际模型收益为0，是否能从单视角输入学会这些变化尚未检验。

保留原候选分数和原Top-1身份的48帧对照如下；未干预的原碰撞／空夹／无解Top-1按原结果保留：

|策略|可行|弱力闭合|碰撞|无解|空夹|
|---|---:|---:|---:|---:|---:|
|原EG|20|13|8|6|1|
|12类I1 Oracle角度|26|3|12|6|1|
|±15°I1 Oracle角度|21|8|12|6|1|
|主GT-logit干预|20|13|8|6|1|
|真实质量角度Oracle|27|6|8|6|1|

主logit干预改变4个固定Top-1的角度，但其失败类别分布没有改善。因此，候选池里的净可行增加还没有转化为当前高排名目标失败的改善。

这些已观察到的解析变化来自**角度姿态干预**，不是候选质量排序：分数与候选ID顺序全程固定。但未训练出新分数，因而不存在有意义的“新旧姿态×新旧学习分数”2×2模型对照；不能用GT I1冒充新模型分数来填表。

## 5. 决策与实验3状态

本轮在汇总结果前固定了保守准入规则：主I1选优与主logit干预都须有正的场景净可行收益，并将碰撞／空夹增量和原可行损害率分别控制在5个百分点以内。该5个百分点是本轮操作性判断标准，不是用户原文给定的统计定理；没有事后放宽。

小幅logit干预有积极的可达性证据，但主I1选优明显违反碰撞与损害条件，邻近±15°也没有完全消除问题；固定Top-1在主logit干预下没有改善。因此整体 **HOLD**，而非GO。也不是STOP：I1确实带来了部分真实摩擦改善，当前不能断言这条物理信息路线无价值；没有运行正常续训，亦不能声称已经证明优于或不如T0。

**实验3未启动。** 未执行T0续训、T1质量权重detach或T2质量权重直接反传，也没有新增方法模块或碰撞损失。本轮不以继续调温度、改步长或扩展样本来争取通过。进入三组训练前，需要明确是否接受当前纯I1的碰撞和原可行损害风险；本次结果不支持直接把“期望I1降低”作为已验证安全有效的训练目标。

**最终回答：I1能指出并在GT辅助角度干预中实现更低摩擦需求的实际解析抓法，收益来自姿态变化而非排序；但纯I1也会把抓法推向碰撞，尚未证明EG能够从输入学习到这些收益或改善高排名失败，因此暂不启动训练。**
