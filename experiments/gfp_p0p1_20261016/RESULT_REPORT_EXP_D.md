## 结论

**按卡判读：B1a 避免了价值岛。** 结果与 seed 0 一致。

**卡上写定的窗口规则：** 305k–400k 共 20 个探针点。某一点同时满足以下两条即为"价值异常点"：
- 起点区对比（起点区 V − 全体 V）比 300k 高出至少 15；
- 起点区 ‖∂Q/∂a‖ 至少是 300k 的 2 倍（≥ 1.58）。

| 分支 | 价值异常点 | 最长连续 | 窗口内最大对比升高 | 窗口内最大范数 | 400k 对比升高 / 范数 | 400k 成功率 / 停在起点区 |
|---|---|---|---|---|---|---|
| **B1a**（只冻结 Actor 生成器） | **0 / 20** | 0 | −2.0 | 0.67 | −15.2 / 0.47 | **59% / 2%** |
| B1（Actor + VaBC 都冻结，C2） | 0 / 20 | 0 | −1.8 | 0.67 | −15.4 / 0.45 | 52% / 0% |
| B0（不冻结，C2） | 3 / 20（335k、340k、345k） | 3 | +22.7 | 2.16 | +0.9 / 1.53 | 1% / 95% |

**说明：**
- 原训练在同一口径下：300k 为 9%（40% 停在起点区），400k 为 0%（100% 停在起点区）。
- 窗口规则用在 B0、B1 上是事后应用，只作对照，不改变实验 C 的结论。按这条规则，B0 有 3 个连续的价值异常点。
- B1a 与 B1 的轨迹几乎重合：起点区对比单调下降，范数从 0.79 降到 0.38–0.47。
- **B1a 中 Actor 仍在学习：** 400k 时起点区动作变化 0.62，B1 为 0.62，B0 为 0.71。
- B1a 400k 的失败回合在迷宫中段，主要是 (6,6) 13 次、(5,4) 9 次、(4,5) 8 次，不在起点区。

## 合起来看（实验 B、C、D）

**在 seed 0（600k → 700k）和 s3（300k → 400k）两条训练上，都观察到同一结果：**
- 只要 TD 目标里 Actor 的下一步动作来自冻结的旧 Actor，就没有出现价值岛，Actor 也没有被推回起点区；
- 不冻结时，两条训练都出现了价值岛和起点区停留。

seed 0 上另外做过只冻结 VaBC 生成器（B1b），它没能阻止价值岛。

所以目前最直接的描述是：**价值岛来自"当前 Actor 的动作进入自举目标 → critic 在起点区被抬高、动作梯度翻转 → Q 项把 Actor 推回起点区"这条反馈。**

**仍然的限制：**
- 两条训练，各一个分叉点，各一次续训（配对续训，不能逐位重放）；
- s3 上没有做 B1b；
- 冻结生成器是诊断手段，不是算法；
- task4 的贴墙未涉及。
