## 结论

1. **拆分 B1（seed 0，600k → 700k）：按卡判读，Actor 生成的下一步动作进入自举目标是关键连接。**
   - 只冻结 TD 目标中的 Actor 生成器（B1a）：完全没有价值岛，700k 成功率 77%。
   - 只冻结 VaBC 生成器（B1b）：价值岛照样出现，只晚了约 10k；700k 成功率 7%。
2. **s3 复验（300k → 400k）：按卡的 400k 判读规则，B0 不算"复现"，所以对 B1 不下正式结论。** 这一点要说清楚，原因是规则本身没有对上 s3 的情况：
   - s3 的价值岛是**时起时落**的。B0 从 325k 起 ∂Q/∂a 范数放大（最高 2.7 倍），335k–355k 起点区对比升高 ≥ 15（最高 +22.7）。340k 冻结评价为 0%，100% 的回合停在起点区。之后它在 370k 消退，到 400k 又开始回升（范数 1.53）。
   - 卡上只在 400k 这一个时间点判是否复现。400k 正好落在回落之后，起点区对比只升了 +0.9、范数为 1.94 倍，两个条件都差一点没达到。
   - 不过 400k 时 B0 的行为仍是崩塌状态：1% 成功，95% 的回合停在起点区。这和原训练 400k（0%，100% 停在起点区）一致。
   - **描述性地看，B1 在 s3 上的表现与 seed 0 一致：** 100k 内起点区对比单调下降（−15.4），范数始终不超过 0.79。400k 成功率 52%，没有回合停在起点区。原训练在同一口径下 300k 为 9%、400k 为 0%；训练日志的评价在 800k 之前最高只有 6%。
   - 这个对照很强，但它是在卡的判读规则之外的描述。我不在事后改规则去把它算成"复现成功"。

## C1：拆分 B1（G_task1_s0，从 600k 续训 100k）

| 分支 | TD 目标中冻结的生成器 | 700k 起点区 V（升高） | 起点区 V 首次升高 ≥20 的位置 | 700k ∂Q/∂a 余弦 / 范数 | 680k 成功率 / 停在起点区 | 700k 成功率 / 停在起点区 | 判读 |
|---|---|---|---|---|---|---|---|
| B0（实验 B） | 无 | −130.1（+57.1） | 680k | −0.12 / 1.51 | 5 / 78% | 0 / 98% | 价值岛 |
| B1（实验 B） | Actor + VaBC | −189.6（−2.4） | 无 | 0.86 / 0.34 | 64 / 0% | 70 / 0% | 抑制 |
| **B1a** | **只冻结 Actor** | **−188.6（−1.4）** | **无** | 0.87 / 0.35 | **74 / 0%** | **77 / 2%** | **抑制** |
| **B1b** | **只冻结 VaBC** | **−138.0（+49.2）** | **690k** | 0.09 / 2.94 | **48 / 15%** | **7 / 66%** | **未抑制** |

- 600k 是 62.5%（200 回合）。
- B1b 在 700k 的失败回合主要停在 (2,1)，有 62 次，与 B0 及原训练相同。
- **按卡判读：** B1a 抑制且 B1b 未抑制，所以 **TD 目标里由当前 Actor 生成的下一步动作是价值岛的关键连接。**
- 这与实验 A（700k critic 的动作梯度足以把 Actor 推回起点区）合起来，可以描述成一条闭环：当前 Actor 的动作进入自举目标 → 起点区的 Q 被抬高，动作梯度翻转 → Q 项把 Actor 推向那里 → 循环。
- **在 B1a 中 Actor 仍在正常学习：** 起点区动作变化 0.53，与 B1 的 0.52、以及 B0 在岛出现前的水平相同。
- **B1b 的价值岛只比 B0 晚约 10k：** 首次升高 ≥20 在 690k，B0 是 680k。所以 VaBC 那一半目标并不提供这条反馈，至多稍微减缓它。
- **注意：** target_agg=mean 时，Actor 那一半只占目标的一半。这说明"冻结一半就够"。它不说明 VaBC 的动作在别的配置下（例如 target_agg=vabc）无关。

## C2：s3 复验（G_task1_s3，从 300k 续训 100k）

**分叉点的选择**（无训练扫描，起点区对比 = 起点区 V − 全体 V）：
- s3 的对比在 300k → 400k 从 −12.8 变为 +9.6，范数从 0.79 增大到 2.13。此后持续到 800k，900k 时恢复到 −20.3。
- 正常的 s1 在整个训练中保持在 −22 到 −27 之间。

| | 起点区对比相对 300k 的升高 | 起点区 ‖∂Q/∂a‖（相对 300k 的倍数） | 成功率 / 停在起点区 |
|---|---|---|---|
| 原训练 300k | 0 | 0.79（1×） | 9 / 40% |
| 原训练 400k | +22.4 | 2.13（2.7×） | **0 / 100%** |
| B0 340k（卡定的出现点） | +22.1 | 1.93（2.4×） | **0 / 100%** |
| B0 400k | +0.9 | 1.53（1.9×） | **1 / 95%** |
| B0 全程最大 | +22.7（345k） | 2.16（325k） | — |
| **B1 400k** | **−15.4** | **0.45（0.6×）** | **52 / 0%** |
| B1 全程最大 | 0（只有 300k 起点） | 0.79 | — |

- **按卡判读：** "B0 复现"要求 400k 时对比升高 ≥ 15 且范数 ≥ 2 倍。B0 是 +0.9、1.94 倍，不满足。按卡的规定，**不对 B1 下结论**，也不重启挑结果。
- **为什么会这样：** 原训练只有每 100k 一个检查点，看不到 s3 的价值岛在 100k 内会起落。我把判读点定在 400k 这一个时间点，没有考虑这种起落。这是卡的设计问题，不是 B0 没有出现价值岛。B0 每 5k 的记录（`results/exp_ab/c/G_task1_s3_B0/train_B0.json`）显示，它在 335k 到 355k 之间一直满足"对比升高 ≥ 15"。
- **行为上 B0 与原训练一致，B1 与它们明显不同：**
  - B0 在 340k 和 400k 的失败回合几乎全部停在 (1,1)、(2,1)；
  - B1 在 400k 的失败回合在迷宫中段，主要是 (6,6)、(5,4)、(4,5)，与 seed 0 正常时的失败位置相同。

## 能说和不能说的

**能说：**
- 在 seed 0 上，**冻结 TD 目标中的 Actor 生成器就足以阻止价值岛和崩塌；冻结 VaBC 生成器不行。**
- 在 s3 上，冻结两个生成器（B1）后，100k 内没有出现任何价值岛迹象，成功率从约 9% 升到 52%；同期 B0 出现了价值岛，行为也崩塌。这与 seed 0 一致。但按卡的规则，这不是正式结论。

**不能说：**
- **s3 上没有做 B1a。** "关键是 Actor 那条连接"只在 seed 0 上检验过。
- **每个分叉点只有一次续训。** GPU 续训不能逐位重放。
- **B1/B1a 都不是算法：** 它们让 critic 去评估一个旧的固定策略。不能直接作为改进方案。
- **task4 的贴墙仍未涉及。**
