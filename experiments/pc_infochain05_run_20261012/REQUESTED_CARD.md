建议把下一轮设计为 **“P1模型信息链诊断＋P2动作—进展诊断”**。两条线并行、共用数据，但回答不同问题：

| 研究线 | 具体问题 |
|---|---|
| **P1** | 六物体条件下，问题更可能出在**视觉编码、目标信息的使用，还是动作生成**？ |
| **P2** | 没有物体进展的片段中，夹爪究竟在做什么？是**接近中、来回运动、运动受限，还是动作没有形成有效操作**？ |

**本轮不再重复稀疏/拥挤实验，不单独研究落桌，也不把修复接触接口、恢复仿真快照设为全部工作的前提。** 落桌仍完整记录，不能从总体结果中删除。

以下是研究方案，尚未执行或授权新的训练、仿真与Git操作。

## 一、相对上一轮，修改什么？

上一轮已经整理了77个历史回合，但没有逐步DLP表征；正常接近对照未匹配成功；原GPU管线又无法提供接触双方，所以多项判断停在了“未判定”。RESULTS RESULTS

下一轮作三项调整：

**第一，直接检查模型处理的信息，不只看外部成功率。** 官方实现提供冻结DLP编码、粒子解码，以及完整生成动作序列的返回接口，可以用于诊断，不必先训练新模型。 

**第二，正常对照采用分级使用，而不是“没有完美匹配就全部停止”。** 条件不完全匹配时，不作严格异常率比较，但仍可以描述具体轨迹、进行同输入模型测试。

**第三，允许在原因尚未确定时开展区分性实验。** 不要求先证明原因再实验，否则会形成循环；但实验必须事先说明不同解释会产生什么不同结果，不能只问“这样改分数会不会提高”。

这些是**下一张卡的设计修正**，不回改PC-CAUSE-04已经冻结的标准和停止结果。

# 二、P1：从模型内部定位数量扩展退化

## P1的目标

不直接问“应该增加什么模块”，而是检查这条信息链：

**当前图像与目标图像 → DLP视觉表征 → 目标条件动作生成 → 实际执行。**

先区分三种候选解释：

| 候选解释 | 要寻找的证据 |
|---|---|
| **E：视觉表征不可靠** | 图像中能辨认的对象或目标，在提供给策略的表征中出现不稳定、混淆或信息损失 |
| **G：目标条件使用不足** | 目标信息变化已经进入表征，但模型的动作分布没有相应变化，或变化与任务要求不一致 |
| **S：动作生成不稳定** | 相同或变化很小的输入下，随机采样产生明显不同的行为倾向，并可能与实际往返、切换相关 |

**三项都是假设，不预设任何一项成立。**

## P1-A：检查DLP到底给策略提供了什么

### 怎么做

从历史回合中预先选取约 **12个代表回合**，包含3C/6C、成功/失败，以及有无进展片段。每个回合只选少量固定时点，例如初始、无进展前、无进展中和后续恢复或终止前。

对已有的原始双视角图像，使用同一冻结DLP重新编码，保存：

- 实际送入策略的前景粒子；
- 粒子位置、覆盖区域、外观特征与透明度；
- 前景重建与原图的对应关系；
- 当前对象与目标对象的可核验图像位置。

官方DLP没有保证不同帧、不同视角的同编号粒子对应同一个物体，因此不能把“粒子编号改变”直接当作表征混乱。[arXiv](https://arxiv.org/html/2412.18907v3)

### 重点检查什么

| 检查 | 用途 |
|---|---|
| 图像中清楚可见的未完成物体，是否在前景粒子与重建中得到合理表示 | 寻找编码侧疑点 |
| 物体实际位置基本不变时，其表征是否发生明显变化 | 检查输入变化与表征变化是否相称 |
| 当前图和目标图中的颜色、位置关系是否可区分 | 判断目标信息是否进入编码 |
| 同类疑点是否也出现在成功片段 | 避免把常见表征特征误当失败原因 |

不能只看整体重建误差。背景重建得很好，也不代表策略需要的某个方块位置被表达好了；反过来，重建不好也不自动说明策略无法利用相应信息。

### 这一项能得出什么

它可以告诉我们**编码侧有没有具体、重复的疑点**，但不能独自证明编码问题造成了任务失败。

如果保存的图片不是原始策略输入、分辨率或预处理无法核对，重新编码结果只能作为辅助分析；不能假称恢复了当时真实的内部状态。

---

## P1-B：固定当前画面，只改变目标，检查模型是否使用目标信息

这是P1中优先级最高的**区分性测试**。

### 核心思路

把“模型看不清当前场景”和“模型没有正确使用目标”尽量分开：

> **当前物体位置、夹爪位置完全不变，只改变合法的目标条件，观察表征与动作生成怎样变化。**

这首先是固定输入上的模型测试，不需要把物理仿真恢复到历史快照。

### 具体设计

优先选择真实轨迹中**只剩一个物体需要明显操作**的状态，以减少多目标顺序的歧义。

对同一个当前观察构造：

| 条件 | 设置 |
|---|---|
| G0 | 原目标 |
| G1 | 将该物体目标改为一个合法位置 |
| G2 | 将其目标改为另一方向、距离相近的合法位置 |

其他物体的目标保持不变。新目标须用一致的官方渲染或目标生成路径获得，检查边界、重叠与任务合法性，不随意修改粒子或删除目标token。

找不到合适的真实片段时，可以构造独立的诊断状态，但必须标明：**这是模型能力探针，不是原失败轨迹的复现。**

### 分别检查两层响应

**编码层：** G1、G2中改变的对象和目标位置，是否已经被DLP表达出来？

**策略层：** 在固定相同采样随机数的情况下，目标变化是否影响动作分布与短动作序列？这种变化相对于相同目标下的随机采样波动有多大？

每个输入先做少量、固定次数的重复采样，例如8次；完整记录采样噪声，不能挑选“看起来最好”的输出。

### 如何解释

| 观察 | 能支持的判断 |
|---|---|
| 图像目标变化清楚，但前景表征没有可靠表达 | 优先检查编码侧 |
| 表征能够区分目标，动作生成也有清晰响应 | 削弱“完全不使用目标信息”的解释 |
| 表征有变化，但动作变化很弱或不稳定 | 保留目标条件使用问题，继续检查是否存在共同接近动作等解释 |
| 相同输入重复采样的变化，比目标改变带来的变化还大 | 需要进一步分离采样随机性与目标条件作用，不能直接叫模型失效 |

**不能要求第一步动作立即朝目标方向移动。** 机械臂可能必须先撤回、绕行或调整接近位置；不同目标也可能共享最初的动作。因此应检查合理的短序列，并在必要时用少量完整运行确认行为差别。

官方策略确实返回动作序列，但默认只执行首动作；诊断时可以记录其余输出，不能把尚未执行的动作当成真实轨迹。

### 与P1数量退化怎样连接

上述测试必须同时纳入3C和6C材料，并分开报告。

若某种表征或目标响应异常在6C更突出，它只是**数量相关的机制线索**。只有后续对照确认这种异常影响执行，才能说它解释了规模退化的一部分。

# 三、P2：直接分析夹爪为什么没有带动物体取得进展

## P2的目标

把“无进展”拆开，而不是一律叫“停滞”：

1. 夹爪基本没动；
2. 夹爪在往返，但没有持续靠近待操作物体；
3. 夹爪正在正常接近，暂时没有推动物体；
4. 夹爪到达操作区域，物体仍未获得有效运动；
5. 物体有运动，但进展被抵消。

最后一种不一定符合原来的“所有物体几乎不动”事件定义，应作为邻近的失败行为另列，不能悄悄改变原停滞统计。

## P2-A：对每个片段形成一张“空间—时间诊断表”

先利用现有数据，不重新跑完整统计矩阵。

每个选定回合展示：无进展前、窗口内、窗口后，以及最终结果。不要只截取首次20步后就停止观察。

### 必须同时记录的量

| 信息 | 要回答的问题 |
|---|---|
| 夹爪三维位置、姿态、高度 | 是在物体上方、旁边，还是远离操作区域？ |
| 夹爪累计路径长度与起终点位移 | 是持续前进，还是走了很长路径却回到原处？ |
| 到各未完成物体的距离变化 | 是否真正接近任何尚待操作对象？ |
| 每个物体的位移与目标距离 | 是完全没推动，还是推动了错误方向？ |
| 动作、控制目标、实际运动 | 输出与执行之间在哪一段出现不一致？ |
| 后续第一次有效进展的时间 | 当前片段是暂时接近，还是长期无效执行的一部分？ |

可用一个简单的描述量：

\[
R=\frac{\text{夹爪起终点位移}}{\text{夹爪累计路径长度}+\varepsilon}
\]

路径很长但 \(R\) 很小，提示往返或绕行；**不直接证明动作错误**，因为必要绕行也可能出现类似数值。必须结合是否持续靠近物体、随后是否取得进展来解释。

### 不依赖接触接口，能查到哪一步？

可以检查夹爪碰撞几何与物体表面的空间关系，比“夹爪中心离物体中心多远”更有意义。

例如，若夹爪一直明显高于物体，且可核验的几何形状没有接近，就可以提出“未建立操作位置”的候选解释。

但必须守住边界：

- 几何接近不等于已经接触；
- 离散采样时刻分离，不等于两个采样时刻之间没有接触；
- 没有接触对信息时，不能声称已排除其他机械臂部件或物体的作用。

**因此，P2可以先定位“接近阶段”或“接近后的阶段”，不必一开始就知道完整接触力。**

## P2-B：区分随机动作变化与输入变化

如果轨迹中确实出现反复往返或动作方向切换，再进行下面的模型测试。

对同一段保存的观察序列，设置四个条件：

| 条件 | 当前观察 | 扩散采样随机数 | 用途 |
|---|---|---|---|
| A | 固定同一帧 | 固定 | 测重复计算的数值基线 |
| B | 固定同一帧 | 改变 | 测模型自身的采样变化 |
| C | 随实际序列变化 | 固定对应噪声 | 测输入变化引起的动作变化 |
| D | 随实际序列变化 | 按原方式变化 | 测正常使用方式下的综合变化 |

这里的“固定随机数”应覆盖完整采样过程，而不只是固定一次初始化种子；批量大小、槽位和预处理也要登记。

### 这项实验回答什么？

- **固定画面时就会产生差异很大的方向：** 随机采样是动作变化的来源之一。
- **固定随机数后，轻微画面变化仍带来很大动作变化：** 输入敏感性值得关注。
- **生成动作稳定，但实际夹爪长期无法形成操作：** 优先检查接近位置、动作可执行性或控制响应，不继续归咎于采样切换。

多模态策略产生不同动作本身并不是缺陷。只有这种变化与实际无效往返、接近中断或目标损失形成一致证据，才值得进一步检验其负面作用。

**这项测试是在分离动作变化的来源，不是给策略设计一个“固定噪声新方法”。**

# 四、正常接近对照怎么处理，避免再次全部卡住？

上一轮从成功轨迹中找严格匹配片段，最终合格对照为0；这只能说明那套匹配方法没有获得可用对照，不能说明所有无进展片段都正常，也不能说明它们都异常。RESULTS

下一轮采用三级证据：

**一级：片段本身的事实。**  
能否确认夹爪高度、往返、靠近过程、物体运动及后续恢复？这不依赖外部正常对照。

**二级：同回合前后对照。**  
在同一回合中，对比此前确实产生进展的操作片段与当前片段。状态不同，所以仅帮助定位差异，不声称严格因果。

**三级：其他回合的正常参照。**  
尽量匹配剩余目标数、距离、操作阶段和可见条件；不够匹配就明确限制，只作描述性参考，不计算所谓“异常增加了多少”。

不再将第三级缺失设为P1、P2全部停止的理由。**真正的因果问题交给随后预先定义的区分性实验，而不是指望从旧数据中找到两个完全相同的世界。**

# 五、何时才做新的区分性实验？

第一阶段结束后，最多选择**一条证据最具体的路径**，不同时测试编码、记忆、恢复、限速等多种方案。

| 第一阶段得到的线索 | 下一步应检验什么 |
|---|---|
| 目标在编码中没有可靠表达 | 先在新图像和合法目标变化中复核编码问题，不直接更换编码器 |
| 目标表征清楚，但行为对目标变化不敏感 | 用相同初始场景、不同等距离合法目标，检查完整行为是否随目标改变 |
| 同一输入的采样差异，与真实往返或接近中断一致 | 设计只改变短期采样相关性的对照，保持每步闭环、控制步数和模型调用数一致，检验往返是否随之改变 |
| 夹爪持续处于无法建立操作的位置 | 针对高度、接近位置或动作可执行性提出一个具体假设，再做有限几何或动作响应测试 |
| 只是笼统“物体不动”，没有更具体的线索 | 不做推测性恢复；指出缺少哪一项测量或对照 |

这里允许干预，但要预先写明：

> **如果原因A成立，会看到什么；如果原因B成立，会看到什么；什么结果仍然无法区分。**

例如，减少采样变化后，如果动作更一致却仍完全没有接近物体，就不能说“采样不稳定是主要原因”；它只改变了一个表面行为。

**不要求一个实验同时排除所有原因，但必须比实验前少一个明确的不确定性。**

# 六、样本、资源和执行顺序

以下是建议的上限，不是对耗时或统计功效的保证。

| 阶段 | 工作 | 建议规模 |
|---|---|---|
| 旧数据分析 | P1表征检查、P2空间时间诊断 | 77回合建立索引；重点分析约12个代表回合 |
| 必要补测 | 记录缺失的逐步RGB、DLP、生成动作序列、夹爪姿态与随机状态 | 最多6个新完整回合，原则上3C/6C各3个 |
| 区分性验证 | 只验证一个最有依据的问题 | 最多12个新完整回合，集中为两条件匹配设计 |
| 总预算 | 所有GPU自检、推理、补测、验证及失败排错 | **2 GPU小时、任务合计12 GiB显存** |

建议预算分配为：模型离线诊断0.4 GPU小时、必要补测0.5、区分性验证0.9、安全与退出余量0.2。实际规模须根据结果不可见的资源试运行确定。

补测中应保存**实际使用的表征和实际生成的动作序列**，而不仅是每十步图片。旧图像重新编码只能覆盖保存时刻，不能补造中间的真实模型状态。

P1、P2的旧数据分析和冻结模型测试可并行；不相互依赖的新场景也可并行。验证必须等待对应假设和条件冻结。不同回合、随机流、批量槽位及输出目录隔离，避免再次把批量变化导致的采样差异误当作同轨迹复现。

这轮样本用于机制筛选，不能据几个回合声称跨训练种子稳定性。重复采样8次也不是8个独立任务。

## 七、本轮最终应该交付什么？

不再用“分析了多少条轨迹”作为主要成果，而是给出下面这张定位表：

| 环节 | 实际观察 | 能排除或削弱什么 | 尚不能区分什么 | 下一步是否值得投入 |
|---|---|---|---|---|
| DLP视觉表征 | 具体对象、具体时刻的证据 | 编码侧某些简单解释 | 编码与控制因果联系 | 保留/停止 |
| 目标条件使用 | 同当前观察、不同目标的响应 | 完全不使用目标等解释 | 合理共同动作与错误条件使用 | 保留/停止 |
| 动作采样 | 固定输入与变化输入下的分布 | 随机性或输入敏感性的部分解释 | 对实际失败的贡献 | 保留/停止 |
| 接近与执行 | 夹爪—物体—目标的时序关系 | 原地受限、往返、正常接近等区别 | 接触后的动力学原因 | 保留/停止 |

**总体建议：P1从“六物体分数低”深入到模型的信息处理；P2从“物体不动”深入到夹爪的实际行为。两者最后在同一片段上汇合：模型接收了什么信息，生成了什么动作，这个动作为什么没有产生进展。**

本轮不把P3接触接口修复作为前置任务，也不提前设计提高成功率的模块。只有上述证据指出一个具体、可检验的机制，才为下一轮算法设计提供依据。
