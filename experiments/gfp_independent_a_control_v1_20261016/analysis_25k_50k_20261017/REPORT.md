# 独立 A：25k→50k 能力退化的只读分析
日期：2026-10-17。范围：已有 200 条评价记录、完整 5k 探针曲线、25k/50k 冻结检查点；新增训练、回合、环境步均为 0。

## 结论
没有触发的是“起点相对价值抬升且历史动作梯度放大”的特定报警，不能据此认定价值判断始终正确，更不能保证部署策略能力保持。
本次退化同时涉及起点无法离开、离开后的低进展和末段未完成；并非全部重现旧的起点价值岛。

**唯一优先验证的解释：TD 参考支路受到约束，但在线 Actor 与 VaBC 的行为仍共同变化，可能使持续推进与末段纠偏的执行能力退化。** 检查点支持“在线行为变化而参考变化较小”，轨迹支持“推进能力丢失”；二者之间的因果连接尚未验证。不能把动作变化大小直接当作动作变坏，也不能据此排除局部 Critic 错误。

## 配对回合：究竟在哪里失败
25k/50k 各 100 回合，初始观测哈希逐回合一致，随机协议相同；这不等于完整模拟器状态逐位重放。
成功率 37%→24%，平均 Return −1798.85→−1856.27，终点在起点区 18%→34%。
29 条成功→失败、16 条失败→成功、8 条均成功、47 条均失败。不能只看退化的 29 条而忽略 16 条改善。

| 29 条退化回合在 50k 的表现 | 数量 | 最后 400 步采样位置直径≤1米 |
|---|---:|---:|
| 所有保存位置均未离开起点区域 | 10 | 10 |
| 已离开，但未接近目标 2 米内 | 12 | 6 |
| 曾进入目标 2 米内，仍未完成 | 7 | 0 |
| 合计 | 29 | 16 |

起点区沿用原矩形 −2≤x<6、−2≤y<6。2米仅为探索性“接近目标”阈值，成功要求约0.5米；改为1米有3条，3米仍为7条。保存间隔20步，无法排除采样间短暂进出。
退化回合第200步相对初始位置的位移中位数从5.34米降至3.47米，但位移不是正确路线进展。已离开者的首次采样离开时间中位数从300步变为380步；两点的“已离开”子集不同，仅为描述。
16条末段低移动包含全部10条起点停滞和6条中途停滞；接近目标的7条没有同一低移动现象。因此不能把所有失败统一解释为完全不动或跌倒。

起点滞留增加16条的来源：
- 29条退化回合：0→10，增加10条。
- 47条均失败回合：13→24，增加11条。
- 16条改善回合：5→0，减少5条。
- 8条均成功：均为0。
合计 +10+11−5=+16。全部100条中，25条新变为终点在起点、9条脱离原起点滞留。保存的位置显示34条最终起点滞留均没有采样到曾离开，而非先出去后回来。

逐回合清单见 episode_comparison.csv，包含全部四组；图见 paired_paths.png。原评价只保存每20步的位置及终点，没有完整观测、姿态、关节动作和模拟器状态，故本轮无法判断跌倒、碰撞、首个错误动作或精确恢复这29条失败状态。

## 完整曲线为什么没有报警
固定原300k历史锚点，单探针同时要求：
1. 起点相对全局Q差增量≥15；
2. 固定历史动作处梯度范数比≥2。
连续两个5k探针满足才判联合异常。

0–50k共11点的Q差增量为−13.358至−12.245，梯度范数比0.697至0.987，联合条件没有一次满足。25k→50k分别为：
- Q差增量 −12.262→−12.278，基本未变；
- 梯度范数比 0.987→0.835，没有放大；
- 相对300k动作梯度方向cos 0.183→0.203。两者相对旧锚点都不高，但没有证据说明此区间又发生普遍方向翻转。

完整曲线沿用 reports/RESULTS.md、reports/full_curves.png，未更换锚点或修改门槛。
报警检测的是特定价值异常，不是同状态动作排序、姿态控制或连续决策鲁棒性的充分检验。行为崩塌的原定义（成功≤5%且起点滞留≥90%）也未触发，但较强收益标准未通过，不能称为修复成功。

## 冻结检查点：什么变化了，什么没有
使用既有4032个离线查询状态、两份相同固定噪声，分别计算在线Actor、VaBC和TD参考Actor；输入未按回合结果挑选。以下重点展示独立验证split（起点960、非起点1024状态）。RMS以动作维及查询样本共同平均，动作范围[-1,1]。

| 25k→50k指标 | 起点 | 非起点 |
|---|---:|---:|
| 在线Actor动作变化RMS | 0.12809 | 0.13120 |
| VaBC动作变化RMS | 0.13119 | 0.13309 |
| TD参考Actor动作变化RMS | 0.00443 | 0.00524 |
| Actor与VaBC动作距离RMS，25k→50k | 0.14394→0.14416 | 0.14662→0.15202 |
| Actor不同固定噪声输出距离，25k→50k | 0.30946→0.30685 | 0.31253→0.31123 |
| Actor/VaBC变化方向平均cos | 0.366 | 0.337 |
| 两者变化方向内积为正的比例 | 90.8% | 89.5% |
| 同一25k Actor动作处，两Critic梯度cos均值 | 0.836 | 0.874 |
| 同一动作处梯度范数均值比 | 0.875 | 0.979 |
| 同一动作处Q值变化均值 | −1.295 | −1.287 |

训练split得到相近变化规模。原始Actor/VaBC蒸馏均方差在验证起点为0.020960→0.020980，非起点0.021742→0.023367。没有看到起点蒸馏距离显著扩大或随机动作多样性塌缩。因此不优先解释为“Actor单方面不再模仿VaBC”；两者有部分同向变化，但cos并不接近1，不能称完全同步。

使用同一个Critic交叉评分旧/新Actor候选：验证起点旧Critic的新减旧Q均值−0.07585，新Critic为−0.02804；偏好新动作比例分别44.9%、49.3%。评分没有给出一致显著的新动作优势；但Critic不是独立动作质量裁判，这也不能证明新动作确实更差。

这里的参考RMS是两个检查点的净差，不是500次事件的累计更新幅度。既有事件记录证明500/500足额持续更新，不能因净差小而称参考网络未更新。
上述离线查询状态不是29条回合中的完整观测；冻结推理无法定位其实际失误动作。平均Q及平均梯度稳定也不能排除少量关键状态的排序错误。

## 证据与推测
| 已有证据 | 仍不能推出 |
|---|---|
| 退化包含起点、中途和接近目标三个阶段 | 单一姿态问题、规划错误或价值岛是共同原因 |
| 所有旧联合价值探针均未报警，同动作梯度未普遍放大 | Critic在所有实际失败状态都正确 |
| 在线Actor/VaBC明显变化，参考变化较小；两者部分同向 | 在线变化必定有害，或VaBC是唯一原因 |
| 成功率净降13个百分点，也有16条反向改善 | 跨训练种子的稳定退化结论 |

配对回合bootstrap95%区间为[-26,0]个百分点，沿用既有计算；它只反映这两个冻结模型的回合波动，不包含训练重复。当前只有一个训练分叉，所有空间分组为事后描述。

## 只保留一个下一步问题
**在这些退化回合进入低进展之前，25k在线Actor是否比50k在线Actor更能持续推动机器人，而这种差异并不需要重新出现旧的价值抬升报警？**

这是对“在线执行能力随Actor/VaBC变化而流失”的直接检验。若以后另行授权，可用预先选定、验证可恢复的完整状态及配对后续随机数比较冻结25k/50k在线策略；这是短时策略替换，不是只换首动作，也不需要先设计新模块。若旧策略没有可重复优势，应削弱本解释，不能凭动作RMS继续主张共同漂移导致退化。当前没有执行新回放、训练或这种干预。
