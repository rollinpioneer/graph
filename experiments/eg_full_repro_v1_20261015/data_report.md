# 数据获取恢复记录

当前状态：正在获取完整数据，尚未放行监督、Smoke Test 或正式训练。上一阶段官方下载阻塞记录保留于原报告和 checks_history。

数据内容来自 EconomicGrasp 作者 DravenALG 账号明确标注为非官方的 GraspNet 镜像 https://huggingface.co/datasets/DravenALG/GraspNet-1Billion ，固定 revision `1f9db26044cd2a7e629bbb465be3665364cbf2bf`。服务器通过 hf-mirror.com 传输；在本机直接读取 Hugging Face 官方元数据，逐项比较 revision、大小和 LFS SHA256，与传输镜像完全一致。下载器逐段要求 HTTP 206、正确 Content-Range 和长度，最终验证官方元数据的完整 TAR SHA256。

为独立确认实际数据内容，本机匿名读取 GraspNet 官方下载页所链接的十个 Google Drive 公共 ZIP 的中央目录，不需要登录或完整下载到本机。共取得 244,862 个本实验核心文件的路径、大小、CRC32，按 379 组生成确定性摘要。选择范围为190个场景的 Kinect、100个训练场景 collision、原始 grasp labels 和88个模型。所需原始文件共127,891,287,559字节。服务器解包时计算每个文件SHA256及CRC32，再与上述官方索引核对。模型的88组、524文件已全部通过；其余组件仍在进行，不能提前声称全量一致。

解包仅写入本实验新目录，拒绝链接、特殊文件及未登记覆盖；完整校验并成功解包后清理本轮下载的对应 TAR，保留逐文件摘要和来源证据。磁盘预分配及解包均保留24GiB余量。大文件和244,862条明细留在服务器/本机原始记录目录；Git只保留分组摘要和代码。数据使用继续遵守官网的非商业研究条件，不在Git再分发数据。

生成 DexNet 缓存使用官方 GraspNetAPI 的 load_dexnet_model 读取已核验模型，再按官方脚本的 pickle 默认协议保存；未更改评测定义。

Graspness 可选场景缓存减少重复读取和求和；正式使用前必须在场景0、99的前两帧分别与未启用缓存的原路径逐元素精确比较。GPU编号由调用者映射；场景分片不改变阈值或KNN块大小。监督保存增加原子写入和摘要回执，恢复时检查摘要、形状、有限性及范围，拒绝无回执覆盖。
