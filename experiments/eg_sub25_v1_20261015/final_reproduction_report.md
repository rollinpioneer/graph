# EG-SUB25-V1：25% Baseline 评价与失败诊断完成

本轮完成开发集官方 AP、固定 Seen/Novel 场景与官方预训练模型的配对评价，以及 12 个探索性案例分析。当前成果是可信的单 seed、25% 数据轻量 Baseline；**不属于全量训练或完整官方测试划分的论文复现**。

## 训练与正确性

冻结 50 场景 × 128 均匀帧 = 6,400 帧，元数据选择，不按模型性能修改。一个 seed `20261015`，随机初始化，10 Epoch、Batch 4、Adam 0.001、20,000 点、Voxel 0.005、官方 Cosine，共 16,000 次连续更新。未增加 seed、改变模型或启动第二套配方。

环境、CUDA 扩展、监督标签、80 帧 Smoke、前向/反向/优化器和 checkpoint 门均通过。先前顺序 Smoke 的空候选 FPS 问题通过对齐官方 Shuffle/Worker 播种定位处理，仅增加明确空集报错，不做回退或改阈值。正式训练与本轮评价均未触发该问题。

训练日志损失均有限，10 个权重严格加载通过；Epoch 平均总损失 4.681914→3.267090。所有 4,608 个预测均为有限 1024×17 表示，18 组官方场景评价完整结束；保存的质量/碰撞记录逐项复算全部 native precision 完全一致。配对输入哈希相同，24 次案例回放与原始预测在预设容差内全部匹配。源码补丁哈希在评价后仍与启动时一致。

本轮外置评价驱动复用原 Dataset、模型、pred_decode 和官方 GraspGroup 序列化，适配冻结场景及相同输入缓存；碰撞阈值 0 保持官方默认，物理碰撞/力闭合评价仍由原 API 完成。没有修改评分、NMS、AP 或跳过帧。相关源代码、配置及官方函数哈希已归档。

## Bad Case 结论

在 1,024 个配对帧中，按“Top-1 无碰撞且 μ≤0.4”口径：259 帧仅官方通过，191 帧双方未通过，136 帧仅子集通过。子集/官方分别有 **450/327 帧**将未通过的候选排在后续通过候选之前；Top-1 碰撞分别有 **246/156 帧**。两个模型每帧的官方评价候选池中都至少存在一个通过候选，排序和碰撞值得优先诊断，但尚不能单独归因于评分头。

0122/0011 的子集与官方 AP 为 15.08/51.94，Top-10 碰撞为 9/1；还找到中心相同而姿态/宽度和质量不同的候选对。0189/0015 的双方 Top-1 均碰撞，说明全量预训练后仍有可分析的问题。抓取点前景覆盖、方向、宽度、候选排序及训练量仍互相混杂，未证实模块因果。

**重要数据发现：**0188 的 109–255 帧重复、全场景仅 110 种不同 RGB/深度/分割/Meta 和位姿；0189 的 170–255 帧重复，仅 171 种观测。逐文件重新计算的大小/CRC 清单与官方 ZIP 索引一致，未发现本地损坏。维持原 256 帧 AP 和冻结选帧，不去重改分。0188 的同一观测对应不同点采样，子集 AP 19.24–58.06、官方 31.94–64.20；没有分离采样与数值因素。该场景选中的三个案例实为一个观测的三次采样，不能作为视角/遮挡变化证据。

详细证据、案例图及解释边界见 [bad_case_report.md](bad_case_report.md)。12 张图均通过文件解码检查，已实际查看覆盖四场景的五张代表图；不是声称逐张人工审阅全部 12 图。案例为探索性事后选择，非无偏因果证据。

## 成本与资源

正式训练实测 **10,322.36 秒，约 2 小时 52 分钟**，GPU 1 单卡共享；Torch allocated 峰值 2.562 GiB，驱动采样自有显存峰值 3,656 MiB，进程组 RSS 峰值 4.690 GiB。

本轮五组预测墙钟合计约 405 秒；CUDA forward+decode 平均约 22–47 ms/帧，随模型分组和共享负载变化，仅作运行记录。官方 AP 两阶段墙钟合计 **6,598.89 秒，约 1 小时 50 分钟**，四个 Nice +10 CPU 进程、每进程 BLAS/OpenMP 单线程；采样进程组 RSS 峰值约 18.94 GiB。

推理和回放使用获准共享的 GPU 0，记录了其他进程负载。回放前全设备 NVML 查询短暂等待后自行恢复；没有中止其他进程。回放短任务的资源采样未覆盖 GPU 执行，回执中的 GPU 0 MiB/RSS 小值不是实际执行峰值，不据此声称零占用。推理组另有 Torch 分配峰值记录。未建立定时监控。
