# 条件卡 C：持续移动与末段修正的动作组织
日期：2026-10-15。状态：保留为已有资产支持的机制问题；尚不能把时间组织认定为缺陷。

| 字段 | 核查结果 |
|---|---|
| 条件定义 | 导航过程需要持续移动，接近目标需要有效局部修正；这是同一现有任务内的阶段差异。训练数据与部署均可能包含，但尚未在训练数据中完成阶段覆盖统计。 |
| 原方法边界 | 固定 GFP 每个环境步接收新观测、重新采样一个动作；one-step Actor 是生成计算方式，不等于只看即时收益，也不等于开环执行长 action chunk。不能说它“不能及时反馈”。 |
| 数据证据 | OGBench1.1.0 HumanoidMaze-medium navigate singletask task1；本项目已有冻结 G0 seeds0/1 1M权重、48完整轨迹和12状态36分支。本轮9,481步完整数值记录可定位。原版输入69维、动作21维、dt0.025s、成功半径0.5m、最长2000步。 |
| 本轮实际发现 | 8个失败状态中4个由单次首动作替换获得300步内成功，Actor重采样和VaBC各2个；其中2个状态平均Q最高候选未成功。12个A分支逐步恢复误差0。 |
| 可验证预测 | 若时间组织确为问题，匹配状态下应持续出现动作随时间的冲突/承诺过长或不足；仅改一个动作的现象不能区分这些原因。后续先检验多噪声后续下局部救回是否稳定。 |
| 简单替代解释 | 随机提案差异、局部价值排序、姿态/速度、数据覆盖或普通控制设置，可能已经解释。不得预先归因于记忆、规划、Actor精度或蒸馏。 |
| 最近邻工作 | Adaptive Q-Chunking 按阶段选择动作承诺长度；MAC 在离线模型式RL中使用动作片段动力学和价值扩展。它们与“动作时间组织”相关，但前者含offline-to-online设置，后者改变模型式价值学习，不能当作等价GFP替换。 |
| 最小后续试验 | 候选为本轮4个局部救回状态，先冻结多个共同后续噪声序列，区分单次提案偶然性与持续排序不一致；如仍指向时间组织，再比较简单平滑/固定执行周期与候选机制。所有新增回放或训练均需下一卡，不在本轮自动执行。 |
| 退出条件 | 多噪声证据不支持时间组织问题，普通采样/控制处理已解释，或候选改动只复现已有chunking机制，则停止该模块方向。 |

证据：[GFP v2](https://arxiv.org/html/2512.03973v2)、[固定 GFP 源码](https://github.com/Simple-Robotics/guided-flow-policy/tree/1abbd5f0e287caf9bda70e7bc655d0a499ac8401)、本轮 MECHANISM_REPORT.md / branch_results.json。

[Adaptive Q-Chunking v1](https://arxiv.org/html/2605.05544v1) 明确讨论自由移动与接触阶段的不同承诺长度，因此“不同阶段用不同时间尺度”不能直接作为新贡献。[MAC v1](https://arxiv.org/abs/2512.08108v1) 利用 action-chunk 模型缓解长步预测误差并做模型式价值扩展，属于需要区分的已有机制，不是本轮验证对象。

当前更窄、已有实证支撑的问题是：同一冻结 GFP 在部分状态能够生成有效替代动作，但单次执行提案及 Critic 的均值排序并不总与所观察的短期效果一致。没有证明长期期望Q排序错误，也没有证明加入动作分块会修复它。现有近目标案例不是新数据集或新现实条件。

后续公平对照要同时保留原条件/候选困难条件、合理适配原版/简单处理/候选机制；若无法构造严格匹配条件，只能报告分层关联，而不能宣称单因素因果实验。原版必须保留必要输入及合理调参机会。
