# 条件卡 A：延迟系统中“已有历史未被充分利用”
日期：2026-10-15。状态：筛查完成；不批准新训练。当前不支持“Pipeline 缺历史，所以给 GFP 加记忆”的立项理由。

| 字段 | 核查结果 |
|---|---|
| 条件定义 | 动作的影响经过输运后才出现在出口流量；训练数据与部署模拟器均包含延迟。候选问题应是对完整历史的利用，而非假设历史不存在。 |
| 原方法边界 | GFP 接收当前输入向量的 MLP 可以读取其中已展开的历史；一步 Actor 指采样计算形式，不是只优化即时回报。当前没有在 Pipeline 运行 GFP，不能声称发现其能力缺陷。 |
| 数据与任务 | 官方 Pipeline；验证集实读 20,000 转移、20 条各 1,000 步轨迹。obs/next_obs 为 (20000,52)，action 为 (20000,1)，包含 reward/done/truncated。官方 MD5 一致。训练集和模拟器运行兼容性本轮未验证。 |
| 轨迹边界 | 实际 NPZ 没有 README 声称的 index；20 个 truncated 恰在 999,1999,…,19999。done 全 0；跨边界外 next_obs 与后续 obs 完全一致。未来序列采样必须据此隔断，不能把 timeout 当真正吸收终止。 |
| 已有信息 | 默认输入为出口流量、目标流量、25 个历史出口流量和25 个历史动作，共52维。两个历史序列逐行移位误差0，最新动作写入误差0。 |
| 可验证预测 | 只有在保留全部输入的合理 GFP 仍反复混淆需要不同操作的控制情境，且这种混淆可由历史表示/共同状态编码改善，才形成方法假设。不能只比较分数。 |
| 简单替代解释 | 历史已充分，只是尺度归一化、任务超参数、有限数据或普通历史编码问题。应先对照完整输入 MLP、简单按时间编码/循环网络，给相当调参机会。 |
| 最近邻工作 | NeoRL-2 已定义延迟基准；Ni 等 ICML 2022 已展示合理实现的 recurrent model-free Actor-Critic 可成为强基线。“加 RNN”本身不构成新贡献，且该工作不等于离线 GFP 已复现。 |
| 最小后续试验 | 先解决下面版本差异并固定训练数据、环境；完整输入 GFP 与一个简单历史基线对照，按控制状态/目标变化分层测量 Q 排序、动作响应及滞后。这需要另定训练卡，本轮未执行。 |
| 退出条件 | 原始完整输入已能解决问题、简单处理可解释收益，或数据/环境身份仍不一致，则停止新增记忆模块方向。不得删去已有历史制造缺口。 |

证据：[固定 Pipeline 源码](https://github.com/polixir/NeoRL2/blob/b50d91d0a65916a89342a4f6978188b17cb2d97a/neorl2/envs/pipline.py)、[官方加载器](https://github.com/polixir/NeoRL2/blob/b50d91d0a65916a89342a4f6978188b17cb2d97a/neorl2/envs/base.py)、[NeoRL-2 v1 附录B](https://arxiv.org/html/2503.19267v1)、[recurrent 基线](https://proceedings.mlr.press/v162/ni22a.html)。

## 必须登记的来源差异

1. 论文 Table 5 描述25步延迟；固定代码 channel_length=100、pipe_velocity=5，建立20槽位队列。不要把25条历史长度自动当作物理延迟。
2. 对官方验证集逐行检验，按代码推导的 next_flow = clip(current_flow + history_action[18],0,200)，平均绝对误差 2.064e-6、最大7.629e-6；history_action[23] 的平均误差0.01173、最大0.58706。这个索引检验支持当前代码的移位语义，不能替代完整模拟器准入。
3. 同一论文 Table 4 为 Pipeline train100000/validation20000；Table5又说20条×1000步。实读文件明确是 validation 的20条；没有据此宣称训练集仅20条。
4. README 写 index，当前加载器按 done/truncated 切分，实际验证数据也采用后者。
5. RandomFrictionHopper 固定源码将 friction_value 附加到观测，不能描述为完全隐藏摩擦。此项只读代码核查，没有增加第二套实验。

从20槽位队列及历史增量规则可以推导：忽略浮点量化，当前出口值与最近19个动作已可递推队列内流量；现有25步动作历史并不显然缺少这个信息。实际输入为float32，需保留数值容差。这是基于代码的结构推断，不是 GFP 学会该关系的实验证据。
