### 需要限制的审查结论

1. “旧场景均值大于 0、两个种子为正”只是预算放行规则，不是严格统计非劣性检验。
2. NQS-A 与 S 的差异同时包含监督支持、动作标签数量、有效重复次数及选模差异；不能把性能差异直接归因于一个因素。
3. 组间/组内 MSE 的数学分解成立，但“全局排序只需组间项小”过强：原动作的实际质量还包含它偏离本组均值的部分。本卡不把该解释当作定论。
4. 低姿态修改率限制了此前 2×2 对所有姿态方法的外推；Gdelta 未训练差值损失，因此其阴性不是 H1 的阴性。
5. 在前 200 个候选中按真实质量逐个择优，再重做 NMS，不是所有部署策略的严格全局 AP 上界；低 Oracle 增益不能直接证明所有局部选择无价值。本卡不以它作必经门槛。
6. 参数量较少、跨硬件时间较短不等于已证明端到端快一个或两个数量级；先测本方法实际延迟即可。

以上是对来源的审查与新决策，不把不同意见默默合并为已经达成的实验事实。

## 4. 第一版方法及唯一备选

### 4.1 共同输入与结构

EG 原始点云处理 → 原始 1024 候选与中间特征 → 评分模块 → 按既有部署 CD 处理 → 官方完整选择与评测。

对候选 i，特征为：

`x_i = [f_group(256), f_score(64), sin(2θ_i), cos(2θ_i), d_i/0.04, w_i/0.1]`。

轻量头保持 `Linear(324,128) → ReLU → Linear(128,1) → Sigmoid`，41,729 参数。只计算原动作的 Q，不生成 6 个或 48 个姿态，不启用 τ、κ 或局部替换。

固定中心、接近方向、角度、深度、最终宽度、高度、候选 ID。统一官方宽度截断在评价适配层保持与基线一致，不覆盖原预测。每帧最终仍提交原始 1024 个候选，不增加数量。

### 4.2 三组定义

|组别|评分|角色|
|---|---|---|
|R0|原 EG 分数 s|不训练基线|
|S|q = Q(original)|主方法|
|F05|0.5 z(s) + 0.5 z(q)|本轮新增、固定融合备选|

`z(v_i) = (v_i - mean(v)) / std(v)`，统计范围为该帧原始 1024 个候选，先于 CD 和 NMS，std 使用 ddof=0，float64 计算。不同头各自使用其 q；不跨帧、不使用 GT、不要只对旧 Top-50 标准化。

若 s 或 q 的 std < 1e-6，该帧 F05 退回原 EG 分数并记录。NaN/Inf 是技术错误，不用退回掩盖。系数 0.5 固定，不测试 0.25/0.75，不按帧或场景动态调系数。融合不是 Gdelta，不使用新旧姿态差值。

F05 只是假设性稳健备选；不保证降低 Top-1 风险或优于 S。S+CD 有正向证据；F05 还没有本项目实测。[S1]

### 预先指定的选择规则

## 8. 评价与统计

### 主指标

`ΔAP = AP(selected_family + CD) − AP(R0 + CD)`。

对每场景先平均三个配对头差，再在 Seen/Similar/Novel 内场景等权，三个划分等权。按划分分层重采样场景，10,000 次 bootstrap，种子 20261019。

### 拟定确认标准

同时满足才记 `AP_CONFIRMED_TARGET`：

- 平均增益 ≥ 1.0 AP 百分点；
- 场景分层 95% CI 下界 > 0；
- 三个头各自总体差均 > 0；
- 至少 8/12 场景的三头均值差 > 0。

这些是本卡拟定的实验目标，不是公认科学临界值或录用标准。用户目标是搭方法，不要求把未达 1 点但可信的较小收益写成“完全无效”：

- 均值为正、CI 下界大于 0，但未满足全部目标：`LIMITED_GAIN`，较小/不完整增益，不改标准追认主成功；
- 95% CI 上界小于 0：`NEGATIVE`；
- 预定 90% CI 全落在 [−0.5,+0.5]：可称本设置下差异较小，不等于普遍等价；
- 其他：`INCONCLUSIVE_OR_NOT_TARGET_REACHED`；
- 数据/几何/缓存/资源失败：`TECHNICAL_STOP`，不输出科学否定。

不把相邻帧、头种子×场景当作独立样本。次要区间为描述性、不以其中最好一个代替主指标。

### Top-1 与实际风险单独报告

报告 AP0.4/0.8、Top-1 合格率（原生 0<μ≤0.4）、Top-1 碰撞/空抓、Top-50 碰撞率、候选 CD 拒绝率、逐划分与逐场景差、失败→成功及成功→失败数。

原动作不变，本轮 Top-1 变化来自“选了另一个候选”，不是同 ID 的姿态修复。AP 改善不能直接称机械臂成功率改善。若 AP 达标但 Top-1 下降，结论标为“AP 提升、首选可靠性存在权衡”。只有相应独立指标支持才能称 Top-1 改善。

原协议保留完整帧；额外按原始观测身份做去重敏感性，不按预测挑帧。

## 9. 评测实现与缓存规则

所有新分数均作用于原始 1024 个候选；必须重走原生 NMS、物体分配/筛选和官方质量评价，不能只重排旧 Top-50 冒充应用结果。

CD 参数沿用 `collision_thresh=0.01, approach_dist=0.05, voxel_size=0.005`。S/F05/R0 的几何相同，CD 标记应一致；该核验可廉价识别错误。评分导致 NMS 选择不同是预期现象。

候选质量缓存至少绑定骨干、场景/帧、输入、candidate ID、完整几何和评价版本身份。只补算新排名需要而缓存中缺少的候选；缓存缺失、计算异常不等于质量零。新场景点云采样按固定规则生成并保存身份，不能不同头重新抽点。推理不依赖官方物体分配身份；该身份仅在官方评价器内部使用。

同序缓存重放不等于真机实时性。方法延迟应同时报告单独评分头耗时和同设备完整 EG / EG+score / EG+score+CD 路径，固定输入/批量、预热、GPU 同步，给中位数和 P95；不得把跨硬件数字除出“快若干倍”。
