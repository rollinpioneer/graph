## 问题和边界

比较已有 L0、L1a、L1b 的 0–50k（每 5k）冻结参考 Actor，在相同数据状态、相同标准正态输入上的条件行为支持。原 GFP 参数更新 0，环境构造/reset/step 0；不追加原实验训练、评价或分支。密度分数不是动作正确性，也不是长期优势。

L0 来自 gfp_midwindow_td_freeze_v1_20261016；L1a/L1b 来自 gfp_midwindow_td_split_v1_20261016。检查来源 checkpoint JSON 的 SHA 和更新数，前后哈希不变。历史异常曲线只在独立评估器验证后用于关联分析。

## 独立评估器（预先冻结）

不使用任何 Critic、Q、Guidance 或 VaBC 权重。原始 OGBench navigate 数据，所有非 terminal 转移，动作裁剪与宿主一致。拟合条件高斯混合密度：8 分量、两层 256 ReLU、对角标准差 exp(clip(logstd,-4,1))、tanh 均值。全 69 维观测用训练数据均值/标准差归一化。两个拟合种子 1701/1702，每个最多 15,000 Adam 更新，batch 512，lr 0.0003；每 1,000 更新检查校准集平均 NLL，保存最低者。总监督模型更新上限 30,000，与 GFP 更新严格分开。

官方 100 条 validation 轨迹按奇偶分成 50 条校准和 50 条独立测试；不按相邻状态随机拆分。模型只用原始 train 1000 条轨迹训练。校准集固定 8192 状态，测试固定 16384 状态。评估实际数据动作、跨状态置换动作、均匀随机动作。负对照不是已知错误动作，仅检验模型是否学习条件结构。

另检查 task1/task4 已登记的绕行进展、完整路径片段和实际转弯片段，仅用独立测试轨迹。它们是观测到的行为支持正例，不宣称单步最优或专家动作。每类最多 2048，记录轨迹数。每个区域在校准实际动作上取 95% NLL 分位阈值；报告稀有正例误拒率，不能把稀有但真实动作自动称为 OOD。

最低可靠性筛查：两模型均有限；真实动作对均匀动作 AUC>=0.90、对置换动作 AUC>=0.65；每类至少 5 条测试轨迹才作粗粒度可靠性判断，若正例误拒率>20%，标为该类评估器不可靠。阈值是本轮操作标准，非理论保证。不通过不搜索新架构或扩大训练。

## 冻结参考动作测量

train 与独立 test 各选 1024 起点、1024 非起点状态，共 4096；每轨迹每区域最多 32 个，排除 terminal 及首状态，保证可作为 TD 下一状态且有实际数据动作。起点区域沿用网格 (1,1),(2,1),(1,2),(2,2)。统一两组固定高斯噪声；所有臂/检查点完全配对。主推理 33×4096×2=270336 状态动作。报告每维 NLL、相对同状态真实数据动作的 NLL 差、95% 尾部比例、变化幅度；两模型和两组噪声分别报告。

按轨迹聚类自助法报告相对 0k 的变化区间。L1a 恒定只是实现检查，不是支持假设的独立证据。L0/L1b 在 +25k 的行为已明显下降，故 +25k 以后的支持变化不能宣称先于行为恶化；既有联合异常首次点 L0 +45k、L1b +40k。0k 已是全局 350k，不能覆盖更早形成过程。

## 裁决

可靠评估器下，两个崩塌分支在 +5–20k 都持续恶化、L1a 不变，才构成进一步数据约束干预的候选证据；仍是相关，不是成因证明。若可靠评分没有对应变化，不优先推进该方案。若评估器不可靠或结果依区域/模型变化，结论 DIAGNOSE/无法裁决。不得把一个训练状态和两个密度拟合种子写成跨训练种子结论。

预算：单卡共享、监督模型最多 30k 更新、GFP 0 更新、环境 0 步，无 GPU 小时上限；只读检查脚本可必要修正，失败计算成本保留。不修改旧权重。轻量代码/配置/报告/图表/回执归档；模型和数值数组留服务器。

采样前修订：独立测试起点区域在每轨迹32状态限制下仅960个；保留原轨迹上限，不重复补样。实际总4032，参考动作推理266112。修订发生在行为模型拟合及任何目标分支评分前。首次准备失败10.17秒，零模型更新，保留日志。
