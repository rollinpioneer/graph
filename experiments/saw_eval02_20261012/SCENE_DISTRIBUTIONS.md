# 随机场景与失败轨迹分布比较

事后实测 1000 组同 task/episode/stream 索引：位置+目标完全相同 1000；完整 qpos+qvel+目标相同 0；后续位置、动作、奖励和判定逐元素相同 1000。这些是对保存数据的核验，不是以同种子假定配对。完整初始速度不同的场景不能称完整初态匹配对照。

各条件/任务/流的坐标、初始速度、目标、起点距离、任务中心偏移的均值、SD、5/50/95 分位、KS 与标准化均值差在 B_SCENE_DISTRIBUTIONS.csv。KS 仅描述、不作机制证明；相同分布不等于相同有限场景。初始化 RNG 哈希在每个 B_<model>_<condition>_<stream>.csv，完整随机状态保存在对应原始 pickle。

源码解释：Maze.add_noise 从全局 NumPy 取 XY 和目标噪声；主比较两条件持有相同全局流，reset(seed) 只重置内部生成器。PointEnv.step 每步先将 qvel 置零，再推进 MuJoCo；模型观测为 qpos。若本次不同初始速度没有改变后续轨迹，这符合该具体控制实现，而不是所有 OGBench 系统的普遍等价。
