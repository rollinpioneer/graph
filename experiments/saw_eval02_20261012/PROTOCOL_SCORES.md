## 极端成功率单元的区间边界

全成功或全失败单元的经验二项 bootstrap 无法生成未观测结果，因而差区间可能退化为 [0,0]；这不是零总体不确定性，也不是所有随机流严格等价的证明。逐条件 Wilson 区间仍保留边界不确定性。补充、未预登记的 Wilson-score 非配对差分敏感性区间在 B_TASK_SCORE_DIFFERENCE_SENSITIVITY.csv，不替代原 bootstrap 主判定，不据它挑选更有利的结论。对于双方 100/100 或 0/100 的任务，该补充差区间约为 ±3.7pp。
