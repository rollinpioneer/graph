# EG-SUB25-B-F05-REPL-V1 实验计划

**状态：执行中；用户已于2026-10-19授权**  
**研究目标：跨25%训练数据子集复现F05性能提升**  
**优先级：性能验证与工程复现；暂不增加新模块**

## 1. 实验背景与核心假设

上一阶段，F05在25%数据训练的EG骨干A上取得以下结果：

- C2确认集：EG+CD = 45.895 AP。
- EG+F05+CD = 48.497 AP。
- **提升+2.602 AP**，95% CI为[+1.893, +3.386]。
- 三个轻量头均正向，12/12场景提升。
- 不需要修改抓取姿态，只替换全局排序分数。

上述结果已通过原预注册标准，但目前只验证了一个EG骨干。

**核心假设H1：** F05的排序收益不完全依赖于原25%训练子集。使用另一组互不重叠的50个场景训练EG，并重新训练配套轻量头后，仍能够在未参与方法选择的测试场景获得正向AP提升。

本实验不验证50%训练数据的效果，不研究局部姿态重选，也不改变F05结构。

## 2. 实验组设计

| 组别 | EG训练数据 | 轻量评分头 | 作用 |
|---|---|---|---|
| A-EG | 原50场景 | 无 | 已有骨干基线 |
| A-F05 | 原50场景 | 已训练的3个头 | 已确认方法的同场景参照 |
| **B-EG** | 另一50场景 | 无 | 新骨干基线 |
| **B-F05** | 另一50场景 | 重新训练3个头 | **主要研究对象** |

**本次实际新增训练：1个完整EG骨干＋3个轻量评分头。**

所有组分别报告带CD和不带CD的结果。不同骨干的候选不能共享抓取质量缓存。

主比较：

\[
\Delta_B=AP(B\text{-F05+CD})-AP(B\text{-EG+CD})
\]

次要比较是在同一批测试场景上计算：

\[
\Delta_A=AP(A\text{-F05+CD})-AP(A\text{-EG+CD})
\]

比较两个增益的方向和稳定性，不能直接把B的绝对AP高低当作F05有效性的证据。

- B的旧开发10场景现在属于B训练集，**不能再作为B的未见场景验证材料**。

实际执行前，读取原始冻结文件生成B的完整50场景清单，核对交集为空、并集数量为100，保存划分哈希。不能根据模型表现重新挑选场景。

## 4. 新轻量评分头的训练

### 4.1 为什么必须重新训练？

新EG骨干的特征分布、候选抓法和原始评分可能改变。

因此B-F05必须使用B骨干生成的数据，重新训练对应的小评分头，不能直接拿A的评分头作为正式B-F05。

### 4.2 轻量头训练场景

为了与A方法保持可比，B的轻量头训练场景必须来自**B骨干未参加训练的官方训练场景**。

具体使用原A的50个骨干训练场景作为候选池，而不是直接复用A轻量头的24个fit场景，因为后者已被纳入B骨干训练。

建议以固定种子20261020、不参考预测或AP结果，提前将这50个场景划分为：

| 用途 | 场景数 | 作用 |
|---|---:|---|
| Fit | 24 | 训练小头 |
| Model-val | 4 | 计算质量预测诊断 |
| Gate-cal | 4 | 保留与V1匹配的校准数据规模 |
| 开发预留 | 10 | 检查B骨干、工程调试 |
| 其他预留 | 8 | 不参与本轮模型选择 |

以上拆分共50个场景。执行前冻结具体ID和哈希；Model-val和Gate-cal不用于按测试AP选权重或修改F05系数。

### 4.3 标签生成

严格复用Pose Select V1的监督配方：

每个fit/cal场景取8帧，每帧从EG生成的1024个候选中选128个：

- EG原分数最高的64个。
- 从剩余候选中确定性随机抽64个。

每个候选生成Top-3角度×Top-2深度，共6个姿态，用官方完整几何计算实际质量。

\[
32\text{场景}\times8\text{帧}\times128\text{候选}\times6\text{姿态}
=196,608\text{标签}
\]

质量定义、无效值、夹爪宽度处理及对象碰撞评价保持V1一致。

训练和校准可使用真实几何标签，但推理评分不得读取GT几何、摩擦质量或对象身份。

### 4.4 小头网络和训练

| 参数 | 配置 |
|---|---|
| 输入 | EG的320维共享特征＋4维姿态参数 |
| 网络 | Linear(324,128)→ReLU→Linear(128,1)→Sigmoid |
| 参数量 | 41,729 |
| 损失 | 六姿态效用MSE |
| 优化器 | AdamW |
| 学习率 | 0.001 |
| Weight decay | 0.0001 |
| Batch | 128个候选组 |
| 更新次数 | 1,000 |
| 随机种子 | 20261018、20261019、20261020 |
| 使用权重 | **固定第1,000步** |

归一化统计只从B的fit样本计算，不复用A的特征均值或标准差。

本轮不加入Ranking Loss、相对质量差损失、FiLM或姿态重选择。

## 5. F05方法保持完全一致

每个新骨干的1024个原始抓取候选，先分别获取EG原评分与对应小头评分。

最终分数：

\[
s_{\mathrm{F05}}
=0.5z(s_{\mathrm{EG}})+0.5z(Q(g_{\mathrm{original}}))
\]

其中，\(z\) 是同一帧1024个候选上的标准化。

复用V4的精确实现，包括float64、总体标准差（ddof=0）及既有边界处理。

固定条件：

- 融合系数永远为0.5。
- 不修改抓取位置、方向、角度、深度和宽度。
- 不组合三个小头进行集成。
- 不使用测试数据训练或标定。
- CD保持 `collision_thresh=0.01`。
- 每种分数都必须由全部1024个候选重新执行官方选择和NMS。

## 7. 统计与成功标准

主要统计以场景为独立重采样单位：

- 每场景先计算三个种子的配对AP差。
- Seen、Similar、Novel各4场景，三个划分等权。
- 按划分进行10,000次场景bootstrap。
- 同时报告三个头的差值，不能把种子×帧当作独立样本。

**拟定主要成功标准：**

| 条件 | 要求 |
|---|---|
| B-F05平均AP增益 | ≥1.0个百分点 |
| 95% CI下界 | >0 |
| 三个轻量头 | 各自平均增益均为正 |
| 正向场景数 | 至少8/12 |

仅当B达到上述条件，才判定“第二套25%骨干上的F05达到预定AP目标”。

若A在同一C3也达到相同标准，则形成更强的跨两套骨干证据。若A与B方向不同，应明确报告，不进行事后模型筛选。

如果增益为正但置信区间跨零，判为**证据不确定**，不能简单写成完全无效。Top-1或碰撞未改善也必须如实报告。

## 8. 执行阶段与停止条件

### P0：数据和资源核验

只读取当前GPU、CPU、内存、数据及剩余磁盘情况。

检查A原冻结配置、新B互补场景、训练输入、标签、源码和输出目录。

不覆盖A权重、已有F05头及C1/C2历史结果。

**技术停止：** 原始数据缺失、划分不满足互斥、资源不足或环境无法准确复现。

### P1：训练EG-B

先做最小训练Smoke，确认有限loss和1024候选解码。

然后按固定条件完成10 Epoch。

保存Epoch日志、最终权重、SHA256及显存和运行时间。

训练期间不查看C3性能。

**停止：** loss非有限、训练技术失败或资源超预算。不得擅自降低训练数据或更新数。

### P2：制作B标签并训练小头

生成B候选及196,608个几何质量标签，训练三个轻量头，每头1,000步。

校验所有目标与特征维度，核对F05分数、冻结权重身份及测试时无GT输入。

若存在技术错误，停止并保留回执；不得通过替换标签、丢弃坏场景或增加训练来隐性改变实验。

### P3：冻结并执行C3

确认完整场景清单、两套骨干及六个评分头权重哈希、F05公式、CD参数和统计标准均已冻结。

之后统一完成A、B在C3的正式评价。

C3结果不得用于重选头、调融合系数或重新训练。

### P4：报告与归档

输出B主对照、A同步对照、场景级结果、Top-1指标、训练和推理资源统计，以及成功、阴性或不确定结论。

重要原始文件留服务器，轻量报告和配置通过单独的执行授权归档到Git。

## 10. 结果解释与研究决策

| 实验结果 | 研究结论 |
|---|---|
| B-F05达到预定目标，A在同C3也正向 | F05跨两套25%骨干具备较强复现证据 |
| B-F05通过，但A在C3不稳定 | B本身有效；跨骨干一致性仍需限定 |
| B-F05正向但CI跨0 | 有积极信号，但复现证据不足 |
| B-F05退化 | F05对训练子集敏感；不能认为普适 |
| AP改善、Top-1退化 | 平均排序收益与首选动作可靠性存在权衡 |
| 技术中断 | 只报告完成部分，不能当作科学负结果 |

**本卡完成的标准，是完整执行并形成可信结果，而不是必须获得正数。**

即使B结果不理想，也不自动扩大数据集、调融合系数或改变F05结构。下一轮是否继续研究评分头训练方式、50%数据或其他改进，应根据本卡真实结果另行决定。
