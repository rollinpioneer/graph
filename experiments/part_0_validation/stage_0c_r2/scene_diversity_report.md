# Scene diversity

Each task has eight distinct deterministic seeds and reset configurations. D0/T_A vary target and second-object positions across a 4x2 layout; T_C varies target and interferer positions across a 4x2 layout. All 24 image hashes and all 24 scene-config hashes are unique. The three few-shots use independent IDs, seeds 9001–9003, and reset configurations outside the formal dev matrix. No brightness, crop, compression, filename-only, or duplicated-image variation was used.
