## 3. P0：零训练职责审计

### 3.1 目的与范围

“零训练”在这里严格指：不拟合任何参数，不调用 GT 质量计算，不做 EG 前向。允许的计算只有读缓存、读 EG-B 检查点中分数层的权重、以及对冻结组件（G 前向、CD、官方选择）做确定性重放。重放的先例是 A 诊断（`aaae139d5`），它在 32 个头数据场景上做过同样的事。

### 3.3 记号

帧 f，G 头种子 k ∈ {20261018, 20261019, 20261020}，候选 i = 1…1024。
s_i：EG 原分数；Q_i^k：G_k 的分数；S_i^k = F05(s, Q^k)_i；cd_i = 1 表示被 CD 拒绝。
μ_i：a0 的官方质量；已知 κ_i = isfinite(μ_i)；合格 v_i = (0 < μ_i ≤ 0.4)。
部署 Top-1：T^k = argmax_{cd_i=0} S_i^k（并列取最小候选号）。
G-only Top-1：T_G^k = argmax_{cd_i=0} Q_i^k。这是诊断用的参照排序，不是部署方法。
EG-only Top-1：T_E = argmax_{cd_i=0} s_i（即缓存中的 `EG_CD`）。

### 3.6 P0-2：G 的组内分辨力（头数据）

对每组 i 的六姿态，真实效用 u_ia、预测 q_ia、组均值 ū_i、q̄_i。三个 G 头分别前向，fit / model-val / gate-cal 分开报告，Top64 与随机 64 分开报告。

| 指标 | 定义 |
|---|---|
| 均值/组内分解 | `(1/6)Σ_a(q−u)² = (q̄−ū)² + (1/6)Σ_a[(q−q̄)−(u−ū)]²`，分别报告两项 |
| 组内中心化 R² | `1 − ΣΣ[(q−q̄)−(u−ū)]² / ΣΣ(u−ū)²`；组内效用全同的组不进分母，单列数目；允许为负 |
| 动作对方向正确率 | 组内效用不同的动作对中 sign(q_a−q_b) = sign(u_a−u_b) 的比例；另报含 a0 的对子 |
| 六姿态选择遗憾 | `max_a u_ia − u_{i, argmax_a q_ia}` |
| a0 被组均值抬高 | `(q_i0 − u_i0)` 与 `(ū_i − u_i0)` 的相关与斜率，按 u0 档和 EG 分位分层 |

先帧内、再场景内聚合，再在场景层做 bootstrap（每个留出角色只有 4 个场景，区间只作描述）。本节不设门槛，只用于解释 H1/H5，并作为 P1 结果的背景。组内分辨弱不自动否定 G，因为部署只用 a0 的跨种子排序。

### 3.7 P0-3：EG 与 G 的冗余，以及“EG 推翻 G 正确偏好”

**(a) 相关性。** 每帧 Spearman(s, Q^k)，全体 1024 与 CD 通过子集各一份；再按 s 的十分位分段。

**(b) Top-1 层面的推翻与救回（核心）。** 对每个 (f, k) 比较 G-only Top-1 与部署 Top-1：

| 类别 | 定义 |
|---|---|
| **推翻（overturn）** | T_G^k 已知合格，T^k 已知不合格 |
| **救回（rescue）** | T_G^k 已知不合格，T^k 已知合格 |
| 下界 L_O | 已知推翻数 / 帧数 |
| 上界 U_O | (已知推翻 + 两者有一未知且 T_G ≠ T 的帧) / 帧数 |

每个推翻案例做 F05 分解：`ΔS = ½·Δs/σ_s + ½·ΔQ/σ_q`，报告 EG 项与 G 项的大小。由 T_G 的定义，G 项必然偏向 T_G，推翻意味着 EG 项更大。

**(c) 成对层面。** 在 C3 每帧取已知、CD 通过、效用不同的候选对，范围限定为 G 的提交 Top-50 与 G-only 前 50 的并集。按 s 与 Q 的排序方向分四类（EG 对 G 对、EG 对 G 错、EG 错 G 对、都错），再看 F05 跟了哪一方。EG 错 G 对且 F05 错 = 成对推翻；EG 对 G 错且 F05 对 = 成对救回。B 诊断里 408 次退化中 EG 偏向新失败候选 190 次、426 次救回中 EG 偏向新成功候选 196 次，所以两个方向必须同时报告。

**(d) 机制特征（头数据，仅描述）。** 对头数据上的推翻案例，查看被推上去的失败 a0 是否有“潜力高于实际”的特征：同种子六姿态最大效用比 u0 高至少一档（1/6），以及它的 EG 分位。这正是 E_act 想纠正的情形。头数据留出部分只有 8 个场景，这里只描述，不作门槛。

**(e) 可复核见证。** 用固定种子 20261021 随机抽取不超过 30 个 C3 推翻案例，列出场景、帧、候选号、s、Q、S、两项 z 贡献、μ 与类别，供人工核查。

### 3.8 P0 判定规则 [建议，运行前冻结]

**状态**

- `IDENTITY_FAIL`：F4 或 F5 不通过。停止一切后续阶段，先修读数。
- `INCONCLUSIVE`：未知标签使某项统计无法判定。不自动补标，照常报告上下界。
- `PASS`：其余情况。

**P1 放行 `P1_go`**：状态不是 `IDENTITY_FAIL`，并且排序可挽回空间的上界不低于 Top-1 实用门槛：在 C3 上，G Top-1 失败且存在 “CD 通过、已知合格或未知” 的其他 a0 的帧比例，种子平均 ≥ 1.0pp。（这条几乎必然满足，写出来是为了让“排序没有空间”这种情况有明确的处理。）P0-2 的结果不阻止 P1，因为相关性统计推翻不了一个因果对照。

**P2 触发 `P2_trigger = GO`** 需同时满足：

| 条件 | 内容 |
|---|---|
| T0 | F1 通过 |
| T1 存在且可复现 | 种子平均后，C3 上已知 Top-1 推翻出现在 ≥3 个场景，覆盖 ≥2 个难度组；三个头中至少两个各自在 ≥2 个场景出现 |
| T2 有实用空间 | 推翻率上界 U_O（种子平均）≥ 1.0pp。若低于 1.0pp，即使把所有推翻都纠正，Top-1 也到不了 +1.0pp 门槛 |

T2 只看 Top-1 是有意的保守选择：P2 的立论是“EG 的潜力分数在关键竞争里推翻 G”，只靠 AP 的改善不构成这个机制的证据。如果你希望 AP 路线也能单独触发 P2，需要在 P0 运行前改写本条。

## 5. P1：G-W 单因素对照

### 5.1 假设

H1：G 的六姿态等权 MSE 中 a0 只占 1/6，部署又只用 a0，监督权重与部署决策错配。只调高 a0 的权重，在其他一切不变的情况下，能否改善部署的 AP 或 Top-1。

### 5.2 唯一改动

```
G   ：L = (1/128) Σ_g Σ_{a=0..5} (1/6)·(q_ga − u_ga)²
G-W ：L = (1/128) Σ_g [ 0.5·(q_g0 − u_g0)² + 0.1·Σ_{a=1..5} (q_ga − u_ga)² ]
```

即未归一化权重 (5,1,1,1,1,1)，每组总权重仍为 1。a0 的梯度权重变为原来的 3 倍，其余每个姿态变为 0.6 倍。Top64 与随机 64 的组权重不变；碰撞负例保留；不同时引入高分区加权。这个权重是外部审查提出的单一配置，不是在 C3 上搜出来的，也不扫描。

## 6. P2：L1 读出对齐（仅在 `P2_trigger = GO` 时执行）

### 6.1 假设

原 EG 分数学的是“种子—视角的潜力”，F05 却把它当作当前 a0 的一路证据。把 EG 侧这个 65 参数的仿射读出改为直接估计 a0 的实际效用 u0，能否减少 EG 推翻 G 正确偏好的情况，同时保留 EG 对 G 的有益补充。

### 6.2 三组（同时跑，缺一不可）

记 t̃_i = (t_i − μ_t)/σ_t，其中 μ_t、σ_t 取 G 检查点中 fit 统计的 mean/std 的第 256–319 维，也就是 G 输入里已经归一化的 score64 切片。

| 组 | 函数 | 目标 | 进入 F05 的方式 | 回答的问题 |
|---|---|---|---|---|
| **E_act** | Ê_i = wᵀt̃_i + b（64+1 参数） | u_i0 | F05(Ê, Q_G_s) | 主方案：EG 侧读出改学实际动作效用 |
| **E_pot** | 同上 | m_i = max_{a=0..5} u_ia | F05(Ê_pot, Q_G_s) | 同函数类、同插槽，只换目标为六姿态范围内的潜力。用来区分“目标语义”与“一般性重新拟合/尺度修正” |
| **G-cap65** | Q'_i = σ(ℓ_G_s(x_i0) + wᵀt̃_i + b)，ℓ_G 为冻结 G 的 logit | u_i0 | F05(s, Q') | 同样 65 个参数、同样数据和优化预算，但加在 G 侧做普通修正 |

EG-B 主干、候选、宽度、视角全部不动；G 的结构、权重、输入、归一化全部不动；1024 个候选和几何逐位不变；F05、CD、NMS、Top-1 规则不变。必须披露：E_act 和 E_pot 组里 F05 的公式没变，但第一路输入的语义变了。

### 6.3 训练

| 项 | 值 |
|---|---|
| 样本 | fit 24 场景 × 8 帧 × 128 组，每组只取 a0，共 24,576 个样本（需 A5）。不用其余 8 个场景拟合 |
| 采样流 | 与 G 种子 s 完全相同的组排列和游标逻辑，每步 128 组的 a0；流哈希必须等于 G 的对应值 |
| 优化 | AdamW，lr 1e-3，wd 1e-4，1000 步，MSE；只保存 step1000 |
| 种子 | 20261018、20261019、20261020，与 G 同种子配对进 F05 |
| E_act/E_pot 初始化 | 从原有效读出开始：`w₀ = α·(Wᵀc)⊙σ_t`，`b₀ = α·[(Wᵀc)ᵀμ_t + cᵀb] + β`。α>0、β 只由 fit 统计确定，使初值在 fit a0 上的均值和标准差分别等于 u0（E_pot 为 m）的均值和标准差。这是对原分数的正仿射变换，所以 step 0 的 F05 与 G 完全相同。不用 C3 选初始尺度 |
| G-cap65 初始化 | w = 0、b = 0，step 0 时 Q' = Q_G |
| ℓ_G | 用冻结 G 在缓存几何上前向得到，不从缓存 Q 反推 logit（避免 Sigmoid 饱和）；并核对 σ(ℓ_G) 与缓存 Q_G 一致 |
| 设备 | CPU 即可（65 参数线性模型） |

### 6.4 不变量检查（训练前执行）

任何一项失败都先排查实现，不进入训练。

## 10. 风险与已知局限

1. C3 已被反复用于开发，P1、P2 在同一 C3 上各试一次，两次机会里至少一次因噪声过门槛的概率高于单次。门槛是实用投资规则，不是家族错误率控制。
2. 头数据每个留出角色只有 4 个场景，P0-2 与离线诊断只能作描述。
3. 标签覆盖：C3 只有 Top-50 并集已知，头数据每帧 896 个候选未知。推翻率与 R/D 都按上下界报告，未知不按失败算。
4. E_act 在 128 池（Top64 + 随机 64）的 a0 上训练，却在 1024 个候选上部署，存在支持集偏移（审查中的 H7）。
5. G-only Top-1 只是诊断参照，不是部署方法；“推翻”是相对这个参照定义的。
6. E_act 估计的是平均效用，不是 P(μ≤0.4)。即使回归更准，也不保证 Top-1 更好，所以判定只看完整 C3 的门槛，不用 MSE 代替。
7. Top-1 = CD 后最高分依赖 `grasp_nms` 是贪心 NMS 的前提，本轮没有读到其源码，由 P0-F2 实证。
