# GT–Depth–CD Alignment Audit V1

## 结论

**暂缓新增可观测性网络，先明确碰撞几何和观测的对应口径。** 本轮直接证实：官方GT与CD在碰撞区域、点采样及触发阈值上均不同；失败高度集中在少量、接近抓手边界的GT点。但空间覆盖与阈值差异并不能解释全部现象，深度与GT局部表面差异仍明显。

没有发现满足本卡描述规则的、跨帧一致且超过10mm的对象偏移；这不能排除局部位姿、模型形状或传感器误差。深度孔洞和边缘也不是唯一解释。当前证据不足以将“GT点位于深度前方”当作稳定、可学习的物理规律，更不能据此承诺AP改善。

## 完成范围与可信性

- 来源：已归档D-V及EG-B/G的完整C3缓存，父提交 `2aafe0541e6a770f03a2450de813a584e0d010d2`。
- 纳入全部 **1,177次** G三头Top-1非空碰撞事件，去重为 **786个失败候选**。共处理 **784帧、1,692个唯一候选**。
- 成功配对：581次同帧同物体、269次同帧其他物体、327次无合格Top10对照；无配对保留。另有每场景最多16个均匀选出的成功帧作背景。
- 1,692个候选的原CD重放、官方GT碰撞和空抓判定均与历史缓存一致；输入导出和质量缓存逐帧哈希与D-V记录一致。
- XML与MAT物体位姿最大元素差为0。两者可能来自同一套标注，**这不是独立真实配准证明**。
- 原始质量标签、候选姿态、G权重、F05及历史结果未改动。训练0、EG推理0、新质量标签0、GPU0、C4读取0。

以下“事件口径”包含头间重复，与原Top-1指标对应；“场景口径”先在场景内汇总，再等权平均12个场景、bootstrap 10,000次。未将帧或种子当作独立场景。C3已使用过，本报告为探索性诊断。

## 1. 官方GT与CD的几何确实不同

抓手局部x为接近方向，d为解码深度，单位米：

| 项目 | 官方GT碰撞 | 原CD |
|---|---|---|
| 手指x范围 | −0.02 到 d | d−0.06 到 d |
| 底座x范围 | −0.03 到 −0.02 | d−0.07 到 d−0.06 |
| 额外接近通道 | 无该项 | d−0.12 到 d−0.07 |
| 点源 | 8mm采样的完整物体模型及桌面 | 可见深度、原工作区裁剪、5mm体素 |
| 触发规则 | 任意GT点进入指/底座区域 | 占用数/等效总体积 > 0.01 |
| 宽度 | 裁剪至0–0.1m | 原始解码宽度 |

高度与边界严格/非严格不等式均按实际源码重放。仅8次失败事件的原始宽度超过0.1m，因此宽度裁剪差异不能解释整体。

当d=0.04m时，两种实体指/底座位置基本一致；较小d时，官方底座的一部分落入CD的闭合空间，CD不会把它视为实体碰撞。这一点是在**同一个GT点的位置**直接比较得到的，不是用不同点云数量间接推断。

| 现象 | 事件口径 | 场景等权均值及95%区间 |
|---|---:|---:|
| GT碰撞点数≤5 | 74.43% | 84.22% [76.03,91.39] |
| 全部GT碰撞点位于CD区域之外 | 19.12% | 12.81% [4.64,23.42] |
| 至少部分GT碰撞点位于CD区域之外 | 22.26% | 15.15% [6.06,26.95] |
| CD区域有深度占用，但未超过阈值 | 23.70% | 25.58% [14.14,41.49] |

每个事件GT碰撞点中位数为3，范围1–24；逐抓法平均 **81.55%** 的碰撞点距离碰撞盒边界≤2mm，抓法内边界距离中位数的总体中位数仅 **0.90mm**。因此毫米级表面或采样差异就可能改变官方的二元判定。

逐抓法平均碰撞点归属：左指27.79%、右指48.00%、底座24.20%；目标物体74.02%、其他物体25.19%、桌面0.79%。仅1.27%的事件涉及任何桌面点，桌面不是本批退化的主要来源。

CD当前需要约8–14个深度体素才会触发，中位数12。23.70%的事件有1–12个深度体素但低于阈值；其余 **76.30%** 的事件在CD区域没有深度体素。后者不能通过简单降低正阈值解决。

覆盖与观测证据并不互斥：

| | CD没有深度体素 | CD有体素但低于阈值 |
|---|---:|---:|
| 全部GT碰撞点不被CD覆盖 | 178 | 47 |
| 至少一个GT碰撞点被CD覆盖 | 720 | 232 |

这些是几何事实，不能相加成互斥的“因果贡献百分比”。

## 2. 深度漏测与边缘是部分证据，不能解释全部

沿用D-V的4mm描述阈值，残差定义为 **GT z − 原始深度z**。负值只表示GT点在同像素深度之前，不自动代表空间真的空闲，也不自动代表GT错误。

逐抓法平均碰撞点比例：

| 状态/邻域 | 比例 |
|---|---:|
| GT在深度前方超过4mm | 83.39% |
| 深度表面±4mm | 1.49% |
| GT在深度之后超过4mm | 8.37% |
| 深度无效/投影无效 | 6.75% |
| 5×5邻域含深度孔洞 | 30.18% |
| 3×3深度跳变>10mm | 13.38% |
| 3×3分割边界 | 20.12% |
| 前方差异且同对象分割、无上述孔洞/跳变/边界 | **44.21%** |

邻域项可重叠；投影超出图像的像素不参与邻域归因，仅1次事件有此情况。GT分割仅作为审计参照，不是独立传感器真值，也未用于新增模型输入。

每个抓法GT碰撞点有符号深度残差中位数，再取事件中位数为 **−22.10mm**；到最近真实深度点的三维距离对应中位数为 **10.14mm**。扩大到5×5像素邻域后，仅逐抓法平均6.18%的点能在4mm内找到深度表面，简单移动一两个像素不能覆盖大部分差异。

工作区掩码保留了逐抓法平均99.92%的对应像素，故原工作区裁剪不是主要解释。孔洞/边缘有实质贡献，但44.21%的点仍落在当前规则判为平滑、同对象的区域，不能把所有差异归结为孔洞、边缘或遮挡。

## 3. 未证实统一的大配准偏移

对所审计物体的有效、侵蚀后内部深度像素，固定最多2,048点/对象/帧，计算到完整高密度GT模型表面的最近点残差：

- 1,056个对象—帧、56个场景—对象组；32组至少有8帧。
- 对象—帧表面距离中位数的总体中位数 **5.69mm**，90分位 **11.42mm**。
- 平均41.05%的深度点距GT表面≤4mm，78.91%≤10mm。
- 按预先固定的“至少8帧、某轴残差中位数绝对值>10mm、至少75%帧同方向”规则，**0/32组**被标记。

这不支持“全局或大量对象存在统一的大偏移”这一强解释。与此同时，模型—深度表面仍有毫米级至厘米级差异，完全可能影响0.90mm边界余量的碰撞点。

重要限制：最近点不是已知真实对应；曲面、可见性、物体局部坐标中的偏移及正负抵消都可能掩盖局部误差。本轮没有独立标定真值，也没有按GT渲染完整可见表面来估计校正变换。因此不能宣称已经排除局部标注/模型/深度系统误差。

## 4. 成功对照没有支持直接用CD占用作为新判别信号

850次可配对事件中，失败/成功的平均CD深度体素数为 **1.033/1.015**，平均占用比为 **0.000867/0.000844**。限制到581次同物体配对后，体素数为 **0.960/1.088**，占用比 **0.000804/0.000892**。

失败并没有稳定表现为“观测碰撞更强”。同物体配对本身共享同帧的对象配准背景，适合检查候选层面的占用，却不能提供独立标定对照。成功候选也来自当前头的Top10，存在选择偏差，不能将上述均值当作新的预测性能证明。

## 5. 三种竞争解释的判断

| 解释 | 当前证据 | 判断 |
|---|---|---|
| GT与深度统一对应偏差 | XML/MAT一致；0/32组满足跨帧大偏移规则；局部表面差异仍明显 | 未证实统一大偏移，局部误差未排除 |
| 深度漏测/噪声 | 孔洞、边缘、跳变覆盖一部分点，但44.21%仍为平滑同对象前方差异 | 部分成立，不能作为唯一原因；没有验证可预测性 |
| 官方GT与CD判据不同 | 少量边界点、底座不覆盖、占用阈值差异均直接复现 | 证据最直接，但不能单独解释所有GT—观测不一致 |

**研究决策：保留G，暂停把GT前方残差转为新输入或训练可观测性分支。**

若继续，首选仍是一次有界、零训练的**统一实体几何敏感性对照**：保持原正式评价不变，单独审计将CD实体盒与官方实体盒对齐后，成功与失败候选的观测占用变化；同时报告误杀成功抓法，不能只统计“抓到更多GT碰撞”。这能隔离已证实的底座口径差异，成本预计CPU≤1 worker小时、GPU0、新质量标签0。

若这种一致口径仍无法区分成功/失败，则停止“仅靠可见点占用修复这些GT碰撞”的方向。只有存在独立校准/多视角证据，才进一步研究稳定可靠性建模；不建议直接增加网络模块、扫描CD阈值或修改官方指标。本轮未执行此后续对照。
