# GT–Depth–CD Alignment Audit V1

冻结日期：2026-10-20。零训练、零新增质量标签、零GPU，不修改受保护G及评分，不读取C4。
分支：https://github.com/rollinpioneer/graph/tree/codex/eg-gt-depth-cd-audit-v1-20261020
起点：D-V `2aafe0541e6a770f03a2450de813a584e0d010d2`。

## 范围与预先固定规则

纳入D-V完整C3三个G头的全部1177次Top-1非空碰撞事件；计算按(scene,frame,candidate)去重，统计同时保留事件权重和唯一候选口径。
每个事件从同一头同帧Top10已有合格候选中优先配对同GT对象的最高排名候选，否则采用最高排名其他对象候选；无配对保留，不补质量标签。
每场景另外均匀选取最多16个原Top-1合格帧作为背景对照。GT对象归属仅用于审计，不作为网络输入。

1. 重放原CD：原始深度、原工作区掩码、Open3D 5mm体素、原姿态与宽度、approach_dist=.05、阈值=.01。与缓存逐候选核对。
2. 重建官方GT碰撞点：8mm模型采样、对象外扩5cm裁剪、官方指/底座区域、任一点规则；与已有碰撞/空抓结果核对。只计几何，不调用摩擦质量搜索。
3. 在完全相同GT点处判断CD手指/底座/接近通道覆盖。报告点数、手指/底座、目标物体/其他物体/桌面、到GT碰撞盒边界距离、原/裁剪宽度。
4. 报告同像素有符号z差（GT z−depth）、有效性、3×3深度跳变、5×5孔洞、分割边界、同物体像素、GT点到最近可见深度点距离。4mm仅沿用D-V描述阈值。
5. 核对XML物体位姿与MAT poses、相机/桌面链。以侵蚀后的有效同物体深度点到GT模型最近表面的残差和投影位移检查跨帧一致性。最近点不是已知真实对应；不把配准残差直接解释为标注错误。

## 分析与停止

三个解释允许同时成立。分别报告几何不覆盖、存在可见占用但低于CD阈值、原始观测缺少GT占用的证据，不强行互斥归因。
按场景等权报告比例和场景bootstrap95%区间；配对数据单独报告，不将重复头/帧当独立场景。
少量边界点定义≤5点；边界距离≤2mm；深度突变>10mm；这些是描述分组，不作通过阈值。
一致偏移仅作解释线索：同一场景/对象至少8帧，残差中位数幅值>10mm且≥75%帧同方向。仍需区分模型形状、最近点偏差、传感器与标注。
若主要为判据差异，先建议统一解释口径，不训练；若主要为分散不可预测噪声且无稳定信号，停止新增可观测性分支。

预算：CPU≤3 worker小时，GPU0，新增磁盘≤0.5GiB。最多24个低优先级单线程worker，依当前余量派发；小规模验证后运行。超限保留结果并停止相关计算。
