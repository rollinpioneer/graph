# X3 实验卡：去掉 Actor 的直接 Q 优化（2026-10-16）

**状态：** 卡片已写好，未训练。用户 11:18 的决定是“批准继续设计 X3 的实验卡，不批准直接训练”。训练需要用户另行批准。批准前不改动本卡的判据。

## 1. 要回答的问题

我们怀疑存在下面这个循环：

1. Actor 按 Critic 的高评分调整动作（actor 损失中的 −λQ 项）。
2. Critic 用 Actor 的新动作做 TD 目标，继续学习。
3. 评分异常与动作变化相互加强，在起点区域形成价值岛。

- B1a 切断的是第 2 条连接（TD 目标里的 actor 生成器冻结在分叉点）：s0、s3 两个分叉上都没有出现岛。
- X3 切断第 1 条连接：Actor 不再为了提高 Q 而直接调整动作。Actor 仍通过蒸馏模仿 VaBC 学习；Critic 照常训练，并继续参与 Guidance；TD 目标仍使用当前 Actor 的动作。

X3 借用了 OptiFlow 去掉 Actor 直接 Q 优化的思路，但不是 OptiFlow 的复现：OptiFlow 还改了蒸馏机制（OT 分配），X3 保留 GFP 原来的蒸馏。

**与实验 A3 的区别：** A3 从 600k 出发只训练 actor 20k，VaBC 冻结，去掉 Q 项，成功率 26%。X3 中 VaBC、Critic、目标 Critic 全部照常学习，训练 200k。因此 X3 是一项不同的新实验，A3 的结果不能直接预测它。

## 2. 改动（只改 actor 损失）

官方（1abbd5f，`agents/gfp.py` 第 186 行）：

```
actor_loss = VaBC_loss(guidance) + alpha * distill_loss + q_loss      # q_loss = lam * (-Q_online(s, clip(mu(s, z))))
```

X3：

```
actor_loss = VaBC_loss(guidance) + alpha * distill_loss
```

其余全部沿用官方代码路径：critic 损失与 TD 目标（当前 actor + VaBC，target_agg=mean，共享 z），目标 critic EMA τ=0.005，guidance（仍由目标 critic、stop-gradient 的 actor 动作、VaBC 动作和 λ = 1/mean|Q| 计算），VaBC 损失，蒸馏，优化器，采样。q_loss 仍然计算并记录，但不计入损失。部署的策略是当前 actor。

- 代码：`code/x3_fork.py`（sha256 `9750b386…`，远端 `analysis_p0p1/x3/code/` 同一哈希）。
- **单批次核对（只算前向和梯度，不更新参数，不是训练）：** s0@600k 和 s3@300k 上，X3 损失 = 官方损失 − q_loss，误差 4.5e-8。VaBC 损失、蒸馏损失、critic 损失都相同，VaBC 与 critic 的梯度差为 0。Q 项对 actor 梯度的贡献范数为 0.020 / 0.021，官方 actor 梯度范数为 0.054 / 0.051，即约 38–40%。去掉之后 actor 梯度范数几乎不变（0.052 / 0.050），说明 Q 项梯度与其余部分大致正交。结果见 `results/check_s0.txt`、`results/check_s3.txt`。

## 4. 测量

**价值异常（与阶段 1 完全相同）：** 每个 5k 探针点，如果起点区域对比度相对分叉点上升 ≥15，且起点区域 ‖∂Q/∂a‖ ≥ 分叉值的 2 倍，就记为一个异常点。

**Actor 是否仍在学习。** 在固定探针和固定噪声 z 上，取所有探针状态的均值：

- `shift_50k`：‖a_t − a_(t−50k)‖，衡量后期是否还在动；
- `gap_vabc`：‖a_t − f_t‖，衡量 Actor 是否还跟着 VaBC（f 为同一 z 下的 VaBC 动作）；
- `vabc_shift`：‖f_t − f_fork‖，衡量 VaBC 自身是否在学；
- `qadv`：Q(s, a_t) − Q(s, f_t)，只记录不判定，衡量 Actor 相对 VaBC 还剩多少 Q 优势。

**参照值。** 由 `code/x3_motion.py` 只读测量，结果在 `results/x3_motion_ref.json`（sha256 `9e9ac577…`）。它覆盖 B0、B1a 和阶段 1 的 6 个臂，取 +50k 到 +200k 各点。

| 指标（全部探针状态） | 参照范围 | 分叉点 |
|---|---|---|
| shift_50k | 0.541 – 0.687 | — |
| gap_vabc | 0.603 – 0.707 | s0 0.616，s3 0.628 |
| vabc_shift | 0.571 – 0.637 | — |
| qadv | 0.175 – 1.647（岛期偏高） | s0 0.199，s3 0.249 |

**需要说明的局限：** 任意两个不同检查点之间的距离都在 0.54–0.70 左右，Actor 与 VaBC 之间的距离也是这个量级。所以这几个指标只能发现明显的失效（Actor 基本不动，或脱离 VaBC），看不出学习质量的细微差别。学习质量由成功率判断。

## 5. 有效性检查（预注册；任一分叉不通过，则该分叉不下机制结论）

| 检查 | 规则（+100k、+150k、+200k 三个点都要满足） | 不通过的含义 |
|---|---|---|
| V1 Actor 仍在动 | shift_50k ≥ **0.27**（参照最小值 0.541 的一半） | Actor 基本不动，即使“稳定”也是表面稳定 |
| V2 Actor 跟随 VaBC | gap_vabc ≤ **0.88**（参照最大值 0.707 的 1.25 倍） | 蒸馏失效，Actor 不再是在模仿 VaBC |
| V3 VaBC 仍在学 | vabc_shift ≥ **0.29**（参照最小值 0.571 的一半） | 被模仿的对象本身停住了 |

## 6. 判定（预注册，按顺序套用）

成功率取 +100k、+150k、+200k 三个评测点的均值，以减轻阶段 1 里看到的振荡。性能线与阶段 1 相同：B1a 在 +100k 的成功率减 15，即 **s0 ≥ 62，s3 ≥ 44**。

| 结果 | 条件 | 研究含义 |
|---|---|---|
| 无效 | 任一分叉 V1/V2/V3 不通过 | 该分叉不下结论，只报告失效的方式 |
| C：岛仍出现 | 任一有效分叉有 ≥1 个异常点 | Actor 的直接 Q 优化不是形成价值岛的必要条件，需要重新分析其他反馈来源。首要嫌疑是 critic → guidance → VaBC → 蒸馏 → actor → TD 目标这条路径 |
| A：无岛且成功率高 | 两个分叉都有效，都是 0 个异常点，且两个均值都达到性能线 | 支持直接 Q 优化是有害反馈的重要组成部分 |
| B：无岛但成功率下降 | 两个分叉都有效，都是 0 个异常点，但至少一个均值低于性能线 | 切断这条反馈可能以牺牲有效的策略改进为代价 |

补充规则：

- 只有一个分叉有效时，C 仍然可以成立（一个反例就足以否定必要性）；但 A、B 不成立，结论记为“不完整”。
- 无论结果如何，都不把 X3 称为新方法，也不据此宣称通用规律。只有 2 个分叉，只测了 task1。
- 若结果为 A，下一步只讨论 X3 与 B1a 的关系，不直接进入多种子阶段，那需要另一张卡。
- 若结果为 C 或 B，按用户 11:18 的意见，重新评估是继续修这个反馈循环，还是转向 task4 的失败机制。
