# X3 结果：去掉 Actor 的直接 Q 优化（2026-10-16）

**结论（按预注册卡片 `CARD_X3_20261016.md`，提交 d268565；用户 11:38 批准执行）：结果 B。两个分叉都没有价值岛，有效性检查全部通过，但成功率几乎归零（s0 均值 5.7%，s3 均值 1.3%，性能线分别为 62 和 44）。**

按卡片的含义：切断“Actor 按 Q 调整动作”这条反馈，确实能去掉价值岛，但代价是几乎全部的策略改进。

## 1. 价值异常（窗口规则，与阶段 1 相同）

| 分叉 | 异常点 | 最大对比度上升 | 最大 ‖∂Q/∂a‖ 比值 | 结束时 |
|---|---|---|---|---|
| s0（600k→800k） | **0** | 17.7 | 1.02 | 上升 17.6，比值 0.12 |
| s3（300k→500k） | **0** | 6.1 | 0.88 | 上升 6.1，比值 0.05 |

**s0 的对比度上升超过了 15，需要单独说明。** 这次上升来自全局价值下降得比起点区域更快，而不是起点区域的价值上涨：

- V_all 从 −163.1 降到 −192.9，起点区域 V_start 从 −187.3 降到 −199.5。
- 真正的价值岛是起点区域的价值往上冲。例如 B0 中 V_start 从 −187 涨到 −130。
- 同时 ‖∂Q/∂a‖ 一路降到分叉值的 0.12 倍，远低于 2 倍的门槛。

所以无论按规则还是按实质，s0 都没有岛。

| 步数（k） | s0 V_start / V_all / ‖∂Q/∂a‖ | 步数（k） | s3 V_start / V_all / ‖∂Q/∂a‖ |
|---|---|---|---|
| 600 | −187.3 / −163.1 / 0.369 | 300 | −158.8 / −146.0 / 0.788 |
| 650 | −192.0 / −179.9 / 0.204 | 350 | −185.9 / −174.5 / 0.177 |
| 700 | −196.6 / −188.5 / 0.086 | 400 | −194.7 / −186.5 / 0.085 |
| 750 | −198.8 / −191.7 / 0.054 | 450 | −198.2 / −190.9 / 0.054 |
| 800 | −199.5 / −192.9 / 0.044 | 500 | −199.1 / −192.5 / 0.040 |

在 discount 0.995、每步奖励 −1 的设定下，−200 相当于“永远到不了终点”。critic 对所有状态的估值都在向这个值靠拢，与下面的低成功率一致。

## 2. 有效性检查（全部通过）

数值取全部探针状态的均值，参照值见卡片第 4 节。

| s0 | +150k | 0.522 | 0.576 | 0.593 | −0.000 |
| s0 | +200k | 0.515 | 0.564 | 0.593 | −0.001 |
| s3 | +100k | 0.543 | 0.587 | 0.605 | 0.002 |

- Actor 一直在动，幅度和其他分支相当，所以“不出岛”不是因为 Actor 停住了。
- gap_vabc 比分叉点（0.616 / 0.628）略小，说明 Actor 更贴近 VaBC。
- qadv 从分叉点的 0.20 / 0.25 降到约 0。也就是说，Actor 相对 VaBC 的 Q 优势完全消失，X3 的 Actor 基本就是一个蒸馏出来的 VaBC。
- 训练损失正常。s0 的 VaBC 损失 0.209 → 0.189，蒸馏损失 0.0166 → 0.0165，critic 损失 1.89 → 1.66。

## 5. 和已有结果放在一起看（推断）

| 设置 | 切断的连接 | 岛 | 成功率 |
|---|---|---|---|
| B0（官方） | 无 | 有（s0、s3） | s0 700k 为 0% |
| B1a | TD 目标里的 actor 冻结在分叉点 | 无（s0、s3） | s0 77%，s3 59%（+100k） |
| EGRA / 周期 / EMA / 环 | TD 目标里的 actor 延迟前移 | 每种都至少在一个分叉上出现 | 振荡 |
| X3 | Actor 的直接 Q 项 | 无（s0、s3） | s0 5.7%，s3 1.3% |
| 实验 A3（参照） | Q 项，且 VaBC 冻结，只训 20k | — | 26% |
| F（eta=0，参照） | 去掉 guidance，保留 Q 项 | 0/8 有岛 | task1 平均 45.1 |

- 在 task1 上，GFP 的策略改进几乎全部来自 Actor 的直接 Q 项。只靠 guidance 加权的 VaBC 蒸馏，接近纯行为克隆的水平。
- 两个可切的连接代价完全不同：
  - 切第 2 条（B1a）几乎不损失性能，但要求参照永远不前移，这违反设计约束；
  - 切第 1 条（X3）去掉了岛，但也去掉了性能。
- 这次没有证明 Q 项是岛的“原因”，只说明没有 Q 项时岛不会出现，而且其他反馈路径（critic → guidance → VaBC → 蒸馏 → actor → TD 目标）在 200k 内不足以独立形成岛。
