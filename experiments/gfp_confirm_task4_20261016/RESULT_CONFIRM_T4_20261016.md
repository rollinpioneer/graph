# 第一阶段确认结果：task4 seed 3 价值岛分叉（2026-10-16）

**结论：** 三项判据各自的结果如下，都与卡片事先写下的预期一致。

1. **分叉有信息量。** 官方续训对照从 700k 继续后，在 755–770k 和 850–865k 两段复现了价值岛，共 8 个异常点。起点区对比度最多上升 +49.9，‖∂Q/∂a‖ 最多是分叉值的 5.3 倍。
2. **价值岛消失：判为"支持"。** IQL-inspired GFP（expectile 0.7）在同一窗口内 0 个异常点，对比度最多上升 +1.2，范数比最多 0.99。V1–V3 全部通过，没有推迟标记，V 预热在 50k 时通过门槛（|V − Q_data| = 0.41）。
3. **完成任务：判为"没有改进"。** I2 三个评测点的成功率为 0 / 0 / 1%，均值 0.33%；对照为 0 / 0 / 0%。两臂都有 58–79% 的回合停在起点格的西墙边。

所以：在一个没有参与筛查的任务和种子上，IQL 式 TD 目标去掉价值岛的效果复现了；但 task4 的失败方式（贴墙）没有变，这个修改不能让 GFP 完成 task4。第一个结果不能替代第二个结果。

判据见 `CARD_CONFIRM_T4_20261016.md`（提交 a63667a，训练前推送）。卡片第 4.4 节事先写的预期是"岛会消失，完成任务不会有改进"，两条都对。

- **判定（卡片 4.3）：** I2 均值 0.33%，比对照只高 0.33 个点，远低于"高 10 个点且 ≥15%"的要求，判为"没有改进"。

- 对照的 850k 正好在第二段岛期间，但它的失败方式与 800k、900k 没有区别。在 task4 上，岛不是失败的主要原因，贴墙才是。这与 P0/P1 的结论一致：起点格的 critic 动作排序偏向西墙，F 臂也是这样。

## 3. 两阶段的状态

- **第一阶段的条件已满足：** 对照复现了岛，I2 判为"支持"。按用户 14:15 的安排，可以进入第二阶段（从头训练）。
- **第二阶段要回答的问题：** 不依赖已训练好的 critic，从头用 IQL 式 TD 目标训练，是否能在不伤害正常种子的前提下提高整体平均。需要包含没有参与调参的种子和 task1 原本正常的种子。
- **task4 的含义：** IQL 式 TD 目标不解决贴墙问题。第二阶段如果包含 task4，只能用来检查"岛是否消失"和"是否伤害"，不能指望它提高 task4 成功率。
