# TD Target Drift Decomposition：冻结权重分解结果

**结论：优先追查局部价值学习与自举反馈，不继续直接缩小 BFC 的限幅。** 在本次固定输入、固定随机数的反事实计算中，参考目标的主要变化来自 **Target Critic 对相同动作重新评分**；参考 Actor 与 VaBC 单独变化的直接贡献较小。交互项已保留，未改变这一排序。这里定位的是已观察到的目标变化落在哪个组件上，不是证明该组件独立造成了错误。

## 执行与边界

- 原 task1 正式分叉：seed 0 从 600k、seed 3 从 300k 开始；R2 同速纯 EMA、R3 最慢 EMA、R4 小限幅 BFC、R5 大限幅 BFC。
- 使用分叉、+50k、+100k 已有权重。每个分支分析 0→50k、50k→100k、0→100k 三个区间。
- 固定 2048 条起点区域数据转移、2048 条非起点转移，同一批索引用于所有模型。非起点只是对照区域，不声称其行为正常，也未匹配姿态等混杂因素。
- 两套预先冻结的动作随机输入。当前 Actor、参考 Actor 和 VaBC 共用官方接口要求的随机输入；VaBC 保持在当前状态生成动作、下一状态评分的原语义。
- 新增训练、优化器更新、环境构造、reset 和交互均为 **0**。模型、Adam、Agent RNG 全状态摘要及源检查点哈希前后不变。

## A/B/C：谁贡献了参考目标变化？

以区间起点为锚，A 只换参考 Actor，B 只换 VaBC，C 只换 Target Critic，其余组件保持旧版本。完整八组合计算包括 Actor×Critic、VaBC×Critic 等交互项。

|---|---|---:|---:|---:|---:|
| seed 0，同速 EMA R2 | 50k→100k | +60.035 | −0.020 | −0.010 | +59.162 |
| seed 0，最慢 EMA R3 | 50k→100k | +0.314 | +0.002 | −0.003 | +0.310 |
| seed 0，小限幅 R4 | 50k→100k | +59.135 | −0.023 | −0.009 | +58.318 |
| seed 0，大限幅 R5 | 50k→100k | +63.888 | −0.032 | −0.010 | +63.323 |
| seed 3，最慢 EMA R3 | 0→50k | −19.352 | −0.050 | −0.013 | −19.386 |
| seed 3，最慢 EMA R3 | 50k→100k | +28.847 | +0.014 | −0.006 | +28.514 |
| seed 3，小限幅 R4 | 0→50k | +42.832 | +0.017 | +0.006 | +42.420 |
| seed 3，大限幅 R5 | 0→50k | +33.918 | +0.025 | +0.009 | +33.602 |

表内三项主效应不要求单独加总为总变化，剩余部分是交互项，完整报告没有丢弃它们。关键异常区间的交互项平均绝对量之和约 0.35–1.01，远小于 Critic 主效应的数十个单位。由于目标是两个动作分支评分的线性平均，Actor×VaBC 以及三因素交互在本定义下应为零，数值检查通过；这不是额外的机制发现。

以平均绝对量比较，在 **48 个“实验臂×区间×区域”组合的两套随机输入中**，C 都是最大的主效应。改用对称分摊交互项的 Shapley 记账法，C 仍全部最大。这些不是 48 个独立训练实验，不能据此给出跨种子显著性结论。

因此，这不是简单的全局 Q 值一起升高。异常相关窗口存在明显的起点区域相对抬升，而且固定两种动作生成器时仍能通过更换 Critic 重现大部分变化。

最慢 EMA 在 seed 0 的 0→100k 起点参考目标平均变化约 −0.007，平均绝对变化 0.900；它的局部评分较稳定。seed 3 则先降后升：前 50k 降 19.352，后 50k 升 28.847。直接更换参考 Actor 的贡献分别仅 −0.050、+0.014，不能把这一反转直接描述成“参考 Actor 的动作变坏导致目标变坏”。但 Actor 经训练反馈影响 Critic 的间接路径尚未被排除。

## D：BFC 约束了主要变化来源吗？

按恒等式分别计算：

`实际目标变化 = 参考目标变化 + 被接纳增量的变化`。

| BFC／窗口／区间 | 参考目标平均绝对变化 | 接纳增量平均绝对变化 |
|---|---:|---:|
| 小限幅，seed 0，50k→100k | 59.279 | 0.0674 |
| 大限幅，seed 0，50k→100k | 63.983 | 0.1143 |
| 小限幅，seed 3，0→50k | 43.459 | 0.0511 |
| 大限幅，seed 3，0→50k | 34.531 | 0.0820 |

**已有证据支持：BFC 未约束主要的已观测端点漂移来源。** 它限制当前 Actor 相对参考 Actor 的增量，却没有限制参考目标随 Critic 更新而变化。

这个量级差本身部分来自公式：增量在每个端点都有界，而参考目标不受该上界约束。更有信息的证据是固定动作生成器之后，Critic 替换仍重现局部漂移。因此不能只用“大数比小数大”宣布机制被证实，也不能把跨 50k 的变化当成一次 TD 更新跳变。

seed 3 的 BFC 在后 50k 又出现相反方向变化：小限幅参考目标约 −38.865，大限幅约 −41.893。若只比较分叉和最终权重，会掩盖中间抬升与回落；最终目标数值恢复也不代表已损失的策略能力自动恢复。

## 决策与仍未解决的问题

| 候选解释 | 本轮判断 |
|---|---|
| 参考 Actor 单独变化是目标漂移的主要直接来源 | 不支持；直接效应较小，但经 Critic 学习的间接作用未排除 |
| VaBC 单独变化是主要直接来源 | 不支持；不据此删除 VaBC 或 Flow |
| Target Critic 评分变化占主导 | 支持固定权重反事实记账层面的结论；优先追查自举价值学习与局部梯度 |
| 强交互导致无法分离 | 本次关键区间不支持；交互项保留后仍以 C 为主 |
| 已证明 Critic 是错误根因 | 尚未证明；缺乏真实长期价值及受控训练干预 |

下一步最值得单独批准验证的问题是：**保持 TD 动作生成分布不变时，Critic 的自举更新是否仍会产生起点区域的局部抬升？** 这可区分价值学习自身的放大与策略变化通过训练间接推动 Critic 两种解释。本卡没有运行该干预，也未设计或启动新模块、训练或调参。

时间限制仍然关键：seed 3 的 BFC 异常约在 +30k，而现有检查点为 +50k、+100k；本轮只能看到跨事件的变化，不能重建 +30k 的形成顺序。两窗口分叉时的学习阶段不同，也不能将差异归结为种子本身。
