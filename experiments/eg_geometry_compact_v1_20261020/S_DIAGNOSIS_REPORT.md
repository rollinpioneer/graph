# S不如G的零训练诊断

日期：2026-10-20。基于EG-GEOMETRY-COMPACT-V1归档提交`c0a98366f781039f7d8c4a68e07837893a026a35`。本次仅重放已有检查点、读取既有输入/标签/评价缓存，正式训练更新0、新GT标签0、EG前向0、GPU使用0、C4预测/评价读取0。用户另行授权本次推送同一卡片分支。

## 结论

现有证据更支持优先检查**固定区域配额和几何统计表达的信息保留**，不支持把“1000步明显不够”作为首要解释。但不能从这些观察中给出两者的因果贡献比例，也不能说128个点的总容量已被证明不足。

关键发现是：名义128点实际上平均只有约51–52个有效点，闭合区经常被48点配额截断，同时其他区域大量空槽不回填。大多数候选的五区域全部可见点本来就能装入128个槽位。因此，先测试更有效地使用同一128点预算，比直接扩到512点或只延长训练更有判别力。

## 1. 数据身份与诊断范围

- 沿用冻结EG-B、C/S各三个种子20261018/19/20、固定step1000主结果及旧G。没有训练或更新任何模型参数。
- 重放C/S的step250/500/750/1000，共24个已有检查点，加G的三个step1000，共27个。使用原32个头训练/留出场景、256帧、196608个已有六姿态标签，CPU离线前向。
- fit只用于测量既有模型的训练误差；model-val、gate-cal只用于诊断，不参与拟合、选模或重新部署。step1000的CPU重放MSE与原GPU回执误差小于1e-6。
- 对全部196608个实际姿态核验：缓存S每区有效点数精确等于`min(G真实可见区域点数, 原配额)`。统计来自现有G几何和实际S tokens/mask，没有重新采样或补标签。
- C3只复用既有3072帧、三个种子的CD最终结果；9216个“帧×种子”配对只作描述，不视为9216个独立场景。C3已经开发使用，不是独立确认。

代码与机器结果见`diagnosis_s_vs_g/code/`、`diagnosis_s_vs_g/results/`。逐检查点Q缓存保留服务器，不入Git；检查点及Q文件散列记录在回执中。

## 2. 证据A：有效点预算与信息损失

下表仅统计原动作a0的旧Top64+随机64候选，不能直接当作C3全部1024候选的发生率。

| 指标 | fit（24576动作） | model-val（4096） | gate-cal（4096） |
|---|---:|---:|---:|
| 平均有效点数 / 128 | 51.60 | 52.01 | 50.98 |
| 有效点数中位数 | 48 | 48 | 48 |
| padding占比 | 59.69% | 59.37% | 60.17% |
| 有效点少于64的比例 | 89.49% | 88.31% | 89.72% |
| 闭合区点数超过48配额 | 88.73% | 86.38% | 86.77% |
| 五区域真实点数总和≤128 | 87.19% | 89.92% | 92.16% |
| 本可全部装下、仍因区域配额丢点 | 76.83% | 77.66% | 80.00% |
| 闭合区可见跨度保留比例中位数 | 99.43% | 99.92% | 99.80% |
| 跨度低估超过10%的比例* | 3.53% | 3.05% | 3.37% |

*跨度比例仅在完整跨度有限且非零、采样内点不少于2的动作上定义。跨区域点数的汇总保留率为fit54.80%、model-val60.15%、gate-cal59.47%；这是“保留点总数/真实点总数”，不是逐候选保留比例的平均。

配额是左/右手指各24、手掌16、接近通道16、闭合区48。fit原动作中，左/右手指分别约84.55%/72.25%为空，手掌94.47%、接近通道92.73%为空；闭合区平均有86.01个点，却只保留46.56个点。主要问题是空槽不能转给实际存在点的区域。

这说明输入确实发生了可量化的信息压缩，尤其是区域计数、密度和内部细节。但不能据此宣称主要轮廓被普遍破坏：闭合区跨度大部分保留得很好，左右手指的总点保留率也分别约94%和94%。均值/最大池化没有显式绝对点数通道；逐点复制一个点集时两种池化不变，这是结构上的计数歧义，但实际坐标和区域比例仍可能间接携带密度线索。它不等于已证实模型完全不能感知密度。

**尚未证实：**哪些丢失点或统计量导致了多少AP下降。没有训练更密采样或回填版本，不能把“有信息损失”直接等同于“S下降的主要因果机制”。

## 3. 证据B：1000步仍在拟合，不等于继续训练会改善泛化

以下为三个种子平均，对同一批既有标签重放计算的六姿态MSE；不是训练时动态权重下的损失滑动平均。

| S检查点 | fit MSE | model-val MSE | gate-cal MSE |
|---|---:|---:|---:|
| 250 | 0.083470 | 0.092383 | 0.112909 |
| 500 | 0.078588 | 0.090714 | 0.115026 |
| 750 | 0.074567 | 0.091331 | 0.117264 |
| 1000 | 0.071819 | 0.091116 | 0.120089 |

250→1000步，fit MSE降低约14.0%，model-val仅降低约1.4%，gate-cal反而升高约6.4%。750→1000步，fit继续下降，model-val改善约0.000215，gate-cal恶化约0.002825。留出集没有一致受益，不支持凭训练曲线仍下降就断言延长训练能追回部署指标。

训练日志最后500步的下降斜率，S与G/C相近，约每步-1.2e-5到-1.4e-5。S在最后250步的训练损失约0.0748，G约0.0699、C约0.0707，差距并未明显闭合。因此S存在更高的拟合残差，但可能来自表示、学习难度或优化预算，不能单凭此区分。

G/C也仍在下降，且C的gate-cal MSE从250步0.113684升到1000步0.120887。不能把这种训练/留出分离说成S独有的过拟合机制。这里只能说：**当前没有一致的留出证据支持“单纯多训”优先于表示诊断**。1000步以后尚未观察，不能证明继续训练绝对无效。

## 4. 证据C：平均MSE和实际排序的脱节

| step1000三种子平均 | G | C | S |
|---|---:|---:|---:|
| fit六姿态MSE | 0.067069 | 0.067858 | 0.071819 |
| model-val原动作MSE | 0.095575 | 0.094823 | 0.094001 |
| gate-cal原动作MSE | 0.125355 | 0.127170 | 0.123529 |
| model-val Top64同帧成功/失败候选反序率 | 34.48% | 33.23% | 34.30% |
| gate-cal Top64同帧成功/失败候选反序率 | 34.69% | 34.73% | 38.64% |
| gate-cal Top64成功AUROC | 0.6207 | 0.6083 | 0.6123 |

成功定义为既有mu满足`0<mu≤0.4000001`。同帧反序率逐帧平均，正负候选同分计半个反序；不等同全局AUROC，也不是AP。完整六姿态、原动作、Top64和全128候选明细均保留。

S在两个留出集的原动作MSE甚至低于G，但gate-cal同帧反序率比G高约3.95个百分点。降低平均MSE并不保证改善决策区排序；把训练目标拟合得更充分，也不自动等于追回AP。这个观察同时提醒：不能只在“128点”和“步数”之间强行二选一，池化/统计表达、监督与部署排序目标的关系仍是混杂因素。这里不据此追加Ranking Loss或其他新模块。

C提供了一个有用参照：它同样删除PCA/法向，但相对G只损失0.139 AP、0.369pp Top-1；S相对C额外损失约0.870 AP、2.083pp Top-1。故“S没显式PCA/法向”不足以解释主要差距。但C/S也改变了输入形式和参数化，仍不是对128点数的单因素消融。

## 5. 已有C3中，S具体损失在哪里

以G→S的9216个帧×种子配对，原姿态全部不变：

| 转移 | 次数 |
|---|---:|
| 成功→成功 | 3622 |
| 成功→失败 | 758 |
| 失败→成功 | 532 |
| 失败→失败 | 4304 |

净损失226次成功，等于Top-1下降2.452pp。758次退化中，516次是无碰撞但mu>0.4，100次是无碰撞且在评价摩擦范围内无力闭合，141次是非空碰撞，1次为空抓。约81.3%是无碰撞质量不足，不是主要把抓法换成空抓。不能将这些类别直接当成某个具体几何特征失效的机制证据。

S的平均AP在12/12场景低于G，三个种子的整体AP和Top-1差也都为负。这个部署负结果比单个留出MSE或某一条训练曲线更值得保留；不得用本次检查点重放事后改选step250/500/750替换原step1000结果。

## 6. 下一步最值得验证的对照（建议，未执行）

建议先做**固定128点上限的“配额回填×训练预算”最小2×2**，不直接扫描512/1024点、不加蒸馏，不修改F05：

| | 固定1000步 | 固定3000步 |
|---|---|---|
| 原五区固定配额 | 复用当前S | 从同一次1000步状态继续到3000 |
| 相同128槽位，允许空槽回填 | 新对照 | 同一次运行继续到3000 |

回填版本只改变采样分配：先保留现有各区域选点，再将未用槽位优先分给仍有未选点的闭合区，其后依预先冻结的接近通道/手掌/左/右顺序填充；保持同一局部坐标、8通道、128上限、mask、网络和损失。不复制点；区域内仍按确定性字典序均匀选点，排除已选点。若候选总点数不足128仍padding。规则须在新卡P0冻结，不根据结果调整。

维持现有三个种子、原混合采样流和六姿态标签；两个训练长度共享相同前1000步和后续索引流，3000步固定终点，不挑最佳检查点。复用当前原S1000后，新增约15000次轻量头更新；训练成本按上一轮速度粗估约0.1–0.2 GPU进程小时，正式C3评分/官方评价仍是主要成本，完整预算应在新卡核定。

主要比较必须是相同评分/CD下完整C3的AP、Top-1及场景配对区间；留出MSE、反序率只能辅助解释。C3仍是开发，C4不运行。

- 回填在两个训练长度均改善，而延长原S无一致收益：更支持配额导致的信息保留问题。
- 两种采样均主要受益于延长训练：更支持训练预算不足。
- 只有回填+长训练有效：提示信息与学习预算存在交互，不能归于单一因素。
- 两种改变都没有部署收益：保留G，停止这条简单补救路径；再单独评估显式计数通道/池化或监督匹配，不自动追加模型。

该2×2仍只能识别配额回填和一个固定更长训练预算的效果，不能穷尽全部采样/表示/优化原因。若只能批准一个新增臂，优先回填128点、固定1000步，与当前S直接比较；它更直接针对已量化的空槽浪费。后续训练和评价均需新卡批准，本次未启动。
