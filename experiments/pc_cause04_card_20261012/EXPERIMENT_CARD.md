## 1 目标与研究结构

**目标：识别模型执行困难出现在哪个具体环节、哪些竞争性解释与证据一致，并判断它们能否解释物体数量增加后的总体退化。**

三个问题全部保留，但不是三个独立论文方向：P1 是总体科学问题；P2 和 P3 是可能解释 P1 的失败过程。发现其他有直接证据的机制时可以登记，但本轮最多选择两个具体竞争性假设开展区分性验证，不同时开发三套方法。

| 问题 | 当前进展及边界 | 本轮重点 |
|---|---|---|
| P1 数量增加后单物体执行质量下降 | 既有条件下退化已观察；不能视为数量单因素的因果效应。稀疏优势未稳定复现 | 成功/失败轨迹中的感知可用性、对象接近与选择、实际操作需求、物体间干扰 |
| P2 持续无目标进展 | 现象存在，控制目标、关节、末端均有响应；原因未定位 | 机械臂实际在做什么、是否接触、接触后物体为何不向目标推进 |
| P3 物体落桌 | 现象存在，固定的普通 XYZ 动作幅度减半没有改善落桌 | 首次离桌前的直接接触、次级碰撞、物体速度、动作方向和对象选择 |

不重复大规模统计已知现象，不默认稀疏必然更好，不继续盲试限速，不默认需要记忆、预测、规划或新网络。第一轮原因分析并行；干预仅用于区分已有具体解释。

## 2 最新证据与需要修正的判断

下列事实来自已归档记录，本次没有重新执行这些实验：

- PC-P123-03 的八对新六物体场景：稀疏/拥挤平均达标比例均为 0.7292，全部达标均为 1/8，落桌均为 1/8，无进展均为 6/8。主指标配对差为零，探索性区间约 [-0.125, 0.125]。这削弱“稀疏必然提高表现”的推荐，但不能证明布局没有影响；两条件平均距离也并不相同。
- 原四个无进展窗口及新十二个窗口的动作变换、限位目标与官方实现一致；最大重算误差约 5.7e-8 m。接口错误证据较弱，但不等于所有控制问题已排除。
- 四个旧无进展场景各补跑一次，均未复现原事件；批量槽位改变了策略随机流。它们支持“初态相同不保证过程相同”，不能用补跑结果替代原过程解释。
- 普通动作减半的四对完整任务中，平均达标比例从 0.7083 降至 0.4167，落桌从 1/4 到 2/4。该固定规则未通过任务与落桌双重判定；命令幅度缩小不等于实际物理速度减半，不能推广为所有限速方法无效。
- **测量缺口：**P1 和固定补测的接触采集为 `CC_NEVER`，全零读数不可用，零不代表没有接触。后来 `CC_LAST_SUBSTEP` 的非零净力已通过自检，但只记录每个模拟步最后内部子步，不能辨认接触对或覆盖全部瞬态。
- 原快照恢复门失败；本轮不以修复快照为主目标，不把它作为三条分析并行开展的前提。

证据层级：日志、原始字段与代码核验属于记录支持的事实；事件先后与相伴关系属于描述证据；原因解释必须单列；真正改变因素后的效果才构成更强的机制证据。未能排除替代解释时写“未判定”。

主任务指标仍为严格 XY 距离 <0.04 m 的终点达标物体比例，同时保留全部达标率、平均/最大距离；落桌单列。完整补测默认 200 控制步，同条件不额外延时。策略训练见过 3C，视觉编码器见过 6C，不把整个系统描述为未见过六物体。

建立统一回合索引，覆盖历史 3C/6C、PC-SCALE-02 与 PC-P123-03，记录权重、布局、颜色、目标需求、步数、采样分辨率及可用字段。**按协议分层，不合并不同分布与时长估计统一失败率。**已有成功、失败和未触发回合都纳入索引，典型案例只作说明。

- 旧数据：发现/校准集，允许查原因，不冒充独立验证。
- 补测：弥补明确字段缺口；初态重跑不是旧轨迹重现，必须记录是否复现事件。
- 验证集：提出假设、选阈值或干预后使用的新场景/策略随机数；与发现集互斥。随机数至少记录场景、策略采样、槽位及批量大小。

## 4 第一阶段 并行原因分析与共用测量

### P1 成功与失败轨迹中的多物体操作过程

对同协议下的成功/失败轨迹建立对象级事件时间线：每个物体是否未达标、可见程度、接近/接触次数、实际位移方向、达标后再次被移动、长期未被操作以及无效切换。先比较几何需求接近的案例，再回看总体分布，不用事后选出的成功子集估计原因发生率。

| 候选因素 | 优先取得的证据 | 必须避免的归因 |
|---|---|---|
| 感知/目标表征 | 双视角可见性、对象/目标图像对应、粒子覆盖与变化；可用时以真值投影诊断 | DLP 粒子不等于稳定物体身份；遮挡与失败相关不证明感知是原因 |
| 目标选择 | 实际接近/接触的对象、该对象当时目标误差、是否反复操作已达标对象 | 接近最近物体不等于模型选择它；注意力图不等于决策真值 |
| 操作需求 | 初始达标数、逐物体运输距离、需操作对象数、实际有效推进步数 | 数量增加同时增加工作量，不能直接称为泛化能力缺失 |
| 物体干扰 | 操作对象之外的位移、目标偏离及其接触时序 | 次级物体运动本身不证明发生物体间碰撞 |

没有唯一正确操作顺序时，不以顺序不同判错；将“疑似遗漏/切换”与经对象身份和时序证实的行为分开。输出每个因素的支持案例、反例、未知字段及最能区分解释的下一项测量。

### P2 动作为什么没有转化为进展

同步检查：**策略输出 → 反归一化/缩放/限位 → 控制目标 → 关节/末端响应 → 接触对象与方向 → 物体运动 → 目标进展。**重点定位已经有末端响应之后的环节，不重复把“大动作、小进展”当作原因。

原事件定义保留为入口：20 步窗口内尚有未完成目标、无落桌、最大物体位移与最大平均目标进展均 <0.001 m。窗口结束才可在线检测，不以窗口起点偷看未来触发。窗口内还要看逐物体距离，避免平均值掩盖一物体改善、另一物体恶化。

对每个窗口及其前后片段登记：重新接近、无接触运动、接触但物体不动、物体运动方向不利、已达标对象被移动、证据不足。分类可以重叠。正常接近需要时间，不能以物体短时静止直接判为策略错误；末端最大位移不等于累计路径或有效操作。

### P3 首次落桌前发生了什么

沿用中心 Z <0.975 m 连续 5 步的落桌定义；另定位首次包围盒跨桌边的时间。分析跨边前动作方向、控制目标、末端及物体轨迹、桌边距离、速度与接触时序。只使用跨边前的物体速度解释诱因，不用之后自由落体速度倒推原因。

分类为直接机械臂接触后向边缘移动、操作其他物体时的可核验次级碰撞、接触结束后的运动延续、混合或未知。要将“没有记录到接触”和“已确认没有接触”区分。不能因为某段轨迹危险，就认定存在错误对象选择或不可避免的物理困难。

### P2 与 P3 共用的测量门

统一记录动作各变换阶段、控制目标、关节位置/速度、末端姿态、物体位置/姿态/速度、目标距离、接触采集模式、模拟时间与动作时间。事件前后保留同步图像或短视频，不能把每十步图片当作精确接触时刻。

先核验当前后端是否能提供接触双方身份、位置、法向与受力；不能假定 API 支持。只有净力时，将接触对象关系标为未知，位置接近只能作代理。若额外读出会改变执行路径或物理，应单独登记并检查可比性。

测量自检至少包括已知分离负例和可核验接触正例、时间对齐、缺失字段检测；根据正例报告读出覆盖范围。无法识别直接与间接接触时，不大量采集同样无判别力的数据。优先解决接口读出；无法低成本解决则停止该归因，不宣布没有碰撞。

## 5 有界补测与第二阶段区分性实验

补测必须说明“缺哪个字段、补齐后能区分哪两个解释”。优先让同一回合同时提供 P1/P2/P3 所需字段，避免分别重跑。候选上限为 **6 个发现集完整回合**，包含正负/成功失败参照，不全选失败；按字段缺口、预期判别力、重复性排序后冻结清单。每个预定场景只跑一次，不复现即记未复现，不换种子直到出现目标事件。

完成第一阶段后，最多保留两个具体假设。每个必须有：可核验事件链、竞争解释、可观察预测、反例及一个能改变判断的最小实验。若证据只够描述，停止在描述层，不为了完成卡片而试干预。

| 若第一阶段支持的线索 | 可考虑的区分性操作示例 | 解释边界 |
|---|---|---|
| P3 操作其他物体后出现次级位移，接触对支持传播链 | 控制运输需求和边缘距离，改变相关物体间通路/间隙并设置几何匹配对照 | 改间隙也改变视觉；缺接触链时仍无法独占归因于碰撞 |
| P2 末端可动但反复未建立接触 | 固定、有限的接近动作对照，保持总步数和调用成本 | 接近变化也改视觉；能恢复不等于唯一原因确定 |
| P2 有接触但推进方向不利 | 根据已核实接触与几何，测试一个幅度受限的方向变化，与简单等成本动作比较 | 真值选动作属诊断性 oracle，不冒充原视觉方法 |
| P1 疑似操作需求主导 | 同样对象数量下，匹配布局、控制需移动对象数并更新目标图像 | 同时改变目标分布/难度，不等于纯组合推理试验 |

上述是条件性设计模板，不是已批准的固定干预清单。实际操作、对照、阈值、时长、样本和停止条件必须在验证结果可见前写入冻结附表。不再默认尝试动作乘 0.5，也不枚举多个动作事后选最佳。

默认采用从匹配初态完整运行、预先随机分配条件、在线触发的对照；不依赖严格快照。核对实际初态与目标误差，不以同种子宣称同状态。局部分支仅在恢复精度已另行通过检查时采用；本轮不安排无边界快照排障。

验证资源上限暂定 **12 个完整回合**，优先集中为一个有信息价值的两臂六组配对或三臂四组匹配，而非切成多份极小试验。若确有两项不同的低成本区分实验，先基于实测成本与判别能力登记分配，再并行；不得以查看第一项效果为由临时扩样。预注册的无触发、失败和落桌全部保留。

## 6 第三阶段 把失败机制连接回 P1

必须区分以下证据，不因局部案例可解释就跨级结论：

1. **局部过程证据：**该片段发生了什么；只是个案还是多个独立回合重复。
2. **数量相关证据：**在相同定义、相同可观察窗口和相近协议下，事件是否在 6C 更常见/更早、占用更多时间或伴随更多目标损失。
3. **原因贡献证据：**控制相应因素后，完整任务是否改善；若要声称解释数量退化，还需数量对照及差距变化，而不只证明 6C 有收益。

旧 3C 只有 100 步的数据仅与 6C 的前 100 步比较；PC-SCALE-02 有共同 200 步，可单独分析，但样本只有四组。不同轮次不混合为同一个数量效应估计。物体更多时“至少一次事件”的机会自然增加，因此除回合发生率外，报告观察时长、未达标对象数、首次事件时间和回合级归一化描述；不能把对象或时间步当独立样本。

事件先于失败只说明时间顺序，可能仍是共同原因所致。可描述事件前后损失的目标数和停滞时长，但不将其直接当作该原因可归责的损失。

若现有 3C/6C 协议不足以比较，只能保留“可能解释 P1”的候选。需要新数量对照时，应从第二阶段已有预算中明确分配并冻结，不能自动扩展整套数量×布局×干预矩阵。没有公平数量对照，不报告“解释了多少比例的数量退化”。

|---|---|---|

| 连接 P1 的分析 | 已完成数据的 CPU 汇总可与独立 GPU 作业并行 | 依赖新结果的判断不能提前形成 |

新执行轮拟定硬上限：**总计 2 GPU 小时、任务相关 GPU 进程合计 12 GiB**。预算包括策略、DLP、仿真/渲染、副卡上下文、自检、失败排错和完整前缀。先少量试运行测耗时显存，再在结果不可见时冻结实际样本数；上限不代表必须用满或已保证足够。

建议上限分配：测量自检 0.25、发现集补测 0.50、区分性验证 1.00、资源波动及退出余量 0.25 GPU 小时。所有分支共用同一本预算账；变更须在对应正式运行前登记。CPU 读出排障最多两个有依据的修正循环或 90 分钟专门工程时间，先触及者停止。降低并行数可行，不能静默降低去噪、改成功阈值或删关键条件。

八张卡均共享：每次选择当时最空闲且满足预算的卡，不等待完全空卡；独立任务优先并行，但并行累计 GPU 小时按各卡计，不用墙钟替代。任务目录、随机数和可写状态隔离；共享负载明显干扰时分批，不终止其他用户进程。记录资源竞争、并行区间及必须串行的理由。

## 8 冻结、判定和停止规则

每阶段开始前，附表登记 UTC 时间和散列、实际代码/权重身份、案例与种子、字段/时间分辨率、分类定义、成功与过程指标、发现/验证角色、操纵与对照、匹配容差、样本与资源上限。后续发现新模式单独登记，不事后改已完成实验的主标准。

统计以回合或匹配场景组为单位，展示逐回合结果、效应量和小样本不确定性。一个公开训练权重的多个评价种子不代表多个训练种子。未知类别、未复现、未触发和技术失败都保留；只按预先登记的技术有效性规则处理，不能删掉不利结果。

| 结果 | 判定与下一步 |
|---|---|
| 对象接触与时序可核验，替代解释有区分性反例/对照 | 保留该具体机制；明确支持到局部、总体还是数量层面 |
| 动作链某环节存在实现错误 | 工程修复候选，停止基于该错误的算法立项 |
| 简单控制已经解释并处理主要困难 | 作为强基线或工程结果，不强造新模型 |
| 只有相关现象或病例重跑不稳定 | 未判定；指出缺失字段/样本，不宣称原因确认 |
| 测量不能识别接触双方、预算不足或匹配失效 | 停止相应归因/实验，完成其余独立工作 |
| 三问题均未形成足够具体机制 | 停止本轮，不自动扩展第三、第四种干预直到出现正结果 |

只有证据具体、可重复且已有简单解释不足时，才建议下一轮方法干预。最终最多推荐一个算法研究主线；P1/P2/P3 分析可以全部保留，不等于同时立三项算法课题。
