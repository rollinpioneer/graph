## 3. 两个最小候选的精确定义

令 b_phi(s',z)=clip(reference_actor(s',z),-1,1)，c(s',z) 为 stop-gradient 后的最新在线 Actor 动作。所有动作幅度和密度均在**裁剪后的实际动作**上计算。这里不把关节动作正负解释为地图方向。

每个参考更新事件，用两臂共享、独立于原训练 RNG 的训练数据样本及高斯噪声。起点和非起点各 256 个有效下一状态，各两组噪声；两区域等权。梯度拟合集与步长检查集分开抽取，各自遵守此规模。起点沿用网格 (1,1)、(2,1)、(1,2)、(2,2)。只用 train，不能把留出轨迹加入优化。

共同拟合损失：

参考更新使用单独 PRNGKey(6824100)，按事件编号 fold_in 后分出 fit/check、区域和噪声子键；校准使用 PRNGKey(6824000)。不消耗原 Agent、NumPy/Python 训练随机流，保存实际索引及子键以核对两臂一致。

`L_follow(phi) = mean_{region,s,z,action_dim} (b_phi(s,z) - c(s,z))^2 / 2`。

**A：** 提议方向 d_A = -grad L_follow。参数候选为 phi + alpha*d_A；alpha 由动作幅度匹配步骤选择。A 没有行为密度损失。

**B：** 每个区域定义 S_r(phi)=mean[-log p_1701(b_phi(s,z)|s)/21]，使用前轮冻结的完整 69 维观测归一化。先得到与 A 相同形式的基本方向 d_0，再求：

`d_B = argmin_d ||d-d_0||_2^2 / 2`

`subject to <grad S_start,d> <= 0 and <grad S_outside,d> <= 0`。

这只是两个线性半空间的欧氏投影，可枚举零/单/双活跃约束求解；不引入可调密度损失权重。行为模型参数、在线 Actor 目标均不接受此更新。投影只提供一阶方向约束，**不能把它写成实际密度非恶化保证**。最终候选还须在步长检查集验证两个区域 S_r 增量均<=1e-5，并且共同 L_follow 不增加超过1e-5，否则缩短步长或拒绝。A 也检查 L_follow，不检查密度。

若 B 的方向投影后为零、无法保持实际密度，或只靠近乎零的步长通过，记为不可行/退化，不能称为持续学习成功。本方法只是待测试原型；非恶化的平均密度也可能掩盖少量动作问题或压制真正的策略改善，必须报告分布和尾部，而不只报告均值。

## 4. 实际变化匹配是解释前提

对每个区域定义：`RMS_r(phi_new,phi_old) = sqrt(mean_{s,z,action_dim}(b_new-b_old)^2)`。总体 RMS 按两个区域等权计算。不能用参数距离、相同学习率或相同上限替代实际动作匹配。

初始尺度按固定规则校准，**尚未计算或执行**：在同源 350k 的 reference 与 online Actor 上，用固定 train 校准集（每区域1024状态、两组噪声），构造 `phi_cal=(1-tau)^100*phi_ref+[1-(1-tau)^100]*theta_actor`，tau=5e-5。该数组只用于定义等效100次 EMA 的总体 rho0 与区域 rho_r0，不写回 Agent。数值、状态索引和哈希在未来获准的零更新准入中登记；不能按成功率或崩塌结果改半径。

若校准半径为零或方向无法产生非零动作变化，停止准入；不得添加噪声或人为抬高半径来冒充持续更新。

每次更新均受总体 rho0 和各区域 rho_r0 上限约束。对固定方向进行有界标量步长搜索：计算动作 JVP `v=J_phi b @ d`，以 `alpha_init=rho0/max(sqrt(mean(v^2)),1e-12)` 为初始尺度。最多8次步长减半回溯、12次区间细化，所有候选都要实际前向测量。遇非单调曲线只保留已验证可行的步长，不声称找到全局最大值。

先取得两臂各自可行的总体动作半径，再用 `rho_common=min(rho0,rho_A_feasible,rho_B_feasible)` 对两臂重新定标，使总体实际 RMS 与 rho_common 相差不超过5%。每次更新需短暂同步两臂；可以多卡并行执行 GFP 更新，但不能一臂越过参考更新边界后先继续。

**这个 A 是配对实验控制，不是独立部署算法：** A 的方向不读数据支持模型，匹配器只把共同半径交给 A；B 可行性可能缩小两臂共同半径。此设计刻意让 A 同步承受 B 的减速，以隔离数据支持对方向选择的额外作用。若共同半径缩小导致两臂近乎冻结，本轮不能裁决。

未来准入及解释门槛预先规定：

- 相同参考尝试时点、相同逻辑更新数、相同样本/噪声；每臂最多500次参考事件。
- 初始真实500次 GFP 更新含5次参考事件，计入50k。五次均须通过总体匹配和有限性，至少4次各区域 RMS 相对差<=20%，且至少4次发生非零实际变化、共同半径>=0.5*rho0，否则停止两臂，保留为匹配准入失败，不自动换参数。
- 完整运行要求>=90%事件的总体 RMS 相对差<=5%，且各区域差<=20%；每个5k窗口的区域累计动作路径长度差<=10%。相对差用 `abs(A-B)/max(A,B,1e-8)`，不能用有符号差抵消。
- >=90%事件需发生非零实际动作变化且 rho_common>=0.5*rho0。还要报告相对初始 reference 的净漂移、距在线 Actor 的拟合误差、接受/拒绝率和裁剪比例，避免把参数微小变化或来回振荡冒充有效跟进。
- 冻结审计集（沿用前轮 train/test 的4032状态和固定噪声）每5k另测相邻检查点的区域动作 RMS、相对初始的净漂移和支持变化。相邻检查点动作差之和只是粗粒度路径，不能冒充100更新事件级的累计路径。独立 test 不参与选步长、半径、模型或调参。若 test 中 B 的区域粗粒度路径比 A 少超过10%，即使训练检查集匹配，也将结果标为残余幅度混淆；反向差异也如实报告。

准入后若出现单纯匹配偏离，记录而不按成绩反复调参；最终不满足门槛就不能作“数据支持额外保护”的解释。不要为了让 B 胜出而把 A 加速，也不要为了匹配数值把 B 改成永久冻结。

## 7. 预先规定如何解释

| 结果 | 决策 |
|---|---|
| 幅度/持续更新门槛通过，B保留较强收益而A崩塌，审计支持评分也改善 | 支持本窗口中数据支持信息有额外保护；仍非跨种子或最终算法证明 |
