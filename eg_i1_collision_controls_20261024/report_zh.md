# EG力闭合：I1与现有碰撞／PCR约束对照

2026-10-24。**结论：HOLD。EG现有点云碰撞过滤能明显减轻I1的碰撞副作用；原PCR的Rᶜ/Rˢ额外作用较小。组合后仍有明显漏检与原可行抓法损害，尚不能认为问题已解决。** 本轮未训练、未开发模块、未调参，代码与轻量结果按每轮归档要求上传新分支。

## 1. 范围与固定规则

复用48帧、1,229个原始干净候选（641可行、588弱力闭合）、14,748个15°离散角度姿态及既有GraspNet直接解析标签。没有新增力闭合计算。只补算原EG点云碰撞检测和PCR物理项；固定位置、接近轴、深度、宽度、分数与候选ID。

|组别|选角规则|
|---|---|
|O|原始EG角度|
|A|最小I1|
|B|通过原EG点云碰撞检测的角度中，最小I1|
|C|最小 I1＋Rᶜ＋Rˢ|
|D|通过原EG点云碰撞检测的角度中，最小 I1＋Rᶜ＋Rˢ|
|E|通过GT碰撞／空夹筛选的角度中，最小I1；Oracle参照|
|F|最小原PCR Rᴬ＋Rᶜ＋Rˢ|

所有系数预先固定为1，不归一化或搜索权重。原PCR的量纲及数值尺度保持不变，因此结论针对这一固定组合，不覆盖重新加权的所有可能结果。I1缺失的角度不参与A–E的风险比较；F只要求PCR有限。风险差≤10⁻⁷视为数值并列，优先保留原角度，再按最近周期角及类别号选择。没有合格角度时回退原动作，实际各组回退数均为0。

EG检测使用原始有效深度的官方工作空间裁剪、5 mm体素、50 mm接近距离、0.01占据比例阈值。PCR使用既有目标物体SDF，指尖位置为`d−2 mm`及`±w/2`，原5/20 mm距离约束、边界采样与法向定义不变。C/D/F是离线GT物理代理选角对照，**不是已训练PCR模型结果**；B也依赖GT接触I1选角，不能作为已部署方法收益。

三机各最多4个CPU进程并行。48帧原EG碰撞掩码、O组完整后处理均严格复现；A/E的选角和状态与上一轮一致。PCR原角度重放最大差异为Rᴬ 1.55×10⁻⁶、Rᶜ 2.33×10⁻⁸、Rˢ 3.35×10⁻⁸。按原规则保留SDF边界外采样；D组121个残余碰撞均非边界外样本。历史输入和既有标签SHA不变；未访问C4/C5。

## 3. 漏检与误过滤

在全部14,748个角度姿态上，GT非空碰撞有7,985个；EG漏检 **2,673/7,985＝33.48%**。场景等权漏检率34.55% [31.86,36.96]。

GT干净非空姿态6,762个，EG过滤457个：相对官方静态GT的“误过滤率” **6.76%**；其中2,470个实际可行姿态被过滤164个，比例 **6.64%**。由于原始1,229个姿态本已通过EG过滤，去掉这些名义姿态后，新增角度的干净姿态误过滤率为 **457/5,533＝8.26%**，可行姿态误过滤率 **164/1,829＝8.97%**。

在A实际选中的224个碰撞中，EG检出127个、漏掉97个，同时过滤40/750个可行抓法。B重新从其余角度选动作，得到的127个碰撞是另一个姿态集合，不能把它与A的97个漏检混为同一计数。

以上是相对官方**静态**碰撞标签的误差，不能直接等同于真实执行误报：EG还检查接近路径，夹爪后部体积和密度阈值也不完全相同。

## 4. 具体缺少什么能力？

只对D的121个残余碰撞及164个被EG过滤的GT可行姿态做限定几何归因；没有重新选角、改变阈值或计算力闭合。辅助几何掩码与既有GT静态碰撞、EG占据比例逐例核对一致。

**D的121个残余碰撞分成三类：**

|证据|数量|能支持的解释|
|---|---:|---|
|真实静态碰撞区域的观测点已被EG计入，但总占据比例≤0.01|74|存在可用碰撞观测，现有全体积归一化判据仍未触发；不能都归因于遮挡|
|存在静态碰撞观测点，但不在EG所用碰撞体内|3|夹爪碰撞体定义不一致|
|官方静态碰撞体内没有采样观测点|44|观测支持不足；可能涉及视角、裁剪、下采样、配准等，不能直接认定为遮挡|

官方静态侧指沿接近轴覆盖`−20 mm < x < d`，后部为`−30 < x < −20 mm`；EG使用固定60 mm指长，侧指为`d−60 < x < d`，再加后部与50 mm接近路径。两套体积并非恒等。

D残余碰撞中，34个涉及目标物体、64个涉及其他物体、32个涉及桌面，类别可重叠；**87个只涉及其他物体或桌面**。53个残余碰撞的Rᶜ和Rˢ同时为0。两指尖到目标物体SDF的距离约束缺少完整夹爪体积、邻物和桌面的碰撞覆盖，不能替代场景碰撞检测。

164个“可行但被过滤”的姿态中，有24个在EG额外体积内确有完整GT点占据，其中11个仅涉及接近扫掠；其余140个在当前GT采样表示的EG体积内没有对应占据。这支持判据、观测与几何离散表示均存在差异，**不足以把140个全部断言为深度噪声**。

代表例：scene100/帧0/候选1008的D选角，8个GT邻物点构成碰撞；11个对应区域观测点也被EG计入，但占据比例0.009403仍低于0.01。scene100/帧0/候选806则碰到邻物，静态碰撞体内没有观测点，且Rᶜ＝Rˢ＝0。

## 5. 原Top-1与完整后处理

在每帧原始1,024候选池中，仅替换本轮候选ID的角度，其余候选保持原状。所有组统一重跑：原EG点云过滤→NMS（3 cm、30°）→每物体Top-10→Top-50。没有只在1,229个子集上模拟“完整后处理”。

|组别|固定原Top-1：可行／弱／碰撞／无解／空夹|完整后处理Top-1可行率|
|---|---|---:|
|O|20／13／8／6／1|20/48＝41.67%|
|A|26／3／12／6／1|25/48＝52.08%|
|B|26／4／11／6／1|26/48＝54.17%|
|C|26／3／12／6／1|25/48＝52.08%|
|D|26／4／11／6／1|26/48＝54.17%|
|E|27／6／8／6／1|26/48＝54.17%|
|F|22／8／11／6／1|21/48已知可行，1个未知：43.75%–45.83%|

B/D的原13个弱Top-1中，6个恢复、3个转为碰撞、4个仍弱；原20个可行Top-1保持可行。B/D重跑后Top-1的候选ID均未改变，质量分数也未改变，故这部分改善来自GT辅助角度选择，不是重排序。相对O，Top-1可行率配对增量为12.50个百分点 [2.08,27.08]，仍只是该C3开发面板上的离线结果。

完整后处理会提升原本未评价的候选。F的scene186/帧0/候选470缺既有解析标签，保留未知，没有违反“只补算碰撞／PCR”边界。各组Top-50中共有3,045个策略—帧—候选条目缺标签，跨组可重复；逐组缺口已保存，不能据此比较完整Top-50平均质量。其余各组Top-1均有标签。

E是GT碰撞过滤下的I1参照，不是所有指标的无条件最优上界；相同EG后处理仍可能过滤GT可行角度，因此其完整Top-1与B/D可行数量相同，并不表示三者风险等价。

## 6. 决策

**HOLD：有明确改善，仍存在明显碰撞与可行率权衡。** 沿用预先固定的操作性5个百分点损害／新碰撞上限，B/C/D/F均未通过；即使不采用该具体门槛，D残余121个碰撞和45个原可行损害仍不能称为“副作用已解决”。

现有点云过滤应保留为强基线；Rᶜ/Rˢ在当前固定规则下的互补收益很小，原PCR完整代理F未提供可靠净收益。所有非O组选角均借助GT接触或SDF，不能将其包装成可部署的方法提升，也不能据此判断已训练PCR模型的效果。

缺口是：**可靠处理稀疏但真实的碰撞证据、统一夹爪／接近路径几何判据，以及在观测不足时覆盖完整场景碰撞风险。** 74/121个残余已有相关观测，当前证据不能直接支持新增复杂几何模块；44个缺观测支持也尚不足以确立新的独立创新点。本轮没有通过调阈值、改权重或新增模块争取GO，亦未启动训练。

**最终回答：EG点云过滤能解决I1碰撞副作用的一部分，原PCR局部约束不能补齐剩余缺口；主要限制同时来自碰撞判据、完整夹爪／场景覆盖和观测支持，尚不支持宣称已有约束足够或直接开发新模块。**
