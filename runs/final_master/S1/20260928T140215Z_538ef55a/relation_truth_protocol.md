# Relation truth protocol (frozen before S1 analysis)

Truth is a three-valued label over a relation in the finite, case-local universe: TRUE only when the relation is supported by the public contract anchor and an independent, adjudicable physical/task consequence witness; FALSE only when an independent witness contradicts the claimed consequence; UNKNOWN when either witness is absent, conflicting, or the case is not bound to T_P. Provider self-report and confidence are not truth. Contract redundancy is an admission rejection, not a FALSE physical relation.

Truth sidecars are evaluator-only and never planner inputs. No hidden simulator state, future result, VLM relation confidence, or learned Q is used.
