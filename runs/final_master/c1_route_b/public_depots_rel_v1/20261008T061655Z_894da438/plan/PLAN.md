# 审查后的下一步实验方向

## 0. 最终决定

**研究方向不变：在动作合同已知、训练目标结构受限的条件下，研究策略对新目标组合的泛化。现在结束积木上的模块筛选，转入关系受限评分的通用化与公开任务验证。**

下一阶段采用以下安排：

- **模型主线：**关系受限的目标交流（REL）。主要研究它能否在保持任务完成能力的同时，减少新目标结构中的额外动作。
- **执行层：**一步决策为默认；固定两步前瞻保留为强对照。另做零训练的选择性前瞻原型，检验是否能保留完成率、减少误干预和计算；它还不是已经成立的主贡献。
- **任务：**以公开 Depots 为下一主验证域；积木只做小规模零训练收尾。Satellite 暂缓为可选第三域，不预先规定它必须出现“REL 没有增益”的结果。
- **预算：**积木新增训练为 0；Depots 内部 MG-G、DENSE-G、REL-G 各一条；外部至少实际运行 LAMA 和一个 WL-GOOSE。AIW-AD／KR 2023 作为一项可选外部策略比较，不能无限扩大适配与重训。

**不是“REL＋门控已经成为完整新方法”，而是把已有最值得保留的结构信号放到公开任务和强基线上检验。**不再为了找到没有先例的方向切换研究问题，也不继续在旧128题上调规则直到获胜。

### 2.1 两段脚本揭示的统计口径问题

`paired_logs.py` 的 T7 使用八个方法共同成功的集合，尽管打印标题写“main four”。因此审查表中的116题、其中高4的52题，是**特定交集**，不是全部128题或全部64道高4题。[A2，T7]

T8 的符号检验则使用每一对方法各自共同成功的集合。T7与T8的样本数不同，不能混写成同一张配对表。

两个脚本将 `raw_is_optimal=true, selected_is_optimal=false` 记为损害。这准确描述“原始一步选择对、整个执行管线最终选择错”，但原始动作可能已经被C3排除。**它不自动等于纯粹的前瞻损害。**下一次运行正常记录 `raw_action`、`c3_action`、`final_action`，无需为此另开全历史审计。[A2，T5；A3，第35–47行]

审查关于“过早目标原子可能被叶值高估”的解释值得检验；但脚本只记录动作与结果，没有检查这些叶子是否真未在训练出现，也没有直接分解价值贡献。因此保持为强推断／假说，不能写成唯一根因。

## 3. 现有结果应怎样重新表述

### 3.1 保留的新证据：REL在部分困难任务上更少绕路

审查对八种方法共同成功的116题重读成本。其中52道高4题的**超额动作总数**为：

| 条件 | 高4超额动作总数，52题 |
|---|---:|
| MG_C3 | 148 |
| GOAL_DENSE | 108 |
| GOAL_REL | **64** |
| RAND_C3 | 142 |
| CAL_ABS_C3 | 88 |
| LOOK2_MG | 148 |
| REL_LOOK2 | 170 |
| RAND_LOOK2 | 136 |

来源为[A1 §1.1；A2 T7]。148降至64约减少56.8%，**仅针对这一共同成功子集**。REL在“所有最优方案都要拆除目标”的共同成功层中仍为54，与MG相同；不能把这种收益写成已经解决必要回退。

审查还报告REL对MG在高4配对中22题成本更好、3题更差，以及相关符号检验。[A1 §0、§1.1] 这些是有方向的证据，但指标是在看过结果后选择，存在多组比较和问题抽样相关性的限制。本轮不重算其p值，不把“探索性有信号”改成“已确证普遍优势”。

### 3.2 两步前瞻的定位改为“可靠完成的比较条件”

前瞻在必须拆除层提高完成率，是应保留的结果。审查同时显示，它对高4共同成功题的成本没有相同幅度的改善，并可能覆盖较好的放置选择。[A1 §1.1–1.3]

因此后续不以“前瞻使模型更聪明”为主张，而研究：

> 在哪些当前可观察的局面里值得追加计算，哪些局面应该保留一步评分器的决定？

这只是执行层候选。固定两步仍保留在表中，不能因为代价不理想就删除。

### 3.3 三条不再追的线

下一事件监督和当前反复关系推理配方继续停止。CAL_ABS保留成本信号和既有权重，但暂不新增“REL再叠校准”的训练，否则新域收益又混入损失变化。[A1 §2]

## 4. 方法主线：通用REL，门控前瞻独立评价

### 4.1 当前要争取的新增能力

**在简单目标结构上训练后，能够限制不合适的目标信息混合，减少复杂目标组合下的决策干扰；在少数确有需要的状态上增加有限前瞻，而不是所有步骤统一增加搜索。**

“关系限制”和“选择性前瞻”分别检验，不预设二者缺一不可。

```text
完整状态、全部目标、动作合同
        ↓
关系状态编码与逐目标表示
        ↓
MG：直接汇总
DENSE：所有目标互相交流
REL：按公开关系限制交流
        ↓
统一状态评分V与候选动作排序
        ↓
一步+C3 / 选择性两步 / 固定两步
        ↓
执行第一步，更新真实历史
```

保留全部目标。REL只限制一层目标注意力中的连接，不从真正的任务目标、合同或成功检查里删除事实。

### 4.2 通用关系定义：先不增加新的复杂机制

第一版沿审查的最小定义：[A1 §4]

\[
M_{ij}(s)=\mathbf 1[i=j\ \lor\ \operatorname{share}(g_i,g_j)\ \lor\ \operatorname{direct}(s,g_i,g_j)\ \lor\ \operatorname{threat}(g_i,g_j)].
\]

- `share`：两目标共享实际参数对象，不是名字相似或ID哈希相同。
- `direct`：某个当前为真的**二元动态事实**直接连接两个目标各自涉及的对象。不按谓词名字硬编码`On`。
- `threat`：沿用已有的动作ADD／DELETE对两个目标的直接威胁项；只用公开合同，当前积木中为空。其是否在Depots激活据实报告。
- 自连接始终保留。

不自动加入多跳闭包、共享任意静态地点的全连边或人工“最佳子目标依赖”。编码器仍可读取所有合法的静态和动态事实；限制的是mask的直接构造，不是剥夺模型必需输入。

**重要局限：**这个最小关系未必能表达经过吊车、车辆才能产生的间接资源冲突。若Depots无效，它可能是候选结构覆盖不足，也可能是训练或推理问题；不能自动归为“REL方向不成立”。本轮也不在看到测试结果后临时把多跳边补进主方法。

DENSE与REL使用相同逐目标特征、同一套一般化关系偏置、相同参数和初始化，主要差异是注意力掩码。新域不使用`both_On`／`both_OnTable`等积木专属类别；使用谓词与参数类型／位置等通用特征。

### 4.3 通用接口的必要工作

原子与动作采用结构化参数列表，不用切分字符串猜对象。保留参数顺序、类型继承、正负事实、静态事实及完整动作前提和效果。Depots含3参数Drive和4参数Lift/Drop/Load/Unload，不能沿用最多两个参数的张量假设。[W1]

三种模型复用同一个适配后的编码器和候选接口，不声称旧积木检查点可零样本迁移。

## 5. 积木阶段：仅做零训练执行检查，不阻塞新域开发

### 5.1 门控条件必须在还有选择时触发

设实际访问集为\(\mathcal V\)，C3保留的根动作为：

\[
A_C(s)=\{a\in A(s):T(s,a)\notin\mathcal V\}.
\]

- \(|A_C|=0\)：沿用原终止行为。前瞻不能从一个空根集合中制造出路。
- \(|A_C|=1\)：只有一个根动作，按原规则执行；不为改变根动作启动前瞻。
- \(|A_C|\ge2\)：才检查是否应展开。

审查提出的“根集合≤1”可作为日志里的风险描述，**不能直接作为有用的改选门控**。[判断]

### 5.2 修订门控：低间隔或首选会进入一步可见的无出口

[方案] 每个评分器独立使用训练状态确定阈值，随后冻结。定义：

- \(a_0\)：C3集合内的一步首选；
- \(m(s)\)：C3集合里第一、第二名的分数差；
- \(\tau\)：该模型在训练状态中至少两个合法动作时的分数差第10百分位；不存在合法估计时停用这一子门控并报告，不改用测试统计；
- \(R_1(a_0)\)：执行\(a_0\)后不是终点，且其所有合法后续动作都返回真实访问集或本地祖先状态。

\[
\operatorname{expand}(s)=\mathbf1[|A_C(s)|\ge2]\,
\mathbf1[m(s)\le\tau\ \lor\ R_1(a_0)].
\]

伪代码：

```python
available = c3_available_actions(state, real_visited)
if not available:
    return existing_no_candidate_termination()
first = one_step_best(available)
if len(available) == 1 or successor_is_goal(first):
    return first

small_margin = margin_of_top_two(available) <= frozen_training_threshold
local_trap = no_unvisited_one_step_exit(successor(first), real_visited)
if small_margin or local_trap:
    return existing_two_step_choice_or_existing_fallback(available)
return first
```

这是对审查门控的**新增修正**，不是旧脚本已经证实的算法。

低分差只是启发式，不是已校准的不确定性；`R1`只识别一层可见的无出口，不代表发现了所有未来死路。检查`R1`本身要调用合同展开，所有这类调用也计入成本。

假想状态不写入真实访问集。不放宽C3、不允许反复回来再试、不调用最优规划器决定触发。无需添加“手空才前瞻”的领域专用规则；拿起／放置仅用于分析。

### 5.3 最小评价范围

- MG门控版、REL门控版：各128局，共256局。
- 固定两步＋`h_add`叶值：128局。同树、同终点处理、同C3和并列规则；比简单目标计数更有信息，但也不是最强经典规划器。
- 既有一步、固定两步、CAL_ABS结果仅在代码、问题、权重完全相同时复用。
- 所有新结果均为旧Confirm128上的开发证据。

合计默认384局，不新增训练、不再从多个阈值中挑胜者。若工程无法暴露同树`h_add`，记为该对照未完成，不用一次完整经典搜索冒充叶启发值，也不阻止Depots主实验。

### 5.4 正常日志直接记录管线内三次选择

```text
raw_action       # 全合法集合的一步选择
c3_action        # 加访问过滤后的一步选择
final_action     # 门控/全量前瞻后的选择
raw_survives_C3
gate_reason, top2_margin, available_roots
expanded_states, evaluated_leaf_states, model_calls
```

评价标签事后计算。需要区分“原始→C3”的损害和“C3→树”的损害。不同控制器完整轨迹不同，管线内逐步修复不等于跨轨迹的总因果收益。

### 5.5 门控怎样决定是否带到新域

门控成功的目标是**计算—完成率—代价的折中**，不要求在三项上同时超过所有系统：

- 若比全量前瞻少计算，且大体保住完成能力，并比全量前瞻少制造放置损害，则保留为新域执行候选。
- 若总成本／完成能力没有合理折中，停止此门控；REL一步和固定两步仍按计划进入公开比较。
- 不因为门控失败就重新训练选择器或改三个阈值；它不是Depots的放行门。

## 6. 不变性探针：一次小检查，不能写成整体策略定理

审查提出“加入不相关目标时保持上下文”的假说。[A1 §4] 本文拆成两级，零训练完成：

### 6.1 模块级隔离检查

固定原目标输入向量\(z_i\)和所有旧关系特征，只追加若干目标向量，并确保REL掩码中旧查询到新目标的边被屏蔽。

- 检查旧目标的注意力输出是否保持数值一致。
- DENSE允许旧目标读新增目标，输出一般会变化。

这主要验证**掩码的局部性质**，不是学习成功的证据。它不要求最终总价值不变，因为\(\rho(\sum_i z_i)\)仍可能受新增目标影响。

### 6.2 端到端增补检查

在已有开发问题的可用状态上，加入已摆好、与旧物体物理不相接的新塔及相应已满足目标；比较原合法动作子集内部的排序、中心化分数和旧目标表示变化。

- 分开报告对象增加、目标标记增加与全图汇总引起的变化。
- 不比较包含新增动作的整体softmax概率，否则候选数量本身就会改变概率。
- 物理不相接仍可能共享手或工具，不把它称为严格任务独立。
- 预期是REL可能**更少受干扰**，不是严格零变化。

最多利用原240状态库，不新增题集、完整执行或梯度样本。若REL与DENSE同样变化，放下这一具体解释；不能仅凭这一探针判定整个REL无用，或反过来断言收益一定只是稀疏化。

## 7. 主任务改为公开Depots，但不把公开域改成自制游戏

### 7.1 选择理由

审查推荐Depots承接已发现的堆叠顺序现象，并加入运输和共享装卸资源。[A1 §6] 本轮读到的公开领域确实包含Drive、Lift、Drop、Load和Unload，原子包括`at/on/in/lifting/available/clear`；Lift能删除一个已成立的`on`目标。[W1]

因此，它比单纯继续扩大积木数量，更适合检验：

> 限制目标交流能否在多种准备动作、跨地点运输和堆叠目标并存时，仍然减少错误排序？

这仍是已知合同下的目标结构泛化。不是转向不完整合同、部分观测或技能可靠度学习。

### 7.2 不能预设的内容

- Depots有成熟求解方法，不能保证REL优于它们。
- 它与积木有部分共同结构，正结果是“堆叠加运输下的方法复用”，不等于任意领域通用。
- 不为让REL获胜修改Drive、Load等动作语义或隐藏基线的资源信息。
- 不预设公开Satellite一定无增益。最终目标不可删除，仍可能存在共享设备、准备和调度问题。

### 7.3 两条数据轨道

**轨道A：公开原始任务。**采用公开任务库中的顺序Depots问题，原领域和目标不修改；记录文件、版本和哈希。不能只挑已经被内部模型做对的实例。

**轨道B：公开域上的受限目标结构训练。**使用公开生成器产生实例，再按明示的规则筛选／构造目标。属于本项目的自定义划分，不冒充IPC官方协议。

公开生成器只有地点、卡车、托盘、吊车、箱子数量和随机种子等选项，没有直接的“目标堆高／堆数”开关。因此构造受限划分需要明确的后处理，不能在命令里虚构不存在的参数。[W2]

### 7.4 轨道B的最小建议规模

| 集合 | 目标范围 | 建议规模与限制 |
|---|---|---|
| 训练 | 3–5箱、1座非平凡目标堆、高2–3 | 固定2地点、1卡车；同时包含需要运输与不需运输的问题；起步目标96个不同问题 |

目标堆高按箱子数量计算，不把托盘算作一层。固定数量与摆放充分的托盘及每地点的装卸能力，使不可解不由错误生成造成。数据与任务的同构查重保持对象类型、静态拓扑和目标，不用物体名字制造“新题”。

## 8. 三条内部训练：一次适配，保持一个核心变量

| 模型 | 状态与目标读出 | 新训练 |
|---|---|---:|
| MG-G | 通用关系编码＋逐目标特征＋整体价值读出 | 1 |
| DENSE-G | 同基座＋全目标对注意力 | 1 |
| REL-G | 与DENSE-G相同，但按通用关系限制注意力 | 1 |

### 8.1 初始化与训练数据

三者都在新域从共同随机初始化开始。共享层初始张量相同；DENSE与REL的新增层相同。它们不加载积木专用词表权重，也不先给REL单独预训练。

训练状态、最优动作集合、各候选后继的距离标签以及采样权重一致。训练只使用轨道B训练题；公开测试、旧积木错误状态或新测试解不能成为梯度样本。

默认延续动作集合损失与候选排序损失。**本轮不同时把绝对值校准只加给REL。**这样新的主对照首先检验mask，而不是“mask＋新损失”。

CAL_ABS的现有正信号保留为下一轮候选。如果后来需要检验校准与REL是否互补，应在基础MG和REL上匹配增加校准，单独计预算；不能因为现成信号就称二者已经正交验证。

### 8.2 训练预算

开发每条件一个种子。先用新域少量训练问题测量合法动作量、接地图大小和标签耗时，再一次性冻结三个方法的相同预算。

初始建议上限100轮、4,100次优化器更新；数据较少时按既定循环采样规则使用同一展示量。**不机械继承旧卡744,600这个数字，更不承诺三条新训练只用3小时。**域图、候选数和标签成本均已改变。

保存相同的五次检查点，例如20/40/60/80/100轮。按开发集统一选择：先任务成功数，再失败计罚成本，再共同成功计划代价；并列取更早检查点。主要比较仍是DENSE-G对REL-G，不能把MG不同参数量的差异当作mask因果效应。

不设ID成绩过门；低分仍完整评价、记录为方法结果。只修新接口正确性、数据泄漏或数值故障，不为成绩不好重复运行。

### 8.3 监督标签的现实成本

使用Fast Downward的A*＋LM-cut获取小问题最优解和训练状态标签；这是官方支持的配置。[W3]

但**一条最优计划不等于全部最优第一动作集合**。对用来做集合／排序训练的状态，需要计算各合法后继的剩余最优成本，或者用能够证明等价集合的搜索接口。

- 训练状态可来自固定最优轨迹与固定规则的少量一步偏离；三模型与WL-GOOSE共享同一已完成的标签池。
- 标签超时记UNKNOWN；未找到解不自动等于死路。
- 证明不可解可记无穷成本，但损失要使用显式掩码／死路类别，不把无穷直接送入数值运算。
- 设统一CPU节点／时间和标签池规模预算，缓存相同问题状态；不足则减少所有方法共享的训练标签池，不只为主方法补标签。

在Depots中，错误动作不再必然只多2步；不能复用积木的“最优／非最优两档距离差”假设。通用状态遗憾应为\(c(a)+d^*(s')-d^*(s)\)。

## 9. 外部方法：至少两个真正运行的系统，而非仅列相关工作

### 9.1 必须运行

**LAMA：**作为经典完整规划参照，记录第一个有效计划和相同时间预算内的最好计划。后者叫“限时最好”，不是没有证明的“限时最优”。Fast Downward将LAMA作为满意规划配置，与A*＋LM-cut的最优求解配置区分。[W3]

当前GOOSE主线使用WL特征，历史GNN分支是另外的实现。必须记录实际运行的是哪一种，不把任意“GOOSE”数字当作同一算法。

### 9.2 可选一项完整学习策略对照

优先尝试AIW-AD作者实现；若接口／依赖无法在有限适配范围内完成，以KR 2023替代，不为了凑表训练两个。默认额外最多一条完整训练；工程未完成如实报告，不用自行简化的模型冒称作者复现。

AIW-AD、KR、WL-GOOSE的监督、搜索和计算预算不同：

- 同一受限训练问题不等于同一训练状态或标签使用方式；分别记录。
- 我们的一步、门控、两步是有限在线选择；WL-GOOSE＋搜索、LAMA是完整搜索。系统表可以并列，结构因果比较不能混在一起。
- 另按统一问题时间预算报告完成率、计划质量和计算资源；GPU、CPU、线程数分别记。
- 不强行剥夺外部方法原有搜索来使其退化。若做同搜索框架的适配表，须标“适配”，与原系统表并列。

本对话此前称为GSP的工作，明确指：Michael Aichmüller、Yannik Hesse、Hector Geffner，**Learning to Search and Searching to Learn for Generalization in Planning**，ICML 2026／PMLR 306，1434–1450。[W6]

## 10. 新域执行与评价：不再以一个“全程最优数”决定路线

### 10.1 执行条件

每个内部评分器默认运行：一步＋C3、固定两步；积木门控表现出合理计算—质量折中时再运行同定义的新域门控，阈值仅用**该域该模型**的训练分数确定。

最多3模型×3档=9个内部条件，不为每个执行档位重新训练模型。MG与REL的一步比较、DENSE与REL的同档比较是主结构对照。

新域C3仍代表真实访问状态排除，不是物理不可达判定。返回完整状态的相等性须包含运输位置、吊车持物、车辆装载与目标成就等全部动态信息。

固定两步在Depots不再天然对应“一次完整移动”，从Lift、Drive或Unload出发的两步意义不同。需要按动作族和准备阶段分别报告，不把积木的拿起／放置规律当作新域定律。

### 10.2 主结果

1. **全部问题的任务完成率**，包括标签参考解超时的公开问题。
2. **每一对方法共同成功题上的计划成本差**：更好／更差／相同数量、差值分布、长尾，附样本数。
3. **覆盖所有问题的失败计罚成本或成功—成本前沿**，避免“难题都失败但平均动作很少”被当成优势。
4. 分层：训练内／外目标高度、堆数、箱子数、运输需求、目标拆除标签（TRUE/FALSE/UNKNOWN）。

共同成功差值\(C_A-C_B\)本身不需要知道最优值；因此规划器未证明最优，不阻止配对成本比较。

### 10.3 辅助结果

最优性参考已证明时报告\(C/C^*\)、超额成本和全程最优。尚未证明时，只能写“相对参考计划长度”或上下界，不把最好已知计划当成真最优。

记录第一次错误与错误类型，仅在对应状态标签可得时计算；计时段外进行评价规划器调用，不把监督标注时间混入策略推理时间。

同时报告完整每题时间、状态展开、叶值评价、网络逻辑调用与批次、峰值内存、门控频率、按动作族的误干预。模型参数量不等于计算量。

### 10.4 统计和数据角色

- T7那种所有方法成功集合可作一张描述表，但不能取代每对方法和全部问题的表。
- 符号检验衡量方向，不衡量改善幅度；附实际成本差。
- 单训练种子限制训练稳定性；不同题目的抽样不确定性与种子方差分开。
- 重命名孪生或同源成组题按簇处理；不把逐动作记录当作独立样本。
- 预先确定少量主比较，其余标为探索性；多个检验报告校正／未校正身份，不用p<0.05作自动继续门。
- 新域封存测试不得用于检查点或门控阈值选择。旧Confirm128仍是开发材料。

### 10.5 拆除标签不能过度要求

“所有最优方案都需要拆除”与“所有成功方案都需要拆除”不同。仅当最优续接搜索和无拆除最优路线判定都完成时，才能给前一种强标签。Depots可能更难，UNKNOWN单列，不强求每题都在训练前算完这种机制标签。

这项标签不作为是否允许整个公开实验运行的门，避免重新落入过度资格审计。

## 12. 结果如何决定后续，避免又进入无限局部修改

### A. REL在Depots同档位下比DENSE减少成本，并保住完成能力

保留REL为方法主线；若门控也产生合理的计算—质量折中，则作为可选执行组件。下一步才补主方法与关键控制的训练种子，或第三个结构不同的公开域。

能主张的是受限目标结构训练下的关系交流先验，不是“首次注意力”“恢复了真实依赖”或任意规模通用。

### B. REL只在一步更好，搜索后差异消失

不当作失败。可以形成**低推理计算下的评分优势**，但必须实测时间、展开和质量；不能因为没有两步后的增益就抹去一步价值，也不能反过来把搜索优势归给mask。

### C. REL与DENSE接近，门控有用

主结构主张尚未跨域得到支持；门控保留为执行改进，不能立刻给成熟规则改名当完整创新。可以复盘数据与接口的明确缺口，但不自动增加新mask、校准或重新选方向。

### D. REL和门控都没有明确收益

停止这一方法组合的推广，完整保留跨域负结果。此时再选择原方向内下一方法；不能仅因为某一张配对表“净好题≤0”就宣告整个方向错误，也不能不停换测试题救方法。

### E. 外部搜索方法更强

先区分：它是否同时在成功率、计划质量、计算时间和监督成本上占优。若我们只在有限在线预算下有优势，就把贡献限定在那里；若在主张相关的全部维度都被覆盖，应放下相应性能优势主张。

**被一个使用不同搜索预算的方法超过，不自动证明所有结构增量不存在；却也不能通过削弱它的搜索把结果反转。**

### 候选问题
