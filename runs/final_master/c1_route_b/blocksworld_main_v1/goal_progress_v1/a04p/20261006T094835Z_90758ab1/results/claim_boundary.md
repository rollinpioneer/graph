# Claim boundary — C1-BW-A04P

Permitted: (1) B2's recorded A2 first errors are uniformly "put the held block on the table instead of stacking it on its goal support", the correct move usually ranked second, with explicit per-group denominators. (2) On the consumed A03 failure states, replacing the other goal towers by table goals (history and hidden fixed) turned the correct stack into B2's argmax in 33/46 valid samples, whereas the reference time input did not change the decision. (3) On the new Pilot80, four zero-training controllers on the frozen B2 file gave the listed success/optimality numbers; C3 and G1 are strong, training-free baselines.

Not permitted: that the goal-set sensitivity proves additive/decomposed scoring is the cause or the cure (the probe changes the task and the input distribution; history, coverage and other variables remain); that the time input is irrelevant in general (only the current-input channel was probed); that a controller is an algorithmic improvement in optimal decisions when it only reduces loops (C3: success up, decision-perfect barely); that Pilot80 results confirm anything for new models (it is development evidence, never a final confirmation set); that G0 samples are episodes; any REP label or ID-gate relaxation; any significance statement (single deterministic checkpoint, small n).
