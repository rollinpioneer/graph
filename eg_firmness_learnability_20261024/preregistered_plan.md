## 0 一句话

## 3 输入、目标与模型

**输入（全部来自冻结官方 EG epoch-10 的一次前向，不改权重）：** 对每个候选（即 EG 的一个种子点及其选定视角）：
- `vp`：抓取头输入的柱状分组特征，256 维；
- `ang`：抓取头内部交互后的角度特征，64 维；
- `logit`：12 个角度 logit（第 13 类不用）。

**目标（只用于训练，推理时不用）：** 对候选的 12 个角度变体，用官方评价得到 μ：
- 未碰撞、非空：μ∈{0.2, …, 1.2} → 牢度 q = (1.4 − μ) / 1.2（0.2 → 1.0，1.2 → 0.167）；无力闭合解 → q = 0；
- 碰撞或空夹的变体：q 不定义，损失里屏蔽（碰撞交给风险项，牢度头只学"牢不牢"）。

**两个小头（结构事先定死）：**
- **M_feat**：输入 [vp, ang, logit]（332 维，按训练集标准化）→ 全连接 256 → ReLU → dropout 0.1 → 12 个输出；
- **M_logit**：输入 logit（12 维）→ 全连接 64 → ReLU → 12 个输出（对照，回答 F-H2）。

**损失：** 屏蔽后的逐角度均方误差 + 列表式交叉熵（对有效角度，预测分布 softmax(ŷ) 对目标分布 softmax(q / 0.1)），权重 1 : 1，固定。

**训练：** Adam，学习率 1e-3，权重衰减 1e-4，批量 512，最多 30 个 epoch，按验证集损失早停（耐心 3）。3 个种子（20261024 + 0/1/2），推理时取 3 个种子预测的平均。不调超参数。

## 4 决策规则（与 P2 复核相同，只换"增益"的来源）

- 增益：gain_k = q̂_k − q̂_原（小头预测）。
- 风险：R_de（距离独热 + EG 碰撞比例 + 其变化），系数用已冻结的 `frozen_models_P2.json`，不重拟合。选 R_de 而不是 R_do，因为 P2 上两者没有差别，而 R_de 只用 EG 现有输出。
- 换角：score_k = gain_k − λ·p_k，score_原 = 0；取最大者，只有为正才换；并列取距离小、再取索引小。原角度 I1 缺失不影响本规则（不用 I1）。
- **λ 标定：** 在 λ 标定集（N0 的 48 帧）上，从 0 ∪ logspace(−4, 2, 601) ∪ {∞（永不换角）} 中选使"可行抓取数"最大的 λ，并列取较大 λ。每个增益来源各自标定。C3、P2 上不再调。

## 5 对照

所有对照用同一风险、同一规则、各自在标定集上定 λ：
- B0：什么都不改（C3 可行 641，P2 可行 591，新增碰撞 0）；

## 6 指标与门槛

主指标：可行抓取数（无碰撞、非空、0<μ≤0.4）。它同时扣掉了新增碰撞和转坏的抓取。区间：场景等权、seen/similar/novel 分层 bootstrap 10,000 次，rng=20261024。

| 门槛 | 条件 |
|---|---|
| **F1（C3 有收益）** | M_feat 可行数 − 641 ≥ +31（候选数的 2.5%），且可行率差的 95% 区间下界 > 0 |
| **F2（特征有用）** | C3 上 M_feat − M_logit 可行率差的区间下界 > 0 |
| **F3（P2 复现）** | M_feat 可行数 − 591 ≥ +37（2.5%），且区间下界 > 0 |
| **G（碰撞护栏）** | C3、P2 上 M_feat 新增碰撞率都 ≤ 4% |
| 只报告 | 预测增益与真实 q 增益、真实 I1 增益的相关（非碰撞变体）；受损与救回；B1、B2、I1 参照的全部数字；验证集曲线 |

## 9 边界（直说）

- 这是冻结特征上的读出实验。LEARNABLE 说明"从单视角能估计牢度到可用程度"，但还不是完整方法：完整评测要看全流水线的 Top-1/AP。
