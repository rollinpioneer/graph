正式两条 GPU 驻留合计 **12.5775 h**，并行墙钟 **6.3328 h**，CPU 合计 **13.6973 h**。独立 P1 另计 0.06664 GPU h；P1+正式合计 12.6441 GPU h。P0 安装、数据核验、队列等待和本轮整理不计入正式训练墙钟，不把此数值冒充整个工程从开始到归档的总耗时。

GPU 驻留以进程有 GPU 显存的采样起止计算，包含评价及停顿；正式资源轮询约 5s，边界有采样误差。共享 A100 卡的总利用率不等于本任务 GPU 利用率，该成本不是专用卡的内核活跃小时。RAM 为进程树轮询峰值；GNU time 单进程 MaxRSS 另保存在 cpu_time.txt。

各进程绑定四核，实际 user+system 平均约 1.09 CPU cores；未改变 batch、精度或训练长度。每条 101 次评价，共 5,050 回合；评价耗时分别约 1.703/1.785 小时，已包含在 GPU 驻留和墙钟中，不能再相加。

稳态统计取官方 5k 日志窗口，舍弃前 50k 和每次评价后的首个窗口（官方 main 在日志后评价），每种子剩 293 个窗口。中位约 8.07 ms/update，仍含数据、日志和验证开销，非纯 JAX kernel 计时。全进程墙钟减原生评价后折算约 122.14/122.15 updates/s，此口径还包含初始化、保存等开销。p10/p90、CPU user/system 原值和单次评价中位见 `final/costs.csv`/`final/summary.json`。
