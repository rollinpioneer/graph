# 待审批实验卡（全部 `PROPOSED_NOT_APPROVED`，本卡不执行）

## A-V：剪枝现象的零拟合裁决（A1 路，唯一主要待审批卡）
**必要性**：它能改变 A1 的去留。现状有一个未解矛盾——官方 a-m 设计上在训练集内保持特征列划分，而上一卡观察到训练内严格序对在 a-m 下特征相同、未剪词表下可分。若是分析假象，A1 的“首个丢失环节”结论撤回，A1 降级；若属实，才有“官方默认配置下仍存在”的版本固定证据。读出/取整/类型静态问题已能由现有静态证据裁决，不需要实验。
- 科学问题（唯一）：在固定 wlplan 构建（wheel sha256 `0089e22796904c5ee73d0d5c863e3ce4e82b54561393e9e86b43d37e3932587f`，源码 `9d9fc99`）上，`pruning=a-m` 是否会使 Train96 训练集内的状态划分变粗？去掉剪枝（单因素）能否恢复这 836 对的区分？
- 方法身份：官方 wlplan 库的调用（`OFFICIAL_RERUN` 级别仅限库函数，不运行 GOOSE 训练入口）；不拟合、不产生权重。
- 单变量：`pruning ∈ {a-m, none}`；保持 ILG、2 轮、set、Train96 词表、状态集不变。
- 三条流水线：①冻结的 CP 流水线（加载 W1 模型的 a-m 嵌入）；②独立重建的 a-m（同输入，检验可复现/是否分析假象）；③同输入的 `pruning=none`。第一步先比较①与②，再比较②与③。
- 数据角色：训练角色=Train96 的 6399 个状态（词表来源，已有）；诊断角色=836 个零差对及其唯一状态（≤1,700 个）与 24 个探索候选（标记）；对照=另取不超过 836 个非零差训练对（固定哈希次序）验证管线没有过度合并。不查询任何标签，不引入 IPC/Joint 数据。
- 预算上限：运行 3 条流水线 ×（1 次 + 1 次重复以检验确定性）；0 训练、0 拟合、0 训练更新、0 神经前向、0 搜索、0 精确查询；8 CPU 核小时；≤2 线程、≤8 GiB；时间上限 2 小时；输出 ≤200 MiB；不在共享 GPU 上运行。
- 指标与分母：训练状态集的不同特征向量数（三条流水线）；836 对中被区分的比例（给全部分母，不只报告成功对）；24 个候选的逐项结果；每题覆盖；差异特征层分布；确定性复核。
- 预期：支持（真实现象）= 流水线①②一致且 a-m 下划分严格粗于 none，836 对中被 none 区分的比例及其分层可报告；反驳（分析假象）= a-m 与 none 在训练集内划分一致；无法判定 = ①与②不一致、或需要重新拟合才能评价；停止条件 = 发现假象或可由单一现成选项解释即停止，不扩展到新表示、不补权重、不升级为拟合卡。
- 随机性处理：无随机；重复运行比较逐位一致。
- 输出目录：新目录 `.../A_V_<UTC>/`；失败时保留日志，不自动重试超过 1 次。
- 信息价值：低成本区分“原方法表示边界”与“实现/配置/分析问题”；**不证明搜索重要性**。反对：即使确认也只是 E0。失败原因：版本不一致、MaxSAT 非确定性；可反驳条件：流水线①②不一致。
