# Omitted file: `transition_metrics.csv`

`transition_metrics.csv` is the 7.7 MiB per-transition scoring table generated
by the U0 corrected baseline evaluation.  It is retained locally but omitted
from GitHub as a large derived artifact.  The compact aggregate files in this
directory, including `corrected_main_table.csv` and `per_group_metrics.csv`,
remain versioned here; the table can be regenerated with the U0 scoring command
recorded in the repository documentation.
