# Omitted file: `transition_metrics_v3.csv`

`transition_metrics_v3.csv` is the 6.7 MiB per-transition table generated by
the reproducible U0 baseline v3 CPU rescore.  It is retained locally and
included in the single delivery ZIP, but omitted from GitHub as a large derived
artifact.  The compact `corrected_main_table_v3.csv`,
`per_group_metrics_v3.csv`, `real_structure_ablation_v3.csv`, and
`u0_v3_rescore_report.md` remain versioned in this directory.
