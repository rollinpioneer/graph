# U2.0 data-design summary

The versioned U2 authority is synchronized and the historical U1-final handoff remains preserved. The generated dataset contains 72 episodes and 804 transitions.

Coverage gates passed for grazing, stochastic mixed success/failure, contact loss/recovery, detours, and stagnation. The transition-record schema exposes numeric state and action features only; generation strata, scenario names, and intervention schedules are prohibited model inputs.

This completes data design, not U2 scientific evaluation. Any subsequent U2 boundary model must retain the simulator-only scope and use heldout root families.
