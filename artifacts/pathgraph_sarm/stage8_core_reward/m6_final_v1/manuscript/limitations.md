# Limitations

The manual graph remains the main method. The real R1 coverage reruns do not support a coverage-scaling claim, and the real order-holdout reruns do not support unseen-order generalization. Policy evidence is secondary/mixed rather than a stable cross-seed improvement. Automatic graph discovery is not a main contribution. The task and data coverage are limited. Controlled symbolic stress checks establish only frozen graph semantics, not real-robot generalization.
