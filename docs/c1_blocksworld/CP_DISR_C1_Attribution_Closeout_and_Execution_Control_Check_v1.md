# 1. 主线决定

接受本卡收口。M1-GOAL 保留为学习评分器候选，B2 + G1 + C3 保留为当前整体表现最强的执行系统。两者不是同一种身份，不因选了学习候选就宣称它是最佳系统。

停止继续追逐“严格相加”“编码器必须不看目标”的解释，不启动 M1-NLL，不追加训练或种子。下一步只补两种未测的执行组合，在统一的执行控制下，判断新学到的评分是否能增加实际价值。

本计划不是为了换题使规则失败，也不是声明加一个访问集合就是新算法贡献。结果仍不支持学习评分增量时，结束当前积木任务族上的这轮局部模型改动，不自动扩展下一轮消融。

# 2. 本轮事实与解释边界

本文件依据固定提交的结果与实现，没有重新运行权重、训练或服务器进程检查。来源见末尾。[R1–R6]

## 2.2 支持的结论

- B2 加排序损失在可不拆的多塔层有收益，但单独不足以达到 M1 的水平。
- 恢复编码阶段的目标标记，没有在本次多塔层造成明显下降；“必须先去掉目标标记”不是现有结果支持的必要条件。
- M1-GOAL 改善了旧 M1 的颜色孪生不对称。它仍有两种颜色都失败的题，不等于一般颜色鲁棒性已被证明。
- M1-GOAL 在“每条最优方案都要拆”的层上有19道最优解，超出当前 G1 单独执行的结果；但没有超过 G1+C3。
- 高度4仍是所有学习条件的明显困难范围。层间的初始已满足目标数、布局、最优长度等并未全部匹配，不能把差距只归因于塔高或是否拆目标。[R1,R2]

## 2.3 两个必须明确的措辞修正

**第一，G1+C3 不是完全无学习的规则系统。**

实现先排除已访问的后继，再优先保留能严格增加已满足目标集合的动作，最后在剩余候选中按原 B2 分数选择。没有这样的进展动作时，仍按 B2 分数选，包括可能拆掉已满足目标的动作。“零训练”应写成“零新增训练”。[R4]

因此，不能由本轮结果推出“学习没有价值”；当前支持的是“现有 B2 配合两项运行时规则，比测试过的新学习系统更强”。该组合是否根本不需要学得分数，本卡也没有证明。

**第二，整体最强不等于每个切片、每个指标都最强。**

在颜色孪生的可不拆层，M1-GOAL 为16/16成功且16/16全程最优，而 G1+C3 为16/16成功、12/16全程最优。原 B2 同样是16/16，所以这不是新模型独有的优势，但说明强制进展规则有时也会损害原本正确的选择。[R1]

# 3. 下一步问题

不再问“新模型能否打败一个完全不用学习的规则”，而问：

> 在相同的访问记录和动作预算下，新评分器比旧评分器是否更会选择动作？简单进展规则对两种评分器分别是帮助还是干扰？

当前九条件表缺少 M1-GOAL+C3 和 M1-GOAL+G1+C3。旧 M1+C3 不能代替这两个结果，因为 M1-GOAL 已改变了评分行为。

# 4. 四条件配对矩阵：只补两个组合，零训练

| 条件ID | 评分器 | 排除已访问后继C3 | 优先直接进展G1 |
|---|---|---|---|
| B_C3 | 固定 A02 B2 | 开 | 关 |
| B_G1C3 | 同一个 B2 | 开 | 开 |
| MG_C3 | 固定 M1-GOAL final | 开 | 关 |
| MG_G1C3 | 同一个 M1-GOAL | 开 | 开 |

前两个是已有系统在新确认题上的配对参照；后两个是新增组合。四者全部无梯度、无优化器步骤。不新增融合权重、阈值、预测器或参数搜索。

## 4.1 必须复用的规则

对每个决策：

1. 从原合法动作集合中排除名义后继已在本局访问集合内的动作。
2. 如果剩余集合为空，按原 C3 以 `NO_UNVISITED_SUCCESSOR` 结束，不增加新回退策略。
3. 若 G1 关闭，在剩余候选中取对应评分器的最大分。
4. 若 G1 开启，找出执行后已满足目标集合为执行前严格超集的候选；该集合非空时优先它，否则使用所有未访问后继候选。
5. 使用原最大分及平分规则选动作；执行后记录实际到达状态。

保持原 hard mask 不变。访问集合是本局具体完整状态，不能合并“只在对象改名下相同”的不同物理状态。每局清空访问记录。

B2 沿实际轨迹更新原 GRU；M1-GOAL 继续没有 GRU/时间输入。不能为了匹配执行控制而偷偷改变两种评分器。两种评分器的训练背景也不同，本比较识别的是固定评分系统之差，不是单一模块的纯因果效应。

G1 是优先级规则，不是永久禁止拆目标。不得改成“任何破坏都不准做”。不得增加搜索树、规划器代选或额外步数。

# 7. 评价与解释

## 7.1 首要比较

1. `MG_C3` 对 `B_C3`：相同防循环控制下，替换评分器的影响。
2. `MG_G1C3` 对 `B_G1C3`：相同规则组合下，替换评分器的影响。
3. `MG_G1C3` 对 `MG_C3`：对新评分器，强制直接进展优先是否有用。
4. `B_G1C3` 对 `B_C3`：相同作用对旧评分器是否不同。

部署层面再比较 MG_C3 与当前最强 B_G1C3；因为规则不同，不将该项差距全部归因于评分器。

## 7.2 指标

同时报告成功数、全程最优数、实际动作数、成功后超额步数、失败预算与失败原因、共同成功案例上的路径差。失败案例不能从成本汇总中隐藏，也不只比较各自成功题的平均长度。

每个配对报告：共同成功、仅甲成功、仅乙成功、共同失败，以及同样的全程最优配对计数。颜色按完整孪生对报告：两边都对、只红对、只蓝对、两边都错。

主结论看全部分层，不用低塔平均分掩盖高度4或颜色的退化。新方法若成功率降低，不能仅凭剩余成功案例走得更短就宣称更好。

分层解释阈值沿用上一卡：32题层净差至少5题、16题层至少3题才标记为值得继续解释的方向。它们是研究决策阈值，不是显著性、等价界限或种子波动估计。阈值以下仍报告全部数值，不称为完全相等。配额不足时不擅自降低计数门槛，不发该层方向标签。

## 7.3 已有策略的保持性质

在准确确定性状态和正步长下，原全程最优轨迹不会重复完整状态。因此仅加 C3 不应改动这类轨迹。G1 可能在首次重复发生前覆盖动作，没有同样的保持保证。

该性质作为人工fixture检查；本卡不为此另做一轮完整原模型确认。只用同一模型的原始输出、访问集合和轨迹记录判断具体干预。

# 8. 技术工作限制

只新增最小的组合入口、fixture、登记与报告；不修改冻结模型或旧规则语义。不要生成一套新的训练框架。

必要fixture：原两个条件输出与原实现一致；两个新增条件只换评分器；C3先于G1；无可选后继处理相同；原合法性不变；孪生题与状态键处理正确；无优化器或反向传播；前后权重哈希相同。

登记并提交后才开放策略评价。模型分数低、不优于基线、颜色退化都不是停止剩余条件的理由。真实技术问题保留所有已执行记录；涉及语义的修复不得混入同一版本静默续跑。

# 9. 明确结束出口

- 若新评分器在相同控制下带来较少绕路或更多成功，并在困难层保留：继续以 M1-GOAL 为候选；下一算法问题聚焦它仍然选错的具体条件，不再回到加法/去目标标记归因。
- 若加G1对旧评分器有益、对新评分器反而有害：保留不加G1的学习控制器作为候选；这只是固定系统证据，不能自动声称学会了通用“何时回退”。
- 若新组合仍没有超过现有B_G1C3：保留B_G1C3作为当前最佳执行系统，结束本任务族上的局部读出、损失和规则微调循环。不因为投入已多而继续自动追加训练。
- 若各组合差异都很小：如实收口。它仍提供“评分与执行控制如何共同影响目标迁移”的比较证据，但不足以单独承诺高水平算法论文。

不自动挑选新任务来制造规则失败，不移除强基线，不宣称搜索慢，不把更少状态记忆当作已有计算优势。若后续确有来自应用本身的不同成本、观测或合同条件，单独定义研究问题和公平基线，再决定是否进入；本卡不启动。
